# 3D Neural Architecture Visualizer & Compression Atlas

Interactive WebGL 3D dataflow and multi-model architectural comparison across **DistilBERT**, **RoBERTa**, **GPT-2**, and **Qwen-2.5**.

### Key Capabilities
- **Interactive 3D Computational Graphs**: Explore exact projection geometries, attention heads, SVD bottlenecks, GPT-2 fused Conv1D, and Qwen-2.5 GQA.
- **Side-by-Side Architectural Comparison**: Baseline uncompressed transformer backbone vs. SVD / Low-Rank factorized topology.
- **240 Research Modules**: Verified drop-in attention and compression mechanisms with live LaTeX formulas, tensor shapes, and code snippets.
- **Real-Time Token Physics**: Trace tokens through residual skip highways, Q/K/V projections, and MLP feedforward blocks.
- **Zero-Install Static App**: Pure client-side Three.js & Vanilla ES modules.
