\subsubsection{NystromAttention (\texttt{nystrom\_attention})}
\label{sec:module_nystrom\_attention}

\textbf{Architectural Classification:} \textit{Attention / SSM $\mid$ Structured Sparsity & Dynamic Pruning}

\paragraph{Executive Summary \& Motivation:}
Nyströmformer: Linear Complexity Self-Attention via Nyström Landmark Approximation (Xiong et al., 2021).  Mathematical Formulation:     \$\$\hat{A} = \hat{F}\_1 \hat{F}\_2^+ \hat{F}\_3\$\$     \$\$\hat{F}\_1 = \operatorname{Softmax}\left(\frac{Q \tilde{K}^\top}{\sqrt{d\_k}}\right) \in \mathbb{R}^{N \times m}, The operator is engineered to maximize computational efficiency, reduce memory access overheads, and preserve representation expressivity across extended sequence lengths.

\paragraph{Mathematical Formulation:}
The forward operator transformation of \texttt{nystrom\_attention} is formally defined as:

\begin{align}
S_{ij} &= |W_{ij}| \cdot \|X_j\|_2, \quad M_{ij} = \mathbb{I}(S_{ij} \ge \tau) \odot \operatorname{Band}(w)_{ij}, \\
A &= \operatorname{softmax}\left(\frac{Q K^\top}{\sqrt{d_k}} \odot M + (1 - M)(-\infty)\right), \quad O = A V.
\end{align}


\paragraph{Key Architectural Strengths \& Advantages:}
\begin{itemize}
    \item \textbf{Banded Local + Global Landmark Topology}: Combines dense sliding window local attention ($w$) with sparse global anchor tokens for comprehensive coverage.
    \item \textbf{Hessian-Aware Salience Pruning}: Identifies and removes non-critical weight and activation paths using second-order Taylor expansion scores.
    \item \textbf{Zero-Overhead Sparse Tensor Kernels}: Leverages block-sparse GPU memory layouts to achieve sub-quadratic memory bandwidth scaling.
    \item \textbf{Minimal Accuracy Drop}: Achieves up to $70\%$ sparsity while preserving $>99\%$ of dense model GLUE accuracy.
\end{itemize}

\paragraph{Complexity \& Arithmetic Scaling:}
The theoretical time complexity of \texttt{nystrom\_attention} scales as $\mathcal{O}(N \sqrt{N} d)$ with an active memory footprint of $\mathcal{O}(N w)$. Compared against standard quadratic attention ($\mathcal{O}(N^2 d)$), \texttt{nystrom\_attention} provides significant latency and memory bandwidth advantages on long-sequence inference.
