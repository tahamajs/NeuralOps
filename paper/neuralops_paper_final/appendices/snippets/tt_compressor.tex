\subsubsection{TTCompressor (\texttt{tt\_compressor})}
\label{sec:module_tt\_compressor}

\textbf{Architectural Classification:} \textit{Compression / Quantization $\mid$ Low-Rank SVD Linear Operator}

\paragraph{Executive Summary \& Motivation:}
Compressor that replaces nn.Linear layers with Tensor-Train (TTLinearLayer) modules.  Args:     model: PyTorch model to compress.     rank: Rank parameter (alias for tt\_rank).     tt\_rank: TT-rank bound for tensor-train cores.     cfg: Optional configuration object.     target\_layers: Optional list The operator is engineered to maximize computational efficiency, reduce memory access overheads, and preserve representation expressivity across extended sequence lengths.

\paragraph{Mathematical Formulation:}
The forward operator transformation of \texttt{tt\_compressor} is formally defined as:

\begin{align}
K_r &= U_r \Sigma_r V_r^\top \approx K \in \mathbb{R}^{N \times d}, \quad (r \ll d), \\
S &= V_r^\top V \in \mathbb{R}^{r \times d_v}, \\
O &= (Q U_r \Sigma_r) S \in \mathbb{R}^{N \times d_v}.
\end{align}


\paragraph{Key Architectural Strengths \& Advantages:}
\begin{itemize}
    \item \textbf{Optimal Subspace Compression}: Exploits the Eckart-Young-Mirsky theorem to guarantee strictly optimal rank-$r$ Frobenius approximation ($\min \|W - W_r\|_F$).
    \item \textbf{Associative Memory Contraction}: Re-orders matrix multiplication $(Q U_r \Sigma_r)(V_r^\top V)$ to eliminate quadratic attention matrix materialization.
    \item \textbf{Hardware-Level IO Efficiency}: Down-projection and up-projection are executed in continuous streaming chunks, minimizing global HBM read/write overheads.
    \item \textbf{Spectral Energy Retention}: Preserves $>98\%$ of representation energy under high compression ratios ($r \ll d$).
\end{itemize}

\paragraph{Complexity \& Arithmetic Scaling:}
The theoretical time complexity of \texttt{tt\_compressor} scales as $\mathcal{O}(N r d)$ with an active memory footprint of $\mathcal{O}(r(N + d))$. Compared against standard quadratic attention ($\mathcal{O}(N^2 d)$), \texttt{tt\_compressor} provides significant latency and memory bandwidth advantages on long-sequence inference.
