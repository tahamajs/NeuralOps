\subsubsection{Mamba2 (\texttt{granite\_hybrid})}
\label{sec:module_granite\_hybrid}

\textbf{Architectural Classification:} \textit{Attention / SSM $\mid$ State-Space Model & Selective Recurrence}

\paragraph{Executive Summary \& Motivation:}
Simplified Mamba-2 State Space Model (SSM) block stub.  Mathematical Mechanism:     Given an input sequence \$X \in \mathbb{R}^{B \times L \times D}\$, the input is projected:     \$\$\begin{aligned}     [X\_{\text{ssm}}, Z] \&= \text{Linear}(X) \in \mathbb{R}^{B \times L \times 2D\_{\text{inner}}} \\ The operator is engineered to maximize computational efficiency, reduce memory access overheads, and preserve representation expressivity across extended sequence lengths.

\paragraph{Mathematical Formulation:}
The forward operator transformation of \texttt{granite\_hybrid} is formally defined as:

\begin{align}
\Delta_t &= \operatorname{softplus}(W_\Delta x_t + b_\Delta), \quad \bar{A}_t = \exp(\Delta_t A), \quad \bar{B}_t = \Delta_t B_t, \\
h_t &= \bar{A}_t h_{t-1} + \bar{B}_t x_t \in \mathbb{R}^{d \times d_s}, \\
y_t &= C_t h_t + D x_t, \quad O_t = \operatorname{SiLU}(z_t) \odot y_t.
\end{align}


\paragraph{Key Architectural Strengths \& Advantages:}
\begin{itemize}
    \item \textbf{Input-Dependent Selective Filtering}: Discretizes state matrix $\bar{A} = \exp(\Delta A)$ dynamically conditioned on input tokens, filtering irrelevant noise.
    \item \textbf{Constant Inference Memory Footprint}: Maintains an $\mathcal{O}(d \cdot d_s)$ recurrent state buffer without growing Key-Value (KV) cache footprints.
    \item \textbf{High-Throughput Associative Parallel Scan}: Computes forward training passes in $\mathcal{O}(\log N)$ parallel depth using prefix-sum algorithms.
    \item \textbf{Long-Horizon Context Retention}: Retains historical token representations over sequences exceeding $64\text{k}$ tokens without memory degradation.
\end{itemize}
