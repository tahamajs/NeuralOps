\section{Reproducibility Statement}
\label{sec:reproducibility}

To uphold the highest standards of scientific reproducibility and open science:
\begin{enumerate}
    \item \textbf{Codebase and Open Source Artifacts}: Complete source code for all \textbf{230 neural operators} (130 attention/SSM architectures and 100 compression/quantization engines), Triton JIT kernels, Stiefel optimizers, and evaluation scripts are released under an open-source permissive license.
    \item \textbf{Deterministic Randomness}: All multi-seed experiments use explicit fixed random seeds ($S \in \{42, 123, 777\}$) with deterministic PyTorch operations and cuDNN deterministic flags enabled.
    \item \textbf{Containerization \& Environment}: A standardized Dockerfile (\texttt{pytorch/pytorch:2.5.0-cuda12.4-cudnn9-runtime}) and pinned \texttt{requirements.txt} specifying all exact Python packages, CUDA drivers, and OS dependencies are provided in the repository.
    \item \textbf{Data Availability}: All raw loss curves, latency traces, singular spectra, and evaluation CSV summaries are preserved to enable instant, independent verification of all reported metrics.
\end{enumerate}
