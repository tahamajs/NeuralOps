
\section{Method}

\subsection{Overview}

Dobi-SVD replaces each target linear layer with a **differentiable 
factorized module**:

\[
y = (x (V \odot \sigma(\alpha))^\top) U^\top + b
\tag{4.1}
\]

where:

\begin{itemize}
\item $U \in \mathbb{R}^{d_\text{out} \times r}$ -- left factor (frozen initially, initialized from SVD)
\item $V \in \mathbb{R}^{r \times d_\text{in}}$ -- right factor (frozen, gate-compensated)
\item $\alpha \in \mathbb{R}^r$ -- learnable gate logits (trainable)
\item $b \in \mathbb{R}^{d_\text{out}}$ -- bias

\end{itemize}
\textbf{Figure 4.1} shows the pipeline.

\begin{lstlisting}
   +----------------------------------------------+
   |  Input weight W $\in$ R^{d\_out $\times$ d\_in}           |
   +--------------------+-------------------------+
                        |
                         
   +----------------------------------------------+
   |  SVD: W = U $\Sigma$ V^T                             |
   |  Rank r selected by energy threshold          |
   |  U\_r = U[:, :r] $\Sigma$[:r]^1/2                     |
   |  V\_r = $\Sigma$[:r]^1/2 V[:r, :]^T                   |
   +--------------------+-------------------------+
                        |
                         
   +----------------------------------------------+
   |  Gate compensation:                           |
   |  V\_r $\leftarrow$ V\_r / $\sigma$($\alpha$\_init)                        |
   +--------------------+-------------------------+
                        |
                         
   +----------------------------------------------+
   |  Create DobiSVDLinearLayer:                   |
   |  U $\leftarrow$ U\_r                                       |
   |  V $\leftarrow$ V\_r                                       |
   |  $\alpha$ $\leftarrow$ init\_gate\_val (learnable)                |
   +--------------------+-------------------------+
                        |
                         
   +----------------------------------------------+
   |  Recovery training:                            |
   |  Train $\alpha$ and LoRA adapters                    |
   +----------------------------------------------+
\end{lstlisting}

\subsection{The `DobiSVDLinearLayer`}

\subsubsection{Module Structure}

\begin{lstlisting}
class DobiSVDLinearLayer(nn.Module):
    def \_\_init\_\_(self, in\_features, out\_features, rank, bias=True,
                 init\_gate\_val=2.5, ...):
        self.V = nn.Parameter(torch.empty(rank, in\_features))
        self.U = nn.Parameter(torch.empty(out\_features, rank))
        self.gate = nn.Parameter(torch.full((rank,), fill\_value=init\_gate\_val))
        if bias:
            self.bias = nn.Parameter(torch.empty(out\_features))
\end{lstlisting}

\subsubsection{Forward Pass}

\begin{lstlisting}
def forward(self, x):
    g = torch.sigmoid(self.gate).unsqueeze(1)   # (rank, 1)
    V\_gated = self.V * g                         # (rank, in\_features)
    latent = F.linear(x, V\_gated)                # (..., rank)
    out = F.linear(latent, self.U, self.bias)    # (..., out\_features)
    return out
\end{lstlisting}

\subsection{Initialization Procedure}

\subsubsection{Step 1: SVD}

\[
W = U \Sigma V^\top
\tag{4.2}
\]

\subsubsection{Step 2: Truncate at rank $r$}

\[
U\_r = U\_{:, :r} \Sigma\_{:r, :r}^{1/2}, \quad
V\_r = \Sigma\_{:r, :r}^{1/2} V\_{:r, :}^\top
\tag{4.3}
\]

\subsubsection{Step 3: Gate compensation}

Let $\sigma_\text{init} = \sigma(\alpha_\text{init})$. Pre-scale $V_r$:

\[
V\_r \leftarrow V\_r / \sigma\_\text{init}
\tag{4.4}
\]

This ensures the initial forward equals the SVD reconstruction.

\subsubsection{Step 4: Store}

\begin{lstlisting}
layer.U.data.copy\_(U\_r)
layer.V.data.copy\_(V\_r)
layer.gate.data.fill\_(init\_gate\_val)
\end{lstlisting}

\subsection{Rank Selection}

\subsubsection{Parameter Reduction Constraint}

The rank must satisfy:

\[
r (d\_\text{in} + d\_\text{out} + 1) \textless{} d\_\text{in} d\_\text{out}
\tag{4.5}
\]

For square matrices at $d = 768$:

\[
r \textless{} \frac{d^2}{2d + 1} \approx \frac{d}{2}
\tag{4.6}
\]

Dobi-SVD uses an upper bound:

\[
r\_\text{max} = \max\!\left(1, \min\!\left(d\_\text{in} - 1, d\_\text{out} - 1, \left\lfloor \frac{d\_\text{in} d\_\text{out}}{d\_\text{in} + d\_\text{out}} \right\rfloor - 1, 32\right)\right)
\tag{4.7}
\]

Default \texttt{RANK\_CAP = 128}.

\subsubsection{Initial Rank}

If \texttt{rank} is not specified, use:

\[
r\_\text{init} = \max\!\left(1, \text{round}(2.1$\times$ \cdot \min(d\_\text{in}, d\_\text{out}))\right)
\tag{4.8}
\]

Default \texttt{INIT\_RANK\_RATIO = 0.5}.

\subsubsection{Adaptive Retry}

If reconstruction error exceeds \texttt{max\_error}, Dobi-SVD retries with:

\[
r\_{k+1} = \min(1.5 \cdot r\_k, r\_\text{max})
\tag{4.9}
\]

up to \texttt{max\_retries} (default 2).

\subsection{Training}

\subsubsection{Trainable Parameters}

\begin{itemize}
\item \textbf{Gates} $\alpha \in \mathbb{R}^r$ (one scalar per rank component)
\item \textbf{LoRA adapters} (attached to the wrapped layer)
\item \textbf{Non-target layers} are frozen

\end{itemize}
\subsubsection{Loss}

Standard cross-entropy on the downstream task:

\[
\mathcal{L} = -\frac{1}{N} \sum\_i \log p\_\theta(y\_i \mid x\_i)
\tag{4.10}
\]

Gradient flows through $\sigma(\alpha)$ to the gate logits.

\subsection{Post-Hoc Rank Pruning}

After training, gates are inspected. Let:

\[
r\_\text{eff} = \left|\{i : \sigma(\alpha\_i) \textgreater{} \tau\_g\}\right|
\tag{4.11}
\]

for a threshold $\tau_g$ (e.g., 0.5). Components with $\sigma(\alpha_i) \leq \tau_g$ 
can be \textbf{removed} without retraining, at the cost of a small accuracy drop.

\textbf{Algorithm 2:} Post-hoc rank pruning
\begin{lstlisting}
Input:  trained DobiSVDLinearLayer, threshold $\tau$\_g
Output: pruned layer with rank r\_eff

1:  gates $\leftarrow$ sigmoid(layer.gate)
2:  keep\_idx $\leftarrow$ where(gates \textgreater{} $\tau$\_g)
3:  r\_eff $\leftarrow$ len(keep\_idx)
4:  V\_pruned $\leftarrow$ layer.V[keep\_idx, :]
5:  U\_pruned $\leftarrow$ layer.U[:, keep\_idx]
6:  gate\_pruned $\leftarrow$ layer.gate[keep\_idx]
7:  return DobiSVDLinearLayer with (U\_pruned, V\_pruned, gate\_pruned)
\end{lstlisting}

\subsection{The Full Algorithm}

\textbf{Algorithm 1:} Dobi-SVD compression
\begin{lstlisting}
Input:  model M, rank r, gate\_init $\alpha$\_0, threshold $\tau$
Output: compressed model M'

1:  for each target layer   in M do
2:      W $\leftarrow$ weight( )
3:      U, $\Sigma$, V^T $\leftarrow$ svd(W)
4:      U\_r $\leftarrow$ U[:, :r]   $\Sigma$[:r]^1/2
5:      V\_r $\leftarrow$ $\Sigma$[:r]^1/2   V^T[:r, :]
6:      V\_r $\leftarrow$ V\_r / $\sigma$($\alpha$\_0)               Gate compensation
7:
8:      # Reconstruction validation
9:      W\_recon $\leftarrow$ U\_r   (V\_r   $\sigma$($\alpha$\_0))
10:     err $\leftarrow$  W - W\_recon \_F /  W \_F
11:     if err \textgreater{} $\tau$:
12:         if fallback: skip  
13:         else: escalate r and retry
14:
15:     # Replace
16:     layer\_new $\leftarrow$ DobiSVDLinearLayer(U\_r, V\_r, gate=$\alpha$\_0)
17:     replace( , layer\_new)
18: end for
19:
20: # Recovery training (external)
21: train\_gates\_and\_lora(M)
22:
23: # Post-hoc pruning (optional)
24: for each compressed layer:
25:     prune\_gates\_below(layer, $\tau$\_g)
26: return M
\end{lstlisting}

\subsection{Theoretical Notes}

\subsubsection{Lossless Initialization}

\textbf{Proposition.} If gates are initialized at $\alpha_0$ and $V$ is 
pre-scaled by $1/\sigma(\alpha_0)$, then the initial forward pass equals 
the truncated SVD:

\[
y\_0 = (x (V\_r / \sigma(\alpha\_0) \odot \sigma(\alpha\_0))^\top) U\_r^\top = (x V\_r^\top) U\_r^\top
\tag{4.12}
\]

$\square$

\subsubsection{Gradient of Gate}

The gradient of the loss with respect to $\alpha_i$:

\[
\frac{\partial \mathcal{L}}{\partial \alpha\_i}
= \frac{\partial \mathcal{L}}{\partial y} \cdot \frac{\partial y}{\partial \sigma(\alpha\_i)} \cdot \sigma(\alpha\_i)(1 - \sigma(\alpha\_i))
\tag{4.13}
\]

The $\sigma(1-\sigma)$ factor provides a natural gradient landscape 
that can push gates toward 0 (pruning) or 1 (retention).

\subsubsection{Rank Reduction Bound}

If after training we prune all gates with $\sigma(\alpha_i) \leq \tau_g$, the 
effective rank is:

\[
r\_\text{eff} = \#\{i : \sigma(\alpha\_i) \textgreater{} \tau\_g\}
\tag{4.14}
\]

and the parameter count is:

\[
|\theta\_\text{eff}| = r\_\text{eff}(d\_\text{in} + d\_\text{out} + 1)
\tag{4.15}
\]

\subsection{Summary}

Dobi-SVD:
\begin{enumerate}
\item Factorizes each target layer with SVD.
\item Adds a learnable gate per rank component.
\item Pre-scales $V$ for lossless initialization.
\item Trains gates jointly with LoRA recovery.
\item Optionally prunes gates post-hoc.
\item Achieves \textbf{real parameter reduction} with \textbf{learnable rank}.
\end{enumerate}
