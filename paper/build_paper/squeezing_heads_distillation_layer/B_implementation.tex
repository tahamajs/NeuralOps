\subsection{B.2 copy\_weights -- Core Logic}

\begin{lstlisting}
def copy\_weights(self, old\_attn):
    # Detect nested encoder
    has\_out\_lin = hasattr(old\_attn, "out\_lin") or hasattr(old\_attn, "c\_proj")
    if has\_out\_lin:
        self.is\_nested\_encoder = False
    elif hasattr(old\_attn, "self") and hasattr(old\_attn, "output"):
        self.is\_nested\_encoder = True
    
    # Extract Q, K, V, O per architecture
    if hasattr(src, "c\_attn"):  # GPT-2
        w = src.c\_attn.weight.t()
        q\_w, k\_w, v\_w = w.chunk(3, dim=0)
    elif hasattr(src, "query"):  # RoBERTa
        q\_w = src.query.weight
        k\_w = src.key.weight
        v\_w = src.value.weight
    elif hasattr(src, "q\_proj"):  # Qwen
        q\_w = src.q\_proj.weight
        ...
    elif hasattr(src, "q\_lin"):  # DistilBERT
        q\_w = src.q\_lin.weight
        ...
    
    # Copy with head-dim slicing
    self.q\_proj.weight.zero\_()
    m\_out = min(self.q\_head\_size, w\_q.shape[0])
    m\_in = min(self.hidden\_size, w\_q.shape[1])
    self.q\_proj.weight[:m\_out, :m\_in].copy\_(w\_q[:m\_out, :m\_in])
    
    # Copy with GQA pooling for K, V
    if w\_k.shape[0] \textgreater{} self.kv\_head\_size:
        rep = w\_k.shape[0] // self.kv\_head\_size
        w\_k\_pooled = w\_k.view(self.num\_kv\_heads, rep, self.head\_dim, -1).mean(dim=1)
        self.k\_proj.weight.copy\_(w\_k\_pooled)
\end{lstlisting}

\subsection{B.3 Common Pitfalls}

\subsubsection{B.3.1 Wrong `is\_nested\_encoder`}

If RoBERTa's \texttt{is\_nested\_encoder} is False, \texttt{out\_proj} is applied inside 
AND outside, doubling the output.

\begin{lstlisting}
# Correct check:
if hasattr(old\_attn, "out\_lin") or hasattr(old\_attn, "c\_proj"):
    self.is\_nested\_encoder = False
elif hasattr(old\_attn, "self") and hasattr(old\_attn, "output"):
    self.is\_nested\_encoder = True
\end{lstlisting}

\subsubsection{B.3.2 Wrong Conv1D Transpose}

GPT-2 Conv1D stores weights as \texttt{(in, out)}. Must transpose:

\begin{lstlisting}
c\_attn\_w = src.c\_attn.weight.detach()
if "Conv1D" in cls\_name or hasattr(src.c\_attn, "nf"):
    c\_attn\_w = c\_attn\_w.t()
\end{lstlisting}

\subsubsection{B.3.3 GQA Pooling Shape}

When pooling GQA heads, the reshape must be exact:

\begin{lstlisting}
w\_k\_pooled = (
    w\_k[:, :self.hidden\_size]
    .view(self.num\_kv\_heads, rep, self.head\_dim, -1)
    .mean(dim=1)
    .view(self.kv\_head\_size, -1)
)
\end{lstlisting}
