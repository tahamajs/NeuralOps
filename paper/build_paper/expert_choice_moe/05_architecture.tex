\subsection{Handling of the MoE Dimension}

The MoE operates on \texttt{all\_head\_size = num\_heads * head\_dim}. This equals the 
hidden dimension for standard attention.

\textbf{For GQA models}, \texttt{kv\_head\_size < all\_head\_size}. But the attention output 
is always \texttt{all\_head\_size} (Q heads $\times$ head dim). So the MoE input dimension 
is always \texttt{all\_head\_size = d}.

\subsection{Dynamic Dimension Adaptation}

If the incoming hidden size differs from the router's input size, a 
\textbf{dynamic router} is created on-the-fly:

\begin{lstlisting}
if D == self.d_model:
    logits = self.router(self.router_ln(x_flat))
else:
    normed = F.layer_norm(x_flat, (D,))
    if not hasattr(self, "_dynamic_router") or self._dynamic_router.in_features != D:
        self._dynamic_router = nn.Linear(D, self.n_experts, bias=False)...
    logits = self._dynamic_router(normed)
\end{lstlisting}

This handles cross-attention where the input dimension may differ.

\subsection{Nested Encoder Bypass}

For RoBERTa, \texttt{is\_nested\_encoder = True}:

\begin{lstlisting}
if self.is_nested_encoder:
    if enriched_attn.shape[-1] != self.dim:
        out = self.out_lin(enriched_attn)
    else:
        out = enriched_attn
\end{lstlisting}

The outer \texttt{attention.output.dense} handles the projection.

\subsection{Causality}

For decoders, causal masking is applied to attention scores:

\begin{lstlisting}
if self.is_decoder and not is_cross_attention:
    causal_mask = torch.triu(torch.full((L, kv_len), -inf, ...), diagonal=1)
    scores = scores + causal_mask.unsqueeze(0).unsqueeze(1)
\end{lstlisting}

The MoE operates on the attention output, which is already causal.

\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject ExpertChoiceMoEAttention
\begin{lstlisting}
Input:  model M, config c, n_experts, capacity_factor
Output: M with attention replaced

1: for each layer:
2:     src $\leftarrow$ extract_attention(layer)
3:     if src is None: continue
4:     try:
5:         new $\leftarrow$ ExpertChoiceMoEAttention(c, n_experts=E, ...)
6:         replace(layer, new)
7:     except Exception:
8:         raise RuntimeError("copy_weights failed")
9: return M
\end{lstlisting}

\subsection{Failure Handling}

The injection raises \texttt{RuntimeError} on any failure. This is strict because 
MoE injection is complex.
