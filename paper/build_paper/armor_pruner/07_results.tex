\subsection{Inference Efficiency and Memory Footprint}
Execution profiling demonstrates that \texttt{armor\_pruner} executes within the hardware constraints of standard cloud accelerators. Peak VRAM consumption remains strictly bounded, and end-to-end latency reflects low-overhead runtime execution without unbounded memory fragmentation.
