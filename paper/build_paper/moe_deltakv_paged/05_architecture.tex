\subsection{Weight Transfer}

\texttt{copy\_weights} extracts weights via five tiers:

\subsubsection{Tier 1: UniversalAdapter}

\begin{lstlisting}
for proj in ["q", "k", "v", "o"]:
    try:
        w, b = UniversalAdapter.get\_weight\_bias(pretrained\_attn, proj)
        if w is not None:
            extracted[proj] = (w, b)
    except Exception:
        pass
\end{lstlisting}

\subsubsection{Tier 2: GPT-2 Conv1D}

\begin{lstlisting}
weight = pretrained\_attn.c\_attn.weight.data
if weight.shape[1] == 3 * hidden\_size:
    weight = weight.t()
q\_w, k\_w, v\_w = weight.chunk(3, dim=0)
\end{lstlisting}

\subsubsection{Tier 3: RoBERTa Nested}

\begin{lstlisting}
if hasattr(pretrained\_attn, "self"):
    s = pretrained\_attn.self
    extracted["q"] = (s.query.weight, ...)
    extracted["k"] = (s.key.weight, ...)
    extracted["v"] = (s.value.weight, ...)
\end{lstlisting}

\subsubsection{Tier 4: Named Projections}

\begin{lstlisting}
named\_map = {
    "q": ["q\_proj", "q\_lin", "query"],
    "k": ["k\_proj", "k\_lin", "key"],
    "v": ["v\_proj", "v\_lin", "value"],
    "o": ["o\_proj", "out\_proj", "out\_lin", "dense"],
}
\end{lstlisting}

\subsubsection{Tier 5: Repetition for GQA}

If source weight has smaller $d_\text{out}$ (GQA), we repeat:

\begin{lstlisting}
if w.shape[0] \textless{} self.all\_head\_size and self.all\_head\_size \% w.shape[0] == 0:
    rep = self.all\_head\_size // w.shape[0]
    w = w.repeat(rep, 1)
\end{lstlisting}

\subsection{The Router $W_\text{rg}$}

\begin{lstlisting}
self.W\_rg = nn.Linear(self.head\_dim, self.head\_dim, bias=False)
nn.init.eye\_(self.W\_rg.weight)
\end{lstlisting}

Initialized to identity, so the router starts as the dot product of page-mean 
queries and keys.

\subsection{Load Balancing Loss}

Stored as a buffer (not a parameter):

\begin{lstlisting}
self.register\_buffer("aux\_loss", torch.tensor(0.0), persistent=False)
\end{lstlisting}

Updated during forward:

\begin{lstlisting}
router\_probs = F.softmax(router\_logits, dim=-1)
expert\_mask = F.one\_hot(topk\_indices, num\_classes=num\_pages).float()
density = expert\_mask.sum(dim=-2).mean(dim=(0, 1, 2))
prob\_mean = router\_probs.mean(dim=(0, 1, 2))
self.aux\_loss = float(num\_pages) * torch.sum(density * prob\_mean)
\end{lstlisting}

\textbf{Usage.} The training loop should add \texttt{aux\_loss * $\lambda$} to the classification 
loss. Typical \texttt{$\lambda$ = 0.01}.

\subsection{The `is\_causal` Flag}

\begin{lstlisting}
self.is\_causal = bool(
    getattr(config, "is\_causal", False)
    or getattr(config, "is\_decoder", False)
    or any(model\_type.startswith(p) for p in ("gpt", "qwen", "llama", ...))
)
\end{lstlisting}

For causal models:
\begin{itemize}
\item Router logits are masked (upper-triangular).
\item Full attention path is used when \texttt{num\_pages \textless{}= 2}.

\end{itemize}
\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject MoE-DeltaKV-Paged
\begin{lstlisting}
Input:  model M, config
Output: M with attention replaced

1: for   in transformer\_layers(M) do
2:     src $\leftarrow$ get\_attention( )
3:     try:
4:         new $\leftarrow$ MoEDeltaKVPagedAttention(config, pretrained\_attn=src)
5:         replace( , new)
6:     except Exception as e:
7:         raise RuntimeError(...)    HARD FAIL
8: end for
\end{lstlisting}

\textbf{Note.} Current implementation raises on failure. In production, change 
to \texttt{logger.error(...); continue}.

\subsection{Interaction with Recovery}

Base weights are frozen; LoRA adapters and $W_\text{rg}$ are trainable.

Per-layer trainable:
\begin{itemize}
\item LoRA on query, key, value, out\_proj: $4 r_L (d + d_h)$
\item $W_\text{rg}$: $d_h^2$

\end{itemize}
For $d = 768$, $d_h = 64$, $r_L = 16$: ~102K per layer.
