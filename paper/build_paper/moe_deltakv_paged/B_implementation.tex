\subsection{B.1 STE Quantization}

\begin{lstlisting}
def ste\_quantize\_4bit(x):
    if x.numel() == 0:
        return x
    x\_min = x.min(dim=-1, keepdim=True)[0]
    x\_max = x.max(dim=-1, keepdim=True)[0]
    scale = torch.clamp((x\_max - x\_min) / 15.0, min=1e-5)
    x\_q\_int = torch.clamp(torch.round((x - x\_min) / scale), 0, 15)
    x\_q = x\_q\_int * scale + x\_min
    return x + (x\_q - x).detach()  # STE
\end{lstlisting}

\subsection{B.2 Delta-KV}

\begin{lstlisting}
def simulate\_paged\_delta\_kv(K, V, rank):
    B, H, N, d = K.shape
    if N \textless{}= 1:
        return K, V
    
    K\_hat = torch.zeros\_like(K)
    V\_hat = torch.zeros\_like(V)
    K\_hat[:, :, 0] = K[:, :, 0]
    V\_hat[:, :, 0] = V[:, :, 0]
    
    delta\_K = K[:, :, 1:] - K[:, :, :-1]
    delta\_V = V[:, :, 1:] - V[:, :, :-1]
    
    delta\_K\_hat = low\_rank\_svd\_quantize(delta\_K, rank)
    delta\_V\_hat = low\_rank\_svd\_quantize(delta\_V, rank)
    
    K\_hat[:, :, 1:] = K[:, :, 0:1] + torch.cumsum(delta\_K\_hat, dim=2)
    V\_hat[:, :, 1:] = V[:, :, 0:1] + torch.cumsum(delta\_V\_hat, dim=2)
    
    return K\_hat, V\_hat
\end{lstlisting}

\subsection{B.4 Common Pitfalls}

\subsubsection{B.4.1 STE Only Affects Backward}

Forward uses quantized; backward uses identity. If you inspect the forward 
values, they will be quantized, but gradients flow through the original.

\subsubsection{B.4.2 Delta-KV Requires Same Shape}

Reconstructed $\hat{K}$ has shape $[B, H, N, d_h]$, same as $K$. No memory 
savings.

\subsubsection{B.4.3 6D Gather is Expensive}

The intermediate \texttt{[B, H, N\_p, k\_exp, P, d\_h]} can be 256 MB per layer.

\subsubsection{B.4.4 Page Padding}

When $N$ is not divisible by $P$, pad with zeros. Mask padding keys.

\subsubsection{B.4.5 CLS Boost Must Exceed All Others}

Use $10^4$, not $10^2$. Small boosts may not guarantee top-k.
