\subsection{Weight Extraction}

\subsubsection{DistilBERT (Flat)}

Direct extraction:

\begin{lstlisting}
W\_Q = src.q\_lin.weight  # Linear(768, 768)
W\_K = src.k\_lin.weight
W\_V = src.v\_lin.weight
W\_O = src.out\_lin.weight
\end{lstlisting}

\texttt{is\_nested\_encoder = False}. All four projections compressed.

\subsubsection{RoBERTa (Nested)}

Extract from \texttt{self}:

\begin{lstlisting}
W\_Q = src.self.query.weight
W\_K = src.self.key.weight
W\_V = src.self.value.weight
# W\_O is not extracted -- outer output.dense applies it
\end{lstlisting}

\texttt{is\_nested\_encoder = True}. During forward, \texttt{context} is returned without 
\texttt{out\_proj}; the outer \texttt{BertSelfOutput.dense} applies its projection.

\subsubsection{GPT-2 (Fused Conv1D)}

Split the fused \texttt{c\_attn} weight:

\begin{lstlisting}
fused = src.c\_attn.weight.T  # (2304, 768)
W\_Q, W\_K, W\_V = fused.chunk(3, dim=0)
W\_O = src.c\_proj.weight.T
\end{lstlisting}

Handles the HuggingFace Conv1D layout \texttt{(in, out)}.

\subsubsection{Qwen3.5 (GQA + RoPE)}

Direct extraction with GQA awareness:

\begin{lstlisting}
W\_Q = src.q\_proj.weight  # (H * d\_h, d)
W\_K = src.k\_proj.weight  # (H\_kv * d\_h, d)
W\_V = src.v\_proj.weight
W\_O = src.o\_proj.weight
\end{lstlisting}

RoPE applied after projection via \texttt{position\_embeddings}.

\subsection{The `AdaSplashLinear` Module}

\begin{lstlisting}
class AdaSplashLinear(nn.Module):
    def \_\_init\_\_(self, in\_features, out\_features, lora\_rank=16, bias=True):
        super().\_\_init\_\_()
        self.lora\_rank = min(lora\_rank, in\_features, out\_features)
        
        # Frozen base weight
        self.weight = nn.Parameter(
            torch.empty(out\_features, in\_features),
            requires\_grad=False
        )
        
        if bias:
            self.bias = nn.Parameter(
                torch.empty(out\_features),
                requires\_grad=False
            )
        
        # Trainable LoRA
        if self.lora\_rank \textgreater{} 0:
            self.lora\_B = nn.Parameter(
                torch.empty(out\_features, self.lora\_rank)
            )
            self.lora\_A = nn.Parameter(
                torch.empty(self.lora\_rank, in\_features)
            )
        
        self.reset\_parameters()
    
    def forward(self, x):
        out = F.linear(x, self.weight, self.bias)
        if self.lora\_A is not None:
            out = out + F.linear(F.linear(x, self.lora\_A), self.lora\_B)
        return out
\end{lstlisting}

\subsection{Injection Algorithm}

\textbf{Algorithm 3:} Inject AdaSplash into a model
\begin{lstlisting}
Input:  model M, config c, hyperparameters $\alpha$, W, r\_L
Output: M with attention replaced

1:  for   in transformer\_layers(M) do
2:      src $\leftarrow$ find\_attention( )
3:      if src is None: continue
4:      new $\leftarrow$ AdaSplashAttention(c, $\alpha$, W, r\_L, pretrained\_attn=src)
5:      new.copy\_weights(src)
6:      replace\_attention( , new)
7: end for
8: return M
\end{lstlisting}

\subsection{Handling Special Cases}

\subsubsection{Attention Sinks}

For causal decoders, we preserve the first $S = 4$ tokens regardless of 
splash mask:

\begin{lstlisting}
splash\_local = ((dist \textgreater{}= 0) & (dist \textless{}= W)) | (k\_idx \textless{} 4)
\end{lstlisting}

\subsubsection{GQA Expansion}

\begin{lstlisting}
if self.kv\_repeat \textgreater{} 1:
    k = repeat\_kv(k, self.kv\_repeat)
    v = repeat\_kv(v, self.kv\_repeat)
\end{lstlisting}

\subsubsection{RoPE}

\begin{lstlisting}
if position\_embeddings is not None:
    cos, sin = position\_embeddings
    q, k = apply\_rotary\_emb(q, k, cos, sin)
\end{lstlisting}

\subsubsection{Causal Masking}

\begin{lstlisting}
if is\_decoder:
    causal\_tril = torch.tril(torch.ones((L\_q, L\_k), device=device))
    logits = logits.masked\_fill(~causal\_tril, -10000)
\end{lstlisting}

\subsubsection{Combined Masking}

The causal mask and splash mask are combined:

\begin{lstlisting}
if is\_decoder and W \textgreater{} 0:
    dist = q\_idx - k\_idx
    splash = ((dist \textgreater{}= 0) & (dist \textless{}= W)) | (k\_idx \textless{} 4)
    causal\_and\_splash = splash  # already includes causality via dist \textgreater{}= 0
    logits = logits.masked\_fill(~causal\_and\_splash, -10000)
\end{lstlisting}

\subsection{Compatibility}

\subsubsection{Encoder-Decoder Models}

For T5, the same class handles encoder (bidirectional, no splash) and decoder 
(causal, splash). The \texttt{is\_decoder} flag switches behavior.

\subsubsection{LoRA Wrappers}

If the source module is a \texttt{LoRALinear}, AdaSplash unwraps to \texttt{base\_layer} and 
preserves the outer LoRA.
