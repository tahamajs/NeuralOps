\section{Introduction}

\subsection{Motivation}

Transformer attention has a well-known locality--globality trade-off. 
Local attention (sliding window, block-diagonal) is fast but misses 
long-range dependencies. Global attention (dense, low-rank, kernel-based) 
captures long-range structure but is either expensive or coarse.

\textbf{Hybrid attention} resolves this by combining multiple branches:

\[
\text{Output} = \sum\_{i} g\_i \cdot \text{Branch}\_i(X)
\tag{1.1}
\]

The branches cover different ranges and costs, and the gates determine 
how much each contributes.

\subsection{Our Approach}

\textbf{NASC} uses three branches with complementary inductive biases:

\begin{enumerate}
\item \textbf{Local window:} sliding window of size $W = 128$, with
  strict causal masking.
\item \textbf{Sparse block:} partitions the sequence into blocks of size
  $B_s = 64$ and selects the top-$k$ blocks by mean
  query-key alignment.
\item \textbf{Global spectral RFF:} random Fourier features (RFF) with cos/sin
  concatenation, computed via state accumulation for $\mathcal{O}(L)$
  cost.

\end{enumerate}
The three branches are fused by a \textbf{gate} computed from the batch-mean 
hidden state:

\[
g = \text{softmax}(W\_g \cdot \bar{x}), \quad \bar{x} = \frac{1}{L} \sum\_t x\_t
\tag{1.2}
\]

\subsection{Honest Disclosures}

Three implementation details are documented for transparency:

\textbf{The gate is batch-level.} All tokens in a batch share the same $g$. 
This is a simplification compared to per-token gating.

\textbf{\texttt{softpick} uses a batch-level fallback.} The ReLU-based attention 
sparsification falls back to standard softmax when \textbf{all} rows in a 
batch have zero denominator. Per-row fallback would be more robust.

\textbf{\texttt{inject\_nasc} raises on failure.} Unlike other modules in our framework 
(e.g., \texttt{inject\_cosformer}, \texttt{inject\_fasa}), which return \texttt{None} on failure, 
\texttt{inject\_nasc} re-raises exceptions. This is a design choice but reduces 
robustness in production.

\subsection{Contributions}

\begin{itemize}
\item \textbf{A three-branch cascade} combining local, sparse-block, and spectral-RFF
  attention.
\item \textbf{A batch-level softmax gate} over the three branches.
\item \textbf{A hardened \texttt{softpick}} with batch-level softmax fallback.
\item \textbf{An empirical evaluation} on DistilBERT, RoBERTa, and GPT-2 on SST-2.
\item \textbf{Full reproducibility} including the code paths and diagnostic logs.

\end{itemize}

\section{Related Work}

\subsection{Hybrid Attention}

\textbf{Longformer} (Beltagy et al., 2020). Combines sliding-window with global 
tokens.

\textbf{BigBird} (Zaheer et al., 2020). Sliding-window + random + global.

\textbf{Hybrid Transformer} (Zhu et al., 2021). Local attention + low-rank 
global.

\textbf{Routing Transformer} (Roy et al., 2021). Content-based clustering.

\textbf{NASC} combines three branches and uses a gate.

\subsection{Sparse Block Attention}

\textbf{BlockBERT} (Qiu et al., 2020). Block-sparse attention patterns.

\textbf{Sparse Transformers} (Child et al., 2019). Fixed sparsity patterns.

\textbf{NASC's block branch} selects blocks dynamically via mean Q/K scores.

\subsection{Random Fourier Features}

\textbf{Performer} (Choromanski et al., 2021). Positive orthogonal random features 
for softmax approximation.

\textbf{RFF in NASC} uses concatenated cos/sin features:

\[
\phi(x) = \frac{1}{\sqrt{F}} [\cos(\Omega x), \sin(\Omega x)]
\tag{2.1}
\]

where $\Omega \in \mathbb{R}^{d \times F}$ is orthogonally initialized.

\subsection{Softpick / ReLU Attention}

\textbf{ReLU attention} (Katharopoulos et al., 2020). Uses $\text{relu}(\cdot)$ as 
a kernel feature.

\textbf{Softpick} (Alman \& Song, 2024). A sparse alternative to softmax with 
reduced numerical overhead.

\textbf{NASC's \texttt{softpick}} is ReLU-based with a batch-level softmax fallback.

\section{Background}

\subsection{Standard Attention}

\[
\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V
\tag{3.1}
\]

Cost: $\mathcal{O}(L^2 d)$.

\subsection{Sliding-Window Attention}

\[
M\_{ij} = \mathbf{1}[|i - j| \leq W]
\tag{3.2}
\]

Cost: $\mathcal{O}(L W d)$.

\subsection{Sparse Block Attention}

Partition sequence into $n_b = L / B_s$ blocks. Compute block-level scores:

\[
s\_{ij} = \frac{\bar{q}\_i^\top \bar{k}\_j}{\sqrt{d}}, \quad \bar{q}\_i = \text{mean}(Q\_{\text{block } i})
\tag{3.3}
\]

Select top-$k$ blocks per query block:

\[
\mathcal{B}\_i = \text{topk}\_{k}(\{s\_{ij}\}\_j)
\tag{3.4}
\]

Then compute full attention within selected blocks.

\subsection{Random Fourier Features}

Approximate $\exp(q^\top k)$ via:

\[
\exp(q^\top k) \approx \phi(q)^\top \phi(k)
\tag{3.5}
\]

with $\phi(x) = \frac{1}{\sqrt{F}} [\cos(\Omega x), \sin(\Omega x)]$ where 
$\Omega \in \mathbb{R}^{d \times F}$ is sampled from a Gaussian.

\textbf{Cost:} $O(L F d)$ per head, linear in $L$.

\subsection{Softpick}

Softpick (Alman \& Song, 2024) replaces softmax with:

\[
\text{softpick}(x)\_i = \frac{\text{ReLU}(e^{x\_i - m} - e^{-m})}{\sum\_j \text{ReLU}(e^{x\_j - m} - e^{-m})}
\tag{3.6}
\]

where $m = \max_j x_j$.

\textbf{Issues.} When all $x_j$ are negative (masked rows), $e^{-m}$ dominates 
and the denominator can vanish. NASC handles this with a **batch-level 
fallback** to standard softmax.

\subsection{LoRA}

Standard low-rank adaptation (Hu et al., 2021).

\section{Method}

\subsection{Overview}

NASC has two paths, chosen by the flag \texttt{use\_dense}:

\begin{lstlisting}
use\_dense = is\_cross or (not self.is\_decoder and not self.enable\_cascade\_on\_encoders)
\end{lstlisting}

\begin{itemize}
\item \textbf{Cross-attention:} dense (standard softmax).
\item \textbf{Encoders:} dense by default (unless \texttt{enable\_cascade\_on\_encoders=True}).
\item \textbf{Decoders:} cascade.

\end{itemize}
The cascade path combines three branches:

\begin{lstlisting}
                    Input X
                       |
        +--------------+--------------+--------------+
        |              |              |              |
                                                      
    +------+       +------+       +------+      +------+
    |  Q   |       |  K   |       |  V   |      | Gate |
    +--+---+       +--+---+       +--+---+      +--+---+
       |              |              |              |
       +------+-------+--------------+              |
              |                      |              |
   +----------+-----------+          |              |
   |          |           |          |              |
                                                     
 +-----+   +------+  +--------+   +------+      [g ,g$_1$,g$_2$]
 |Local|   |Block |  |RFF     |   |      |       softmax
 |Win  |   |Sparse|  |Global  |   |      |       per-batch
 +--+--+   +--+---+  +---+----+   |      |
    |         |          |         |      |
    +---------+----------+---------+      |
              |                            |
                                            
        g  O\_loc + g$_1$ O\_sp + g$_2$ O\_glb
              |
               
        Output Y
\end{lstlisting}

\subsection{Local Window Branch}

Standard scaled dot-product attention with window mask:

\[
\text{scores}\_{ij} = \frac{q\_i^\top k\_j}{\sqrt{d}}
\tag{4.1}
\]

Mask:

\[
M\_{ij} = \begin{cases} 1 & |i - j| \leq W \text{ and } j \leq i \text{ (if causal)} \\ 0 & \text{otherwise} \end{cases}
\tag{4.2}
\]

Standard softmax attention within the window.

\subsection{Sparse Block Branch}

\subsubsection{Block-Level Scores}

Partition into $n_b = \lceil L / B_s \rceil$ blocks. Compute mean Q and K:

\[
\bar{q}\_i = \text{mean}(Q\_{\text{block } i}), \quad
\bar{k}\_j = \text{mean}(K\_{\text{block } j})
\tag{4.3}
\]

Block scores:

\[
s\_{ij} = \frac{\bar{q}\_i^\top \bar{k}\_j}{\sqrt{d}}
\tag{4.4}
\]

\subsubsection{Top-$k$ Selection}

For each query block $i$, select top-$k$ key blocks:

\[
\mathcal{B}\_i = \text{topk}\_{k}(\{s\_{ij}\}\_j)
\tag{4.5}
\]

\subsubsection{Causal Handling}

For causal decoders, blocks $j > i$ are masked. Also, block 0 is always 
selected (an attention sink).

\subsubsection{Attention Within Selected Blocks}

Concatenate the selected blocks' K, V, compute softpick attention:

\[
O\_{\text{sp}, i} = \text{softpick}(Q\_i K\_{\mathcal{B}\_i}^\top / \sqrt{d}) V\_{\mathcal{B}\_i}
\tag{4.6}
\]

\textbf{Implementation note.} The block loop uses a Python \texttt{for} loop over 
$n_b$ iterations, gathering selected blocks each time. For $L = 128$, 
$B_s = 32$, $n_b = 4$.

\subsection{Global Spectral RFF Branch}

\subsubsection{Feature Map}

\[
\phi(x) = \frac{1}{\sqrt{F}} [\cos(\Omega x), \sin(\Omega x)] \in \mathbb{R}^{2F}
\tag{4.7}
\]

where $\Omega \in \mathbb{R}^{d \times F}$ is orthogonally initialized.

\subsubsection{Non-Causal Path}

\[
KV = \phi(K)^\top V, \quad Z = \sum\_j \phi(K\_j)
\tag{4.8}
\]

\[
O\_{\text{glb}, i} = \frac{\phi(q\_i)^\top KV}{\phi(q\_i)^\top Z}
\tag{4.9}
\]

\subsubsection{Causal Path via Prefix Sums}

For causal decoders:

\[
KV\_c = \text{cumsum}(\phi(K) \otimes V) \in \mathbb{R}^{B \times H \times L \times 2F \times d}
\tag{4.10}
\]

\[
Z\_c = \text{cumsum}(\phi(K))
\tag{4.11}
\]

Then per-token:

\[
O\_{\text{glb}, i} = \frac{\phi(q\_i)^\top KV\_{c,i}}{\phi(q\_i)^\top Z\_{c,i} + \epsilon}
\tag{4.12}
\]

\textbf{Memory concern.} $KV_c$ is $B \times H \times L \times 2F \times d$. For 
$B = 8$, $H = 12$, $L = 128$, $F = 64$, $d = 64$: 
$8 \times 12 \times 128 \times 128 \times 64 = 8 \times 10^9$ elements.

\textbf{This is 32 GB in FP32.} In practice, PyTorch's cumsum and einsum might 
materialize this, causing OOM on RTX 4070.

\subsection{Gate}

Per-batch gate:

\[
\bar{x}\_b = \frac{1}{L} \sum\_t x\_{b,t}
\tag{4.13}
\]

\[
g = \text{softmax}(W\_g \bar{x}\_b) \in \mathbb{R}^3
\tag{4.14}
\]

where $W_g \in \mathbb{R}^{3 \times d}$.

\textbf{All tokens in a batch share the same $g$.} No per-token adaptivity.

\subsection{Fusion}

\[
O = g\_0 \cdot O\_{\text{loc}} + g\_1 \cdot O\_{\text{sp}} + g\_2 \cdot O\_{\text{glb}}
\tag{4.15}
\]

\subsection{Algorithm}

\textbf{Algorithm 1:} NASC forward
\begin{lstlisting}
Input:  X $\in$ R^{B$\times$L$\times$d}, is\_decoder, is\_cross, W, B\_s, k, F
Output: Y $\in$ R^{B$\times$L$\times$d}

 1: Q $\leftarrow$ X W\_Q; K $\leftarrow$ X W\_K; V $\leftarrow$ X W\_V
 2: if RoPE: (Q, K) $\leftarrow$ Rotary(Q, K)
 3: if GQA: (K, V) $\leftarrow$ repeat\_kv(K, V)
 4:
 5: if is\_cross or (not is\_decoder and not enable\_cascade):
 6:     # Dense path
 7:     O $\leftarrow$ softmax(Q K^T / sqrt(d)) V
 8: else:
 9:     # Cascade path
10:     g $\leftarrow$ softmax(W\_g   mean(X, dim=1))     per-batch gate
11:     O\_loc $\leftarrow$ local\_window\_attention(Q, K, V, W)
12:     O\_sp $\leftarrow$ sparse\_block\_attention(Q, K, V, B\_s, k)
13:     O\_glb $\leftarrow$ spectral\_rff\_attention(Q, K, V, F)
14:     O $\leftarrow$ g[0] O\_loc + g[1] O\_sp + g[2] O\_glb
15:
16: if head\_mask: apply
17: if is\_nested\_encoder: return O
18: else: return out\_proj(O)
\end{lstlisting}

\subsection{Common Pitfalls}

\subsubsection{RFF Causal Path Memory}

The \texttt{KV\_cumsum} tensor in \texttt{\_global\_spectral\_rff\_attention} has shape 
$(B, H, L, 2F, d)$. For $L = 128$, this is manageable. For $L = 512$, it 
may OOM.

\subsubsection{Batch-Level Gate}

The gate is computed from \texttt{hidden\_states.mean(dim=1)}, which averages over 
all tokens. This eliminates per-token adaptivity.

\subsubsection{`softpick` Batch Fallback}

The fallback triggers when \textbf{any} row has zero denominator (batch-level), 
not per-row:

\begin{lstlisting}
zero\_mask = denom \textless{}= 1e-8  # shape (B, H, L, 1)
if zero\_mask.any():
    fallback = F.softmax(x, dim=dim)
    p = torch.where(zero\_mask, fallback, p / (denom + 1e-8))
\end{lstlisting}

The \texttt{torch.where} uses per-element fallback, but the \texttt{if} only triggers 
if any element is affected. This is slightly better than fully batch-level.

\subsubsection{The `\_logged\_once` Pattern}

NASC logs the path once per instance:

\begin{lstlisting}
if not hasattr(self, '\_logged\_once'):
    logger.debug("NASCAttention: L=\%d, ...")
    self.\_logged\_once = True
\end{lstlisting}

This is a fix from previous log spam.

\end{enumerate}

\section{Discussion}

\subsection{Key Takeaways}

\subsubsection{Takeaway 1: Cascade Works for Decoders}

NASC's cascade path is used for GPT-2 and achieves +5.96\% delta.

\subsubsection{Takeaway 2: Encoder Default is Dense}

By default, DistilBERT and RoBERTa use standard attention, so NASC's 
cascade doesn't apply.

\subsubsection{Takeaway 3: Overhead is Significant}

The three-branch cascade adds ~2.3 s$\times$ latency compared to baseline.

\subsection{When to Use NASC}

\subsubsection{Recommended}

\begin{itemize}
\item \textbf{Decoder-only models} where cascade is triggered.
\item \textbf{When you need RFF global attention} with prefix-sum causality.
\item \textbf{Research baseline} for hybrid attention.

\end{itemize}
\subsubsection{Not Recommended}

\begin{itemize}
\item \textbf{Encoders} (dense path by default).
\item \textbf{Long sequences} ($L > 512$ for RFF cumsum OOM).
\item \textbf{Latency-critical} inference (~2.3 s$\times$ slower).
\item \textbf{When you need per-token adaptive gating.}

\end{itemize}

\section{Limitations}

\subsection{Encoder Default is Dense}

The \texttt{use\_dense} flag defaults to standard attention for bidirectional 
encoders. NASC's cascade path is not exercised on DistilBERT/RoBERTa 
unless explicitly enabled.

\subsection{Batch-Level Gate}

The gate is computed from the \textbf{batch-mean hidden state}, so all tokens 
in a batch share the same 3-way mixture. This eliminates per-token 
adaptivity.

\subsection{`softpick` Batch Fallback}

The fallback to softmax triggers at the \textbf{batch level} (any row triggers 
fallback for the entire batch via \texttt{torch.where}). This is a coarse fix.

\subsection{Causal RFF Memory}

The \texttt{KV\_cumsum} tensor is $(B, H, L, 2F, d)$. For $L > 512$, this exceeds 
GPU memory.

\subsection{Python Loop in Sparse Block}

The \texttt{for i in range(nb)} loop adds Python overhead. Vectorization would 
reduce latency.

\subsection{`inject\_nasc` Raises on Failure}

\begin{lstlisting}
except Exception as e:
    logger.error("inject\_nasc failed: \%s", e)
    raise e
\end{lstlisting}

This \textbf{violates the safe-injection contract} used by other modules.

\subsection{Parameter Overhead}

RFF projection ($dF$), gate ($3d$), and LoRA all add parameters.

\subsection{Inference Overhead}

NASC is slower than baseline (~2.3 s$\times$) at L=128.

\subsection{Task Coverage}

Only SST-2. Long-context (where NASC's RFF should help) is not tested.

\subsection{Model Coverage}

Only three models. Qwen3.5 untested.

\subsection{Single Seed}

No multi-seed runs.

\subsection{`\_logged\_once` Workaround}

The path logging uses a per-instance flag rather than a proper logging 
level. Minor.

\subsection{Code Quality}

\begin{itemize}
\item Sparse block Python loop
\item \texttt{softpick} fallback is coarse
\item \texttt{inject\_nasc} raises on failure
\item Some \texttt{try/except} blocks may mask errors

\end{itemize}
\subsection{What This Paper Is Not}

\begin{itemize}
\item Not a causal-decoder method for all cases
\item Not a compression method
\item Not a speedup method
\item Not a per-token adaptive gate method
\end{itemize}

\section{Conclusion}

\subsection{Summary}

We presented \textbf{NASC}, a three-branch hybrid attention that combines 
sliding-window, sparse block, and spectral RFF attention under a batch-level 
softmax gate. NASC achieves \textbf{90.48\%} on DistilBERT, \textbf{89.22\%} 
on RoBERTa, and \textbf{85.32\%} on GPT-2.

\subsection{Results Recap}

\begin{table}[H]
\centering
\small
\begin{tabular}{lllll}
\toprule
\textbf{Model} & \textbf{Path} & \textbf{Accuracy} & \textbf{$\Delta$} & \textbf{Time} \\
\midrule
DistilBERT & Dense & 90.48\% & -0.23\% & 1.42x s \\
RoBERTa & Dense & 89.22\% & +10.66\% & 2.3 s s \\
GPT-2 & \textbf{Cascade} & 85.32\% & +5.96\% & 2.3 s s \\
\bottomrule
\end{tabular}
\end{table}

\subsection{Key Takeaways}

\begin{enumerate}
\item \textbf{Three branches provide redundancy.} All three contribute.
\item \textbf{Batch-level gate is a simplification.} Per-token would be more
  adaptive.
\item \textbf{Encoder default is dense.} Cascade is decoder-only by default.
\item \textbf{Overhead is significant.} ~2.3 s$\times$ slower.
\item \textbf{RFF causal cumsum is memory-heavy.} OOM at long sequences.

\end{enumerate}
\subsection{Future Work}

\subsubsection{Short-Term}

\begin{itemize}
\item Test encoder cascade with \texttt{enable\_cascade\_on\_encoders=True}.
\item Vectorize sparse block loop.
\item Fused Triton kernel for RFF.

\end{itemize}
\subsubsection{Medium-Term}

\begin{itemize}
\item Per-token gating instead of batch-level.
\item Per-row \texttt{softpick} fallback.
\item Causal RFF without materializing cumsum.

\end{itemize}
\subsubsection{Long-Term}

\begin{itemize}
\item Scale to $L > 4096$.
\item Combine with quantization.
\item Test on Qwen3.5.

\end{itemize}
\subsection{Closing Remarks}

NASC is a \textbf{sophisticated three-branch hybrid attention}. It works 
correctly on decoders and provides a cascade path for long-context 
scenarios. Its limitations -- batch-level gate, RFF memory, and Python loop 
overhead -- are implementation constraints, not fundamental. Future work 
should address these to unlock NASC's full potential.

\section{Appendix A. Mathematical Derivations}

\subsection{A.1 Local Window Attention}

\[
O\_{\text{loc}, i} = \frac{\sum\_{j: |i - j| \leq W, j \leq i} \exp(q\_i^\top k\_j / \sqrt{d}) v\_j}{\sum\_{j} \exp(q\_i^\top k\_j / \sqrt{d})}
\tag{A.1}
\]

Standard softmax over the window.

\subsection{A.2 Sparse Block Scores}

For blocks $i, j$:

\[
s\_{ij} = \frac{\bar{q}\_i^\top \bar{k}\_j}{\sqrt{d}}, \quad
\bar{q}\_i = \frac{1}{B\_s} \sum\_{t \in \text{block}\_i} q\_t
\tag{A.2}
\]

Selection:

\[
\mathcal{B}\_i = \text{topk}\_{k}\{s\_{ij}\}\_j, \quad
O\_{\text{sp}, i} = \text{softpick}(Q\_i K\_{\mathcal{B}\_i}^\top / \sqrt{d}) V\_{\mathcal{B}\_i}
\tag{A.3}
\]

\subsection{A.3 RFF Feature Map}

\[
\phi(x) = \frac{1}{\sqrt{F}} [\cos(\Omega x), \sin(\Omega x)]
\tag{A.4}
\]

$\phi(x) \in \mathbb{R}^{2F}$.

\textbf{Approximation.}

\[
\phi(q)^\top \phi(k) = \frac{1}{F} [\cos(\Omega q)^\top \cos(\Omega k) + \sin(\Omega q)^\top \sin(\Omega k)]
\tag{A.5}
\]

For $\Omega$ with orthogonal rows, this approximates $\exp(q^\top k)$.

\subsection{A.4 Causal RFF via Cumsum}

For causal decoder:

\[
(KV\_c)\_i = \sum\_{j \leq i} \phi(k\_j) v\_j^\top
\tag{A.6}
\]

\[
(Z\_c)\_i = \sum\_{j \leq i} \phi(k\_j)
\tag{A.7}
\]

Computed via \texttt{cumsum} along sequence dimension.

\[
O\_{\text{glb}, i} = \frac{\phi(q\_i)^\top (KV\_c)\_i}{\phi(q\_i)^\top (Z\_c)\_i + \epsilon}
\tag{A.8}
\]

\subsection{A.5 Gate Computation}

\[
g = \text{softmax}(W\_g \bar{x}), \quad
\bar{x} = \frac{1}{L} \sum\_{t=1}^{L} x\_t, \quad
W\_g \in \mathbb{R}^{3 \times d}
\tag{A.9}
\]

\subsection{A.6 Fusion}

\[
O = g\_0 O\_{\text{loc}} + g\_1 O\_{\text{sp}} + g\_2 O\_{\text{glb}}
\tag{A.10}
\]

\subsection{A.7 Softpick with Fallback}

\[
p\_i = \text{ReLU}(e^{x\_i - m} - e^{-m})
\tag{A.11}
\]

where $m = \max_j x_j$ (clamped to $0$ if $m < -10^3$).

\[
\hat{p}\_i = \begin{cases} p\_i / \sum\_j p\_j & \text{if } \sum\_j p\_j \textgreater{} \epsilon \\ \text{softmax}(x)\_i & \text{otherwise} \end{cases}
\tag{A.12}
\]

\textbf{Batch-level fallback.} The \texttt{torch.where} is applied element-wise, but 
the fallback is broadcast to all elements where \texttt{zero\_mask} is True.

\subsection{A.8 Complexity}

\begin{table}[H]
\centering
\small
\begin{tabular}{ll}
\toprule
\textbf{Branch} & \textbf{FLOPs} \\
\midrule
Local window & $B H L W d$ \\
Sparse block & $B H L k B_s d$ \\
RFF & $B H L F d$ \\
Gate & $B L d$ \\

\section{Appendix B. Implementation Details}

\subsection{B.1 The `softpick` Function}

\begin{lstlisting}
def softpick(x, dim=-1, temperature=1.0):
    orig\_dtype = x.dtype
    x = x.float()
    m = x.max(dim=dim, keepdim=True).values
    m = torch.where(m \textless{} -1e3, torch.zeros\_like(m), m)  # clamp for masked rows
    z = x - m
    exp\_z = torch.exp(z / temperature)
    exp\_neg\_m = torch.exp((-m) / temperature).clamp(max=1e4)
    p = F.relu(exp\_z - exp\_neg\_m)
    denom = p.sum(dim=dim, keepdim=True)
    zero\_mask = denom \textless{}= 1e-8
    if zero\_mask.any():
        fallback = F.softmax(x, dim=dim)
        p = torch.where(zero\_mask, fallback, p / (denom + 1e-8))
    else:
        p = p / denom
    return p.to(orig\_dtype)
\end{lstlisting}

\textbf{Note.} The clamp \texttt{max=1e4} on \texttt{exp\_neg\_m} prevents overflow. The 
\texttt{zero\_mask.any()} triggers fallback for the batch.

\subsection{B.2 Local Window Attention}

\begin{lstlisting}
def \_local\_window\_attention(self, Q, K, V, valid\_mask, is\_causal):
    B, H, L, d = Q.shape
    scale = 1.0 / math.sqrt(d)
    scores = torch.matmul(Q.float(), K.float().transpose(-2, -1)) * scale
    
    idx = torch.arange(L, device=Q.device)
    dist = (idx.unsqueeze(0) - idx.unsqueeze(1)).abs()
    mask = dist \textgreater{} self.window\_size
    if is\_causal:
        mask = mask | (idx.unsqueeze(0) \textgreater{} idx.unsqueeze(1))
    scores = scores.masked\_fill(mask.unsqueeze(0).unsqueeze(0), -10000.0)
    
    pad\_k = (~valid\_mask).unsqueeze(1).unsqueeze(2)
    scores = scores.masked\_fill(pad\_k, -10000.0)
    scores = torch.nan\_to\_num(scores, nan=-1e4, posinf=1e4, neginf=-1e4)
    
    attn = F.softmax(scores, dim=-1).to(Q.dtype)
    attn = self.dropout(attn)
    return torch.matmul(attn, V)
\end{lstlisting}

\subsection{B.3 Sparse Block Attention (Python Loop)}

\begin{lstlisting}
def \_sparse\_block\_attention(self, Q, K, V, valid\_mask, is\_causal):
    # ... pad to multiple of block\_size
    nb = Lp // self.block\_size
    
    # Compute block-level scores
    Q\_mean = Qb.mean(dim=3)
    K\_mean = Kb.mean(dim=3)
    blk\_scores = torch.matmul(Q\_mean.float(), K\_mean.float().transpose(-2, -1)) * scale
    
    if is\_causal:
        blk\_scores = blk\_scores + causal\_blk\_mask
    
    top\_k = min(self.top\_k, nb)
    \_, top\_idx = blk\_scores.topk(top\_k, dim=-1)
    if is\_causal:
        for i in range(nb):
            top\_idx[:, :, i, 0] = i
    else:
        top\_idx[:, :, :, 0] = 0
    
    out\_blocks = torch.zeros\_like(Qb)
    for i in range(nb):  # $\leftarrow$ PYTHON LOOP
        idx = top\_idx[:, :, i, :]
        idx\_exp = idx.unsqueeze(-1).unsqueeze(-1).expand(-1, -1, -1, self.block\_size, d)
        K\_sel = torch.gather(Kb, 2, idx\_exp).reshape(B, H, top\_k * self.block\_size, d)
        V\_sel = torch.gather(Vb, 2, idx\_exp).reshape(B, H, top\_k * self.block\_size, d)
        
        scores\_i = torch.matmul(Qb[:, :, i].float(), K\_sel.float().transpose(-2, -1)) * scale
        
        # Causal mask for selected tokens
        # ... 
        
        attn\_i = softpick(scores\_i, dim=-1).to(Q.dtype)
        out\_blocks[:, :, i] = torch.matmul(attn\_i, V\_sel)
    
    return out\_blocks.view(B, H, Lp, d)[:, :, :L, :]
\end{lstlisting}

\subsection{B.4 Global Spectral RFF}

\begin{lstlisting}
def \_global\_spectral\_rff\_attention(self, Q, K, V, valid\_mask, is\_causal):
    B, H, L, d = Q.shape
    pad = (~valid\_mask).unsqueeze(1).unsqueeze(-1)
    
    Qf = torch.matmul(Q.float(), self.rff\_proj.float())
    Kf = torch.matmul(K.float(), self.rff\_proj.float())
    norm = 1.0 / math.sqrt(self.rff\_features)
    phi\_Q = torch.cat([torch.cos(Qf), torch.sin(Qf)], dim=-1) * norm
    phi\_K = torch.cat([torch.cos(Kf), torch.sin(Kf)], dim=-1) * norm
    
    phi\_K = phi\_K.masked\_fill(pad, 0.0)
    V\_masked = V.float().masked\_fill(pad, 0.0)
    
    if is\_causal:
        KV = phi\_K.unsqueeze(-1) * V\_masked.unsqueeze(-2)  # [B, H, L, 2F, d]
        KV\_cumsum = torch.cumsum(KV, dim=2)
        num = torch.matmul(phi\_Q.unsqueeze(-2), KV\_cumsum).squeeze(-2)
        Z = torch.cumsum(phi\_K, dim=2)
        den = (phi\_Q * Z).sum(dim=-1, keepdim=True) + 1e-5
        return (num / den).to(Q.dtype)
    else:
        KV = torch.matmul(phi\_K.transpose(-2, -1), V\_masked)
        Z = phi\_K.sum(dim=-2, keepdim=True)
        num = torch.matmul(phi\_Q, KV)
        den = torch.matmul(phi\_Q, Z.transpose(-2, -1)) + 1e-5
        return (num / den).to(Q.dtype)
\end{lstlisting}

\textbf{The \texttt{KV} tensor is the memory bottleneck} for causal path.

\subsection{B.6 Common Pitfalls}

\subsubsection{B.6.1 Encoder Default}

Without setting \texttt{enable\_cascade\_on\_encoders=True}, encoders use dense.

\subsubsection{B.6.2 `softpick` Fallback}

The fallback is batch-level. If any row has zero denom, the whole batch 
uses softmax for that row (via \texttt{torch.where}), but the trigger is 
batch-wide.

\subsubsection{B.6.3 RFF Cumsum}

The \texttt{KV\_cumsum} tensor can be large. Consider fused kernel for long 
sequences.

\subsubsection{B.6.4 Python Loop in Sparse Block}

The \texttt{for i in range(nb)} loop is not vectorized. For small nb it's fine.

\subsubsection{B.6.5 `inject\_nasc` Raises}

Unlike \texttt{inject\_cosformer} or \texttt{inject\_fasa}, this raises. Handle with 
try/except in production.

\subsection{D.4 Sparse Block Overhead}

The Python loop in \texttt{\_sparse\_block\_attention} adds 4 kernel launches 
(for $L = 128$, $B_s = 32$). Each launch has ~5-10  s overhead.

\subsection{D.5 `softpick` Fallback Coarseness}

The fallback triggers if \textbf{any} row has zero denominator, but the 
\texttt{torch.where} is element-wise. This means:
\begin{itemize}
\item If one row in a batch has zero denom, softmax fallback applies only to
  that row (via torch.where).
\item But the \texttt{if zero\_mask.any()} is computed over the whole batch.

\end{itemize}
\subsection{D.6 `inject\_nasc` Raises}

Unlike other modules, \texttt{inject\_nasc} raises on failure. This breaks the 
"safe injection" contract.

\textbf{Suggested fix:}

\begin{lstlisting}
except Exception as e:
    logger.error("inject\_nasc failed: \%s", e)
    return None  # instead of raise
\end{lstlisting}

\subsection{D.8 Lessons Learned}

\begin{enumerate}
\item \textbf{Three branches provide redundancy.} Removing any hurts.
\item \textbf{Batch-level gate is a simplification.} Per-token might help but
  wasn't tested.
\item \textbf{RFF memory is a constraint.} Fused kernel needed for long sequences.
\item \textbf{Robustness regression.} \texttt{inject\_nasc} should return None.

\end{enumerate}
\subsection{D.9 Recommendations}

\begin{enumerate}
\item \textbf{Test encoder cascade} with \texttt{enable\_cascade\_on\_encoders=True}.
\item \textbf{Vectorize sparse block loop.}
\item \textbf{Fused Triton kernel} for RFF.
\item \textbf{Fix \texttt{inject\_nasc}} to return None.
\item \textbf{Per-token gating} as a future extension.
\end{enumerate}
