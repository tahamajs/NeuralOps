\subsection{Weight Transfer}

Linformer copies base weights via \texttt{copy\_weights}, handling four patterns:

\subsubsection{GPT-2 Conv1D}

\begin{lstlisting}
c\_w = src.c\_attn.weight.t()
q\_w, k\_w, v\_w = c\_w.chunk(3, dim=0)
\end{lstlisting}

\subsubsection{RoBERTa Nested}

\begin{lstlisting}
q\_w = src.self.query.weight
k\_w = src.self.key.weight
v\_w = src.self.value.weight
o\_w = src.output.dense.weight
\end{lstlisting}

\subsubsection{Qwen (GQA)}

\begin{lstlisting}
q\_w = src.q\_proj.weight  # (H d\_h, d)
k\_w = src.k\_proj.weight  # (H\_kv d\_h, d)
v\_w = src.v\_proj.weight
o\_w = src.o\_proj.weight
\end{lstlisting}

\subsubsection{DistilBERT}

\begin{lstlisting}
q\_w = src.q\_lin.weight
k\_w = src.k\_lin.weight
v\_w = src.v\_lin.weight
o\_w = src.out\_lin.weight
\end{lstlisting}

\subsection{The E, F Matrices}

\begin{lstlisting}
self.E = nn.Parameter(torch.empty(self.k\_proj\_dim, self.max\_seq\_len))
self.F = nn.Parameter(torch.empty(self.k\_proj\_dim, self.max\_seq\_len))

with torch.no\_grad():
    nn.init.normal\_(self.E, std=0.02)
    nn.init.normal\_(self.F, std=0.02)
    min\_dim = min(self.k\_proj\_dim, self.max\_seq\_len)
    self.E.data[:min\_dim, :min\_dim].fill\_diagonal\_(1.0)
    self.F.data[:min\_dim, :min\_dim].fill\_diagonal\_(1.0)
\end{lstlisting}

\textbf{Why diagonal init?} Without it, $E K \approx 0$ and the model starts 
broken. With diagonal init, the initial projection $\approx$ identity.

\subsection{Nested Encoder Bypass}

For RoBERTa, we set \texttt{is\_nested\_encoder = True}. Our forward returns raw 
context, and the outer \texttt{BertSelfOutput.dense} applies the output projection:

\begin{lstlisting}
if self.is\_nested\_encoder:
    out = context * self.output\_scale
else:
    out = self.out\_proj(context * self.output\_scale)
\end{lstlisting}

\subsection{RoPE Handling}

Captured from source attention:

\begin{lstlisting}
if hasattr(src, "rotary\_emb"):
    self.rotary\_emb = src.rotary\_emb
\end{lstlisting}

Applied before projection:

\begin{lstlisting}
if pos\_emb is not None:
    q, k = apply\_rotary\_pos\_emb(q, k, cos, sin)
\end{lstlisting}

\textbf{Order matters:} RoPE $\to$ Linformer projection. Reverse order would corrupt 
position information.

\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject Linformer into a model
\begin{lstlisting}
Input:  model M, k, L\_max
Output: M with attention replaced

1: for   in transformer\_layers(M) do
2:     src $\leftarrow$ get\_attention( )
3:     new $\leftarrow$ LinformerAttention(cfg, k, L\_max, old\_attn=src)
4:     replace( , new)
5: end for
6: return M
\end{lstlisting}

\begin{table}[H]

\small

\toprule

\midrule

$L > L_\text{max}$ & Shape mismatch & Interpolate $E, F$ \\
Decoder $L > k$ & \texttt{is\_decoder and L \textgreater{} k} & Fallback to dense \\
