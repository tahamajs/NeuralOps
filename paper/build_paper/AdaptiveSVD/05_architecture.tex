\subsection{Weight Extraction}

\subsubsection{DistilBERT (Flat)}

Direct extraction:

\begin{lstlisting}
W_Q = src.q_lin.weight  # Linear(768, 768)
W_K = src.k_lin.weight
W_V = src.v_lin.weight
W_O = src.out_lin.weight
\end{lstlisting}

All four projections are inside \texttt{MultiHeadSelfAttention}. \texttt{is\_nested\_encoder = False}.

\subsubsection{RoBERTa (Nested)}

Extract from inner \texttt{BertSelfAttention}:

\begin{lstlisting}
W_Q = src.self.query.weight
W_K = src.self.key.weight
W_V = src.self.value.weight
# W_O is not extracted -- outer BertSelfOutput.dense applies it
\end{lstlisting}

\texttt{is\_nested\_encoder = True}. During forward, the compressed \texttt{context} is 
returned without applying \texttt{out\_proj}; the outer \texttt{BertSelfOutput.dense} 
applies its own (unchanged) projection.

\textbf{Consequence.} In RoBERTa, the output projection $W_O$ is \textbf{not compressed}, 
only $W_Q, W_K, W_V$.

\subsubsection{GPT-2 (Fused Conv1D)}

GPT-2 fuses Q, K, V into a single \texttt{c\_attn} Conv1D:

\begin{lstlisting}
fused = src.c_attn.weight.T  # (3*768, 768) after transpose
W_Q, W_K, W_V = fused.chunk(3, dim=0)
W_O = src.c_proj.weight.T
\end{lstlisting}

The transpose handles the HuggingFace Conv1D layout: it stores weights as 
\texttt{(in\_features, out\_features)} instead of the standard \texttt{(out\_features, in\_features)}.

\subsubsection{T5 (Relative Attention Bias)}

T5 uses \texttt{relative\_attention\_bias} (an \texttt{nn.Embedding}) instead of learned 
position embeddings:

\begin{lstlisting}
self.relative_attention_bias = src.relative_attention_bias
self.has_relative_attention_bias = True
\end{lstlisting}

The bias is preserved as a separate module and added to attention scores 
in forward. The bucket function handles bidirectional (encoder) and causal 
(decoder) modes.

\subsubsection{Qwen3.5 (GQA + RoPE)}

Qwen3.5 uses GQA with $H_{kv} < H$:

\begin{lstlisting}
W_Q = src.q_proj.weight  # (H * d_h, d) = (2048, 1024)
W_K = src.k_proj.weight  # (H_kv * d_h, d) = (512, 1024)
W_V = src.v_proj.weight  # (512, 1024)
W_O = src.o_proj.weight  # (1024, 2048)
\end{lstlisting}

RoPE is applied after projection:

\begin{lstlisting}
Q, K = apply_rotary_pos_emb(Q, K, cos, sin)
\end{lstlisting}

\subsection{The `AdaptiveSVDLinear` Module}

\begin{lstlisting}
class AdaptiveSVDLinear(nn.Module):
    def __init__(self, in_features, out_features, svd_rank, residual_rank=16, ...):
        super().__init__()
        self.svd_rank = min(svd_rank, in_features, out_features)
        self.residual_rank = min(residual_rank, in_features, out_features)
        
        # Frozen SVD base
        self.U = nn.Parameter(
            torch.empty(out_features, self.svd_rank),
            requires_grad=False
        )
        self.V = nn.Parameter(
            torch.empty(self.svd_rank, in_features),
            requires_grad=False
        )
        
        # Trainable residual
        if self.residual_rank > 0:
            self.lora_B = nn.Parameter(
                torch.empty(out_features, self.residual_rank)
            )
            self.lora_A = nn.Parameter(
                torch.empty(self.residual_rank, in_features)
            )
        
        if bias:
            self.bias = nn.Parameter(torch.empty(out_features))
        
        self.reset_parameters()
    
    def forward(self, x):
        Vx = F.linear(x, self.V)
        out = F.linear(Vx, self.U)
        if self.lora_A is not None:
            Ax = F.linear(x, self.lora_A)
            out = out + F.linear(Ax, self.lora_B)
        if self.bias is not None:
            out = out + self.bias
        return out
\end{lstlisting}

\textbf{Parameter count:} $r_P(d_\text{in} + d_\text{out}) + r_L(d_\text{in} + d_\text{out}) + d_\text{out}$.

\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject Adaptive SVD into a full model
\begin{lstlisting}
Input:  model M, config c, hyperparameters $\tau$, r_L
Output: M with attention replaced

1:  for   in transformer_layers(M) do
2:      src $\leftarrow$ find_attention( )                     Old attention
3:      if src is None: continue
4:      new $\leftarrow$ AdaptiveSVDAttention(c, $\tau$, r_L, pretrained_attn=src)
5:      new.copy_weights(src)                        SVD + adapter
6:      replace_attention( , new)
7: end for
8: return M
\end{lstlisting}

\subsection{Handling Special Cases}

\subsubsection{T5 Relative Attention Bias}

Forward:

\begin{lstlisting}
position_bias = kwargs.get("position_bias", None)
if position_bias is None and self.has_relative_attention_bias:
    position_bias = self.compute_bias(N_q, N_k, device=hidden_states.device)
\end{lstlisting}

The \texttt{compute\_bias} function uses \texttt{\_relative\_position\_bucket} to map relative 
positions to buckets, then looks up the bias embedding.

\subsubsection{GQA Expansion}

\begin{lstlisting}
if self.kv_repeat > 1:
    K = repeat_kv(K, self.kv_repeat)
    V = repeat_kv(V, self.kv_repeat)
\end{lstlisting}

\begin{lstlisting}
if position_embeddings is not None:

\end{lstlisting}

\subsection{Compatibility}

\subsubsection{LoRA Wrappers}

If the source module is a \texttt{LoRALinear} wrapper, Adaptive SVD extracts the 
inner \texttt{base\_layer} for SVD and preserves the outer LoRA parameters:

\begin{lstlisting}
target_mod = getattr(module, "base_layer", module)
\end{lstlisting}

\subsubsection{Encoder-Decoder}

For T5, the same \texttt{AdaptiveSVDAttention} is used in both encoder and decoder 
blocks. The decoder side has \texttt{is\_decoder = True}, which enables causal masking.
