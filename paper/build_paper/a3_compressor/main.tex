\begin{abstract}
Low-rank factorization is a classical approach to compressing the linear layers 
of transformer models, replacing each weight matrix $W \in \mathbb{R}^{d_\text{out} \times d_\text{in}}$ 
with a product $U V$ where $U \in \mathbb{R}^{d_\text{out} \times r}$, 
$V \in \mathbb{R}^{r \times d_\text{in}}$, and $r \ll \min(d_\text{in}, d_\text{out})$. 
Standard SVD applies this factorization uniformly across all input dimensions, 
ignoring the fact that transformer activations have highly non-uniform variance 
across channels. We introduce \textbf{A3} (\textbf{A}ctivation-\textbf{A}ware \textbf{A}daptive 
factorization), which addresses this by (i) collecting a streaming empirical 
Fisher diagonal during calibration, (ii) weighting the SVD input space by this 
energy estimate before factorization, (iii) adaptively increasing rank when 
reconstruction error exceeds a threshold, and (iv) recalibrating LayerNorm 
affine parameters after factorization to absorb distributional shift.

A3 achieves guaranteed parameter reduction without expansion (+1.25M parameters saved on DistilBERT, 
+0.59M on RoBERTa, +0.53M on GPT-2) under an enforced rank ceiling $r_{\mathrm{ceiling}} \le 256$. 
On SST-2, A3 preserves 90.02\% validation accuracy on DistilBERT ($\Delta -0.69\%$, F1: 0.9043) and 
achieves 83.26\% on RoBERTa ($\Delta +4.70\%$, F1: 0.8460), passing quality gates on DistilBERT and RoBERTa, 
while GPT-2 shows significant degradation (-16.17\%, 63.19\% accuracy, F1: 0.7216) that requires further investigation. 
We additionally evaluate on MNLI and AG News, finding that A3 requires task-specific base checkpoints to achieve meaningful accuracy on multi-class tasks. 
We provide an open-source, fully reproducible implementation with strict Frobenius-norm validation, 
zero-overhead CPU FP32 SVD factorization, and automated Hugging Face hub integration.

\textbf{Keywords:} low-rank factorization, activation-aware compression, Fisher 
information, LayerNorm recalibration, transformer efficiency
\end{abstract}
