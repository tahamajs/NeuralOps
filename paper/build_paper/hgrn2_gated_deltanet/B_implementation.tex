\subsection{B.2 The Gate Initialization}

\begin{lstlisting}
with torch.no\_grad():
    self.gate.weight.zero\_()
    self.gate.bias.fill\_(0.0)
\end{lstlisting}

\textbf{Why?} Initializing to zero gives $\gamma = 0.5$, which is a neutral 
starting point. Random initialization would cause one branch to dominate 
arbitrarily.

\subsection{B.3 Failure-Bias}

\begin{lstlisting}
if hgrn\_ok and not deltanet\_ok:
    with torch.no\_grad():
        self.gate.weight.zero\_()
        self.gate.bias.fill\_(4.0)  # sigmoid(4) $\approx$ 0.98
\end{lstlisting}

When one branch's weight copy fails, we bias the gate toward the surviving 
branch. This prevents the failed branch from injecting random noise.

\subsection{B.4 The `sub\_kwargs` Pattern}

\begin{lstlisting}
sub\_kwargs = {k: v for k, v in kwargs.items() 
              if k not in ("is\_decoder", "is\_causal", "lora\_rank", "lora\_alpha")}
\end{lstlisting}

This is essential to avoid the "multiple values for keyword argument" error 
when the same \texttt{kwargs} dict is passed to nested constructors.

\subsection{B.5 Output Projection Search}

\begin{lstlisting}
if w\_o is None:
    for cand in ("out\_proj", "out\_lin", "o\_proj", "output", "proj", "c\_proj", "dense"):
        for target in (old\_attn, old\_attn.self, old\_attn.attention, old\_attn.output):
            if target and hasattr(target, cand):
                mod = getattr(target, cand)
                if hasattr(mod, "dense"):
                    mod = mod.dense
                cw, cb = \_unpack\_weight\_bias(mod)
                if cw is not None:
                    w\_o, b\_o = cw, cb
                    break
\end{lstlisting}

This search handles:
\begin{itemize}
\item DistilBERT: \texttt{out\_lin}
\item RoBERTa: \texttt{output.dense}
\item GPT-2: \texttt{c\_proj}
\item Qwen: \texttt{o\_proj}

\end{itemize}
\subsection{B.6 Double-Injection Guard}

\begin{lstlisting}
if isinstance(curr\_attn, HGRN2GatedDeltaNet): return None
if "HGRN2GatedDeltaNet" in curr\_attn.\_\_class\_\_.\_\_name\_\_: return None
if hasattr(curr\_attn, "inner") and isinstance(curr\_attn.inner, HGRN2GatedDeltaNet): return None
if hasattr(curr\_attn, "\_wrapped\_attention") and isinstance(curr\_attn.\_wrapped\_attention, HGRN2GatedDeltaNet): return None
\end{lstlisting}

Four checks cover:
\begin{itemize}
\item Direct instance.
\item Class name match.
\item Wrapped inside \texttt{inner}.
\item Wrapped inside \texttt{\_wrapped\_attention}.

\end{itemize}
\subsection{B.7 Skip Hybrid Layers}

\begin{lstlisting}
if "DeltaNet" in c\_name or "LinearAttention" in c\_name:
    return None
\end{lstlisting}

Qwen3.5 has some layers using \texttt{DeltaNet} or \texttt{LinearAttention}. We skip them 
to avoid double-replacing recurrent modules.

\subsection{B.9 Forward Pass}

\begin{lstlisting}
def forward(self, hidden\_states, attention\_mask=None, **kwargs):
    # 1. Branch forwards
    hgrn\_out = self.hgrn(hidden\_states, attention\_mask=attention\_mask, **kwargs)[0]
    delta\_out = self.deltanet(hidden\_states, attention\_mask=attention\_mask, **kwargs)[0]
    
    # 2. Shape align
    if hgrn\_out.shape != delta\_out.shape:
        # pad
        ...
    
    # 3. Gate + fuse
    gamma = torch.sigmoid(self.gate(hidden\_states))
    fused = gamma * hgrn\_out + (1 - gamma) * delta\_out
    
    # 4. Output
    out = self.out\_proj(fused)
    
    return out, None
\end{lstlisting}

\subsection{B.10 Common Pitfalls}

\subsubsection{B.10.1 Forgetting `sub\_kwargs`}

Passing the raw \texttt{kwargs} to branch constructors raises \texttt{TypeError}.

\subsubsection{B.10.2 Random Gate Init}

Initializing \texttt{gate.weight} with default Kaiming gives arbitrary bias.

\subsubsection{B.10.3 Missing Out Projection Failure}

Raising on out\_proj failure is essential -- otherwise the module has a 
random output projection.

\subsubsection{B.10.4 Double Injection}
