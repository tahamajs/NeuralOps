\section{Reproducibility Statement}
All code, model weights, and benchmark evaluation scripts are packaged to guarantee exact reproducibility:
\begin{lstlisting}[language=bash]
# 1. Run unified compression sweep
python -u Codes/framework/run\_compressor.py \
    --model distilbert-base-uncased \
    --compressor huffman\_coder \
    --dataset sst2 \
    --batch\_size 64 \
    --recovery\_steps 50 \
    --output\_dir results/unified\_huffman\_coder

# 2. Run multi-model verification suite
python -u scripts/run\_all\_4\_huffman\_coder.py \
    --models distilbert,roberta,gpt2 \
    --recovery\_steps 50
\end{lstlisting}
