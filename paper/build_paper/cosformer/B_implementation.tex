\subsection{B.2 Cos/Sin Reweighting}

\begin{lstlisting}
def \_get\_cos\_sin\_weights(self, seq\_len, device, dtype):
    pos = torch.arange(seq\_len, device=device, dtype=torch.float32)
    m = max(self.max\_seq\_len, seq\_len)
    angles = (math.pi / (2.0 * m)) * pos
    cos\_weight = torch.cos(angles).view(1, 1, seq\_len, 1).to(dtype=dtype)
    sin\_weight = torch.sin(angles).view(1, 1, seq\_len, 1).to(dtype=dtype)
    return cos\_weight, sin\_weight
\end{lstlisting}

The weights are recomputed per forward. For fixed $L$, this is wasteful 
but correct.

\subsection{B.6 Common Pitfalls}

\subsubsection{B.6.1 Forgetting V Masking}

Masking K but not V means padding tokens contribute to the state via the 
$KV$ matmul. \textbf{Always mask both.}

\subsubsection{B.6.2 Wrong RoPE Extraction}

Triple-nested try/except is fragile. Log which signature succeeded.

\subsubsection{B.6.3 The Dead `tau` Parameter}

\texttt{self.tau} is declared but unused. Remove or implement.

\subsubsection{B.6.4 Cos/Sin Recomputation}

Recomputing cos/sin every forward is wasteful. Cache if sequence length 
is fixed.
