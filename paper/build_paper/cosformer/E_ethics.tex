
\section{Appendix E. Ethical Considerations}

\subsection{E.1 Broader Impact}

\subsubsection{E.1.1 Positive}

\begin{itemize}
\item \textbf{Linear attention} reduces memory for long sequences.
\item \textbf{Port to pretrained models} enables reuse without retraining.
\item \textbf{Reproducibility} -- full code, weights, and metrics released.

\end{itemize}
\subsubsection{E.1.2 Negative}

\begin{itemize}
\item \textbf{Marginal speedup} on short sequences.
\item \textbf{RoBERTa instability} could mislead practitioners.

\end{itemize}
\subsection{E.2 Environmental Impact}

\begin{itemize}
\item \textbf{GPU-hours:} ~4
\item \textbf{CO$_2$:} ~0.4 kg

\end{itemize}
\subsection{E.3 Data Ethics}

\begin{itemize}
\item SST-2 public dataset.
\item No PII.

\end{itemize}
\subsection{E.4 LLM Usage Disclosure}

reviewed by authors.

\subsection{E.5 Conflicts of Interest}

None.

\subsection{E.6 Long-Term Considerations}

Linear attention is important for long-context deployment. Cosformer is one 
of the better variants. We hope this work contributes to a broader 
understanding of when linear attention works and when it doesn't.
