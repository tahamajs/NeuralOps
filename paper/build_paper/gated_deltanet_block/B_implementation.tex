
\section{Appendix B. Implementation Details}

\subsection{B.1 The `try/except` Pattern}

\begin{lstlisting}
try:
    adapter = UniversalAdapter()
    w\_q, b\_q = adapter.get\_weight\_bias(old\_attn, "q")
    ...
    qkv\_w = torch.cat([w\_q, w\_k, w\_v], dim=0)
    if qkv\_w.shape == self.attn.in\_proj\_weight.shape:
        self.attn.in\_proj\_weight.copy\_(qkv\_w)
    ...
except (AttributeError, KeyError, RuntimeError, TypeError, ValueError):
    pass
\end{lstlisting}

\textbf{Problems:}
\begin{enumerate}
\item Catches 5 exception types
\item Silently continues on failure
\item No logging
\item No verification

\end{enumerate}
\textbf{Fix:}

\begin{lstlisting}
try:
    ...
except Exception as e:
    logger.warning(f"Weight transfer failed: {e}")
    raise  # $\leftarrow$ do not swallow
\end{lstlisting}

\subsection{B.2 The Nested Encoder Path}

\begin{lstlisting}
if self.is\_nested\_encoder:
    return delta\_out, None  # $\leftarrow$ no LN, no residual
\end{lstlisting}

For RoBERTa, this returns raw context. The outer \texttt{BertSelfOutput} applies 
residual + LN.

\textbf{Verification:}

\begin{lstlisting}
# Check that self.norm is not used
def forward(self, x):
    if self.is\_nested\_encoder:
        assert not hasattr(self, '\_norm\_used')  # should not be touched
        return delta\_out, None
\end{lstlisting}

\subsection{B.3 Causal Masking for GPT-2}

The \texttt{use\_full\_attention=True} path does not pass \texttt{attn\_mask}:

\begin{lstlisting}
attn\_out, attn\_weights = self.attn(
    x, x, x, key\_padding\_mask=key\_padding\_mask, need\_weights=output\_attentions
)
\end{lstlisting}

\textbf{Fix for GPT-2:}

\begin{lstlisting}
if self.is\_decoder:
    seq\_len = x.shape[1]
    causal\_mask = torch.triu(
        torch.full((seq\_len, seq\_len), float('-inf'), device=x.device),
        diagonal=1
    )
    attn\_out, \_ = self.attn(x, x, x, attn\_mask=causal\_mask)
\end{lstlisting}

\subsection{B.4 Shape Padding Logic}

\begin{lstlisting}
if attn\_out.shape[-1] != x.shape[-1]:
    attn\_out = F.pad(attn\_out, (0, x.shape[-1] - attn\_out.shape[-1])) \
               if attn\_out.shape[-1] \textless{} x.shape[-1] \
               else attn\_out[..., :x.shape[-1]]
\end{lstlisting}

\textbf{Concern.} If shapes mismatch, this silently pads/truncates. \textbf{Should} 
instead be an assertion error -- shape mismatch indicates a bug.

\subsection{B.5 Weight Transfer Logging}

Add explicit logging:

\begin{lstlisting}
import logging
logger = logging.getLogger(\_\_name\_\_)

# After weight transfer:
qkv\_w = torch.cat([w\_q, w\_k, w\_v], dim=0)
if qkv\_w.shape == self.attn.in\_proj\_weight.shape:
    self.attn.in\_proj\_weight.copy\_(qkv\_w)
    logger.info(f"Q/K/V transfer OK: {qkv\_w.shape}")
else:
    logger.error(f"Q/K/V shape mismatch: {qkv\_w.shape} vs {self.attn.in\_proj\_weight.shape}")
\end{lstlisting}

\subsection{B.6 Common Pitfalls}

\subsubsection{B.6.1 `UniversalAdapter` Returns None}

If \texttt{get\_weight\_bias} returns \texttt{None}, \texttt{torch.cat([None, None, None])} raises. 
But \texttt{try/except} masks it.

\subsubsection{B.6.2 Nested Encoder Detection}

\texttt{is\_nested\_encoder} must be set correctly. For DistilBERT, \texttt{False}. For 
RoBERTa, \texttt{True}. Getting this wrong leads to double LayerNorm or missing LN.

\subsubsection{B.6.3 LayerNorm Initialization}

\texttt{nn.LayerNorm} defaults to $\gamma = 1, \beta = 0$. This is \textbf{not} 
pretrained. Consider copying pretrained LN if available.
