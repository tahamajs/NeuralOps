\subsection{Known Issues}

\begin{itemize}
\item Windows \texttt{cp1256} codec errors: set \texttt{PYTHONIOENCODING=utf-8}.
\item FP16 prefix scan may lose precision for $L > 512$.
\item Qwen3.5 DeltaNet layers are skipped.

\end{itemize}
