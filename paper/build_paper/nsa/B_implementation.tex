\subsection{B.2 Forward Pass -- Local + Top-K Mask}

\begin{lstlisting}
def forward(self, hidden\_states, attention\_mask=None, ...):
    B, L, D = hidden\_states.shape
    
    Q = self.q\_proj(hidden\_states).view(B, L, H, d).permute(0, 2, 1, 3)
    K = self.k\_proj(hidden\_states).view(B, L, G, d).permute(0, 2, 1, 3)
    V = self.v\_proj(hidden\_states).view(B, L, G, d).permute(0, 2, 1, 3)
    
    # RoPE, GQA
    ...
    
    scores = torch.matmul(Q.float(), K.float().transpose(-2, -1)) * scale
    
    # Valid mask
    valid\_mask\_2d = get\_token\_valid\_mask(attention\_mask, B, L, device)
    key\_valid\_4d = valid\_mask\_2d.unsqueeze(1).unsqueeze(2)
    
    # Local window mask
    idx = torch.arange(L, device=device)
    if self.is\_decoder:
        local\_mask = (idx.unsqueeze(1) - idx.unsqueeze(0) \textless{}= self.window\_size) \
                   & (idx.unsqueeze(1) \textgreater{}= idx.unsqueeze(0))
    else:
        local\_mask = (idx.unsqueeze(1) - idx.unsqueeze(0)).abs() \textless{}= self.window\_size
    local\_mask\_4d = local\_mask.unsqueeze(0).unsqueeze(0)
    
    # Union mask
    if L \textless{}= (2 * self.window\_size + 1):
        total\_mask = local\_mask\_4d & key\_valid\_4d
    else:
        non\_local\_scores = scores.masked\_fill(local\_mask\_4d | (~key\_valid\_4d), -1e4)
        if is\_dec:
            causal\_tril = torch.tril(torch.ones(L, L, dtype=torch.bool, device=device))
            non\_local\_scores = non\_local\_scores.masked\_fill(~causal\_tril, -1e4)
        k\_val = min(self.top\_k, max(1, L - (2 * self.window\_size + 1)))
        \_, topk\_ind = torch.topk(non\_local\_scores, k=k\_val, dim=-1)
        topk\_mask = torch.zeros\_like(scores, dtype=torch.bool).scatter\_(-1, topk\_ind, True)
        total\_mask = (local\_mask\_4d | topk\_mask) & key\_valid\_4d
    
    if is\_dec:
        causal\_tril = torch.tril(torch.ones(L, L, dtype=torch.bool, device=device))
        total\_mask = total\_mask & causal\_tril
    
    # Softmax on masked scores
    scores = scores.masked\_fill(~total\_mask, -1e4)
    attn = F.softmax(scores, dim=-1).to(dtype)
    attn = torch.nan\_to\_num(attn, nan=0.0)
    attn = self.dropout(attn)
    
    context = torch.matmul(attn, V)
    ...
\end{lstlisting}

\subsection{B.3 Handling Short Sequences}

If $L \leq 2w + 1$, every key is already in the window. Skip top-$k$:

\begin{lstlisting}
if L \textless{}= (2 * self.window\_size + 1):
    total\_mask = local\_mask\_4d & key\_valid\_4d
\end{lstlisting}

\subsection{B.4 Causal Mask Ordering}

\textbf{Critical:} causal mask is applied \textbf{before} top-$k$ selection.

\begin{lstlisting}
# 1. Mask local window + padding
non\_local\_scores = scores.masked\_fill(local\_mask\_4d | (~key\_valid\_4d), -1e4)

# 2. Mask future (for decoder)
if is\_dec:
    non\_local\_scores = non\_local\_scores.masked\_fill(~causal\_tril, -1e4)

# 3. Top-k on remaining
\_, topk\_ind = torch.topk(non\_local\_scores, k=k\_val, dim=-1)
\end{lstlisting}

\subsection{B.5 Common Pitfalls}

\subsubsection{B.5.1 Wrong Top-K Timing}

If you compute top-$k$ before causal masking, it may select future keys. 
Always mask first.

\subsubsection{B.5.2 Missing Padding Mask}

Without masking padding in top-$k$, padding keys with high scores get 
selected.

\subsubsection{B.5.3 Wrong `is\_causal` Detection}

For RoBERTa/BERT, \texttt{is\_decoder = False}. For GPT-2, \texttt{is\_decoder = True}. 
Check via \texttt{config.is\_decoder} or \texttt{model\_type}.

\subsubsection{B.5.4 `is\_nested\_encoder` Mis-set}

For RoBERTa, \texttt{is\_nested\_encoder = True} $\to$ skip \texttt{out\_proj}. Otherwise the 
output is double-projected.

\subsubsection{B.5.5 Top-K on All Keys}

If you don't mask the local window before top-$k$, the $k$ selections may 
duplicate the window, wasting budget.

\subsubsection{B.5.6 Memory for Mask Construction}

The \texttt{torch.zeros\_like(scores, dtype=torch.bool)} allocates 
$\mathcal{O}(B H L^2)$ booleans. For very long $L$, use \texttt{sparse} tensors 
or a custom kernel.
