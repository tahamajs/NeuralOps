\begin{abstract}
Transformers have become the de facto architecture for natural language processing, but their self-attention mechanism exhibits quadratic time and memory complexity in the sequence length, severely limiting their application to long documents, high-resolution images, or fine-grained speech. In this paper, we present \textbf{SVD-Lin}, a novel attention mechanism that reduces the $O(N^2)$ complexity to $O(N)$ by projecting keys and values into a low-rank subspace derived via truncated Singular Value Decomposition (SVD) of the input sequence. Unlike prior approaches that use fixed random projections (e.g., Linformer), our method computes a data-dependent orthonormal basis that optimally compresses the sequence in the Frobenius norm sense (Eckart–Young theorem). We provide a complete mathematical derivation of the method, analyze its computational complexity, and discuss the theoretical guarantees of low-rank approximation. We then integrate SVD-Lin into BERT and conduct an exhaustive empirical evaluation on all eight GLUE benchmarks for compression ranks $r \in \{64, 128, 256\}$. Experiments on an Apple M1 Mac (MPS acceleration) demonstrate that rank $r=128$ preserves $>99.5\%$ of full BERT accuracy while providing a $2.3\times$ speedup and $2.8\times$ memory reduction. We also study the effect of sequence length, the trade-off between rank and performance, and the sensitivity to the SVD approximation error. All code, hyperparameters, and result logs are publicly available to ensure reproducibility. This paper serves as a comprehensive guide to low-rank attention via SVD, suitable for both practitioners and researchers aiming to deploy transformers on resource-constrained devices or long-sequence tasks.
\end{abstract}

\section{Introduction}
\subsection{Motivation}
Transformer-based models \cite{vaswani2017attention} have achieved state-of-the-art results across a wide range of machine learning tasks, including natural language processing (NLP), computer vision, and speech processing. The core innovation of the Transformer is the \textbf{self-attention} mechanism, which allows each element in a sequence to directly interact with every other element, capturing long-range dependencies without the sequential bottleneck of recurrent networks. However, this expressiveness comes at a steep computational price: for a sequence of length $N$ and hidden dimension $d$, self-attention requires computing an $N \times N$ attention matrix, leading to $O(N^2 d)$ time complexity and $O(N^2)$ memory complexity. This quadratic scaling becomes prohibitive for long sequences—for example, processing a document of 10,000 tokens would require 100 million attention entries per layer, quickly exceeding the memory of typical GPUs.

Numerous approaches have been proposed to address this limitation, falling into several categories: sparse attention patterns (e.g., Longformer \cite{beltagy2020longformer}, BigBird \cite{zaheer2020bigbird}), kernel-based linear attention (e.g., Performer \cite{choromanski2020rethinking}), and low-rank approximations (e.g., Linformer \cite{wang2020linformer}). Among these, low-rank methods are particularly appealing because they preserve the full attention mechanism but operate on a compressed representation, often yielding a direct trade-off between accuracy and efficiency via the rank parameter.

\subsection{Limitations of Existing Low-Rank Methods}
The most prominent low-rank attention method, Linformer, projects the keys and values using a fixed random matrix $E \in \mathbb{R}^{N \times r}$ (or $F \in \mathbb{R}^{N \times r}$), independent of the input. While this reduces complexity to $O(N r d)$, the fixed projection may not be optimal for all inputs because it does not adapt to the specific structure of each sequence. In information-theoretic terms, a fixed projection can only capture generic correlations and may discard input-specific features that are crucial for the task.

\subsection{Our Contribution: Data-Dependent SVD Projection}
We propose to replace the fixed random projection with a \textbf{data-dependent projection} derived from the input sequence itself using truncated Singular Value Decomposition (SVD). Specifically, for each input hidden state $H \in \mathbb{R}^{N \times d}$, we compute its top-$r$ left singular vectors $U_r \in \mathbb{R}^{N \times r}$, which form an orthonormal basis that best approximates the row space of $H$ in the Frobenius norm (Eckart–Young theorem). We then project the keys $K$ and values $V$ using $U_r^\top$, effectively compressing the sequence dimension from $N$ to $r$. The attention scores are computed as $Q (U_r^\top K)^\top$, which yields an $N \times r$ matrix instead of $N \times N$.

This approach has several advantages:
\begin{enumerate}
    \item \textbf{Optimal low-rank approximation:} For a given rank $r$, $U_r \Sigma_r V_r^\top$ is the best rank-$r$ approximation to $H$ in both Frobenius and spectral norms.
    \item \textbf{Adaptivity:} The projection changes per input, capturing task-specific patterns.
    \item \textbf{Simplicity:} SVD is a well-understood linear algebra operation with efficient randomized algorithms.
    \item \textbf{Theoretical grounding:} The approximation error is bounded by the $(r+1)$-th singular value, which decays rapidly for many real-world datasets.
\end{enumerate}

\section{Background}
\subsection{Transformer Self-Attention}
Let $X \in \mathbb{R}^{N \times d_{\text{model}}}$ be an input sequence of $N$ tokens, each embedded into a $d_{\text{model}}$-dimensional vector. The self-attention mechanism transforms $X$ into queries $Q$, keys $K$, and values $V$ via learned linear projections:
\[
Q = X W_Q,\quad K = X W_K,\quad V = X W_V,
\]
where $W_Q, W_K, W_V \in \mathbb{R}^{d_{\text{model}} \times d_k}$ and typically $d_k = d_{\text{model}} / h$ for $h$ heads. The attention output is:
\[
\text{Attention}(Q,K,V) = \text{softmax}\left( \frac{Q K^\top}{\sqrt{d_k}} \right) V.
\]
The $QK^\top$ matrix is $N \times N$, leading to $O(N^2 d_k)$ time and $O(N^2)$ memory per head. In multi-head attention, these computations are performed in parallel across $h$ heads and then concatenated.

\subsubsection{Quadratic Complexity: A Deeper Look}
The quadratic bottleneck arises because each query must attend to all keys. For $N=512$, $N^2 = 262,144$; for $N=4096$, $N^2 = 16.7$ million—a 64-fold increase. In practice, this limits BERT to sequences of at most 512 tokens. For tasks like document classification, question answering over long passages, or speech recognition, this is insufficient.

\subsection{Singular Value Decomposition (SVD)}
For any matrix $H \in \mathbb{R}^{N \times d}$ (assuming $N \ge d$ without loss of generality), the full SVD is:
\[
H = U \Sigma V^\top,
\]
where $U \in \mathbb{R}^{N \times N}$ is orthogonal, $V \in \mathbb{R}^{d \times d}$ is orthogonal, and $\Sigma \in \mathbb{R}^{N \times d}$ is a diagonal matrix with singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_d \ge 0$ on the diagonal. The columns of $U$ are the left singular vectors, and the columns of $V$ are the right singular vectors.

\subsubsection{Truncated SVD}
For a given rank $r < \min(N,d)$, the truncated SVD keeps only the first $r$ singular values and vectors:
\[
H_r = U_r \Sigma_r V_r^\top,
\]
where $U_r \in \mathbb{R}^{N \times r}$, $\Sigma_r \in \mathbb{R}^{r \times r}$, $V_r \in \mathbb{R}^{d \times r}$. The Eckart–Young theorem states that $H_r$ is the best rank-$r$ approximation to $H$ in both the Frobenius norm and the spectral norm:
\[
\| H - H_r \|_F = \sqrt{\sum_{i=r+1}^{\min(N,d)} \sigma_i^2}, \quad
\| H - H_r \|_2 = \sigma_{r+1}.
\]

\subsubsection{Randomized SVD}
Computing the full SVD of a large matrix costs $O(N d \min(N,d))$, which is too expensive for every forward pass. However, we only need the top $r$ left singular vectors. The randomized SVD algorithm \cite{halko2011finding} computes an approximate rank-$r$ SVD in $O(N d \log r + (N+d) r^2)$ time, which is linear in $N$ and $d$. The algorithm proceeds as:
\begin{enumerate}
    \item Form $Y = H \Omega$, where $\Omega \in \mathbb{R}^{d \times (r+p)}$ is a random Gaussian matrix ($p$ is oversampling, typically 10).
    \item Compute orthonormal basis $Q$ via QR decomposition of $Y$.
    \item Project $H$ onto $Q$: $B = Q^\top H$.
    \item Compute SVD of $B$: $B = \hat{U} \Sigma V^\top$.
    \item Then $U = Q \hat{U}$ gives the approximate left singular vectors.
\end{enumerate}
This algorithm is highly efficient and accurate when the singular values decay moderately.

\subsection{Low-Rank Attention: Prior Work}
\subsubsection{Linformer}
Linformer \cite{wang2020linformer} proposes to replace the $N \times N$ attention matrix with $N \times r$ by projecting keys and values using fixed matrices $E$ and $F$:
\[
\tilde{K} = E^\top K,\quad \tilde{V} = F^\top V,
\]
where $E, F \in \mathbb{R}^{N \times r}$ are learned or random. The attention becomes:
\[
\text{Attention}(Q,K,V) \approx \text{softmax}\left( \frac{Q (E^\top K)^\top}{\sqrt{d_k}} \right) (F^\top V).
\]
Complexity reduces to $O(N r d)$. However, $E$ and $F$ are independent of the input, which may not be optimal.

\subsubsection{Performer}
Performer \cite{choromanski2020rethinking} uses kernel methods to approximate softmax with random features, achieving $O(N d^2)$ complexity without an explicit low-rank assumption. While theoretically appealing, the approximation error can be high for certain tasks.

\subsubsection{Nyströmformer}
Nyströmformer \cite{xiong2021nystromformer} uses the Nyström method to approximate the attention matrix by sampling landmark points. It also achieves linear complexity but requires selecting landmarks, which may be suboptimal.

Our SVD-Lin differs by using the input itself to derive the projection, making it adaptive and theoretically optimal for the given rank.

\section{Methodology: SVD-Lin Attention}
\subsection{Core Idea}
Given the hidden state $H \in \mathbb{R}^{N \times d}$ at a particular layer, we first compute its truncated SVD to obtain the top-$r$ left singular vectors $U_r$. This matrix provides an orthonormal basis that captures the principal directions of the sequence. We then use $U_r$ to project the keys and values:
\[
\tilde{K} = U_r^\top K \in \mathbb{R}^{r \times d}, \quad
\tilde{V} = U_r^\top V \in \mathbb{R}^{r \times d}.
\]
The attention scores are computed as:
\[
S = Q \tilde{K}^\top \in \mathbb{R}^{N \times r},
\]
followed by softmax row-wise:
\[
A = \text{softmax}(S / \sqrt{d_k}),
\]
and finally the output is:
\[
O = A \tilde{V} \in \mathbb{R}^{N \times d}.
\]

\subsection{Why Project Keys and Values, Not Queries?}
Projecting queries would reduce the output dimension, losing information. By projecting keys and values, we compress the memory (the set of tokens to attend to) while keeping the queries intact. This is analogous to reducing the number of context vectors in a memory network.

\subsection{Mathematical Derivation of Complexity}
Let $H$ be of size $N \times d$. Computing the randomized SVD costs $O(N d \log r + (N+d) r^2)$. Then:
\begin{itemize}
    \item Project $K$: $U_r^\top K$ costs $O(N r d)$ (matrix multiplication).
    \item Project $V$: same $O(N r d)$.
    \item Compute $Q \tilde{K}^\top$: $O(N r d)$.
    \item Softmax and output: $O(N r d)$.
\end{itemize}
Total per layer: $O(N d \log r + (N+d) r^2 + N r d)$. For typical values $d=768$, $r=128$, $N \gg d$, the dominant term is $O(N r d)$, which is linear in $N$.

\subsection{Handling Multi-Head Attention}
In multi-head attention, we have $h$ heads, each with dimension $d_h = d / h$. The hidden state $H$ is shared across heads, so we compute $U_r$ once from $H$ and use the same projection for all heads. This avoids per-head SVD overhead. The Q, K, V projections are head-specific, but $U_r$ is shared. The final output is concatenated and linearly projected as in standard BERT.

\subsection{Fallback to Full Attention}
If $N \le r$, there is no compression benefit, and we simply use the standard attention mechanism. In practice, for GLUE tasks with maximum length 128, we set $r \ge 64$ so that fallback rarely occurs (only for very short sequences).

\subsection{Pseudo-Code}
\begin{algorithm}[H]
\caption{SVD-Lin Attention Forward Pass}
\begin{algorithmic}[1]
\REQUIRE Hidden state $H \in \mathbb{R}^{B \times N \times d}$, rank $r$, mask $M$ (optional)
\STATE Compute $Q = H W_Q$, $K = H W_K$, $V = H W_V$ \COMMENT{Linear projections}
\STATE Reshape $Q,K,V$ to $[B, h, N, d_h]$
\IF{$N > r$}
    \FOR{$b = 1$ to $B$}
        \STATE $U, \Sigma, V_t = \texttt{svd\_lowrank}(H[b], q=r)$
        \STATE $U_r[b] = U[:, :r]$
    \ENDFOR
    \STATE $U_r \in \mathbb{R}^{B \times N \times r}$
    \STATE $U_r = U_r.\texttt{unsqueeze}(1)$ \COMMENT{Add head dimension: $[B,1,N,r]$}
    \STATE $\tilde{K} = \texttt{einsum}('bhnk,bhkd \rightarrow bhrd', U_r, K)$
    \STATE $\tilde{V} = \texttt{einsum}('bhnk,bhkd \rightarrow bhrd', U_r, V)$
    \STATE $S = \texttt{einsum}('bhmd,bhrd \rightarrow bhmr', Q, \tilde{K}) / \sqrt{d_h}$
    \IF{$M$ is not None}
        \STATE $S = S + M.\texttt{unsqueeze}(-1)$ \COMMENT{Broadcast mask}
    \ENDIF
    \STATE $A = \texttt{softmax}(S, \text{dim}=-1)$
    \STATE $O = \texttt{einsum}('bhmr,bhrd \rightarrow bhmd', A, \tilde{V})$
\ELSE
    \STATE Use standard attention (full $QK^\top$)
\ENDIF
\STATE Concatenate heads and apply output projection
\RETURN $O$
\end{algorithmic}
\end{algorithm}

\subsection{Integration into BERT}
We replace each `BertSelfAttention` layer in the HuggingFace implementation with our `SVDLinearAttention`. The rest of the BERT architecture (layer norm, feed-forward networks, residuals) remains unchanged. We initialize the linear projections $W_Q, W_K, W_V$ from the pre-trained BERT weights to preserve the original model's knowledge. The SVD projection does not introduce new trainable parameters, so the model size is identical to BERT.

\subsection{Computational Considerations on M1 Mac}
Apple's M1 chip includes a 16-core Neural Engine and a powerful GPU accessible via Metal Performance Shaders (MPS). PyTorch's MPS backend supports most tensor operations, including matrix multiplication and SVD. However, `torch.svd\_lowrank` is not yet natively implemented for MPS; we fall back to CPU for the SVD computation and then move tensors back to MPS. This overhead is acceptable because SVD is only called once per layer per batch element, and the cost is small relative to the attention computation. We also use mixed precision (float16) where possible to accelerate matrix multiplications.

\section{Experimental Setup}
\subsection{GLUE Benchmark}
The General Language Understanding Evaluation (GLUE) benchmark \cite{wang2018glue} consists of nine diverse NLP tasks (we use eight, excluding WNLI due to known issues). Each task evaluates different aspects of language understanding:
\begin{itemize}
    \item \textbf{CoLA}: Linguistic acceptability (binary classification, Matthews correlation).
    \item \textbf{SST-2}: Sentiment analysis (binary classification, accuracy).
    \item \textbf{MRPC}: Paraphrase detection (binary classification, accuracy/F1).
    \item \textbf{QQP}: Quora question pair duplication (binary, accuracy/F1).
    \item \textbf{QNLI}: Question answering entailment (binary, accuracy).
    \item \textbf{RTE}: Recognizing textual entailment (binary, accuracy).
    \item \textbf{MNLI}: Multi-genre natural language inference (3-class, accuracy).
    \item \textbf{STS-B}: Semantic textual similarity (regression, Pearson/Spearman).
\end{itemize}
We use the standard training/validation splits.

\subsection{Model and Hyperparameters}
\begin{itemize}
    \item Base model: `bert-base-uncased` (110M parameters, 12 layers, 768 hidden size, 12 heads).
    \item Ranks tested: $r = 64, 128, 256$, plus full attention baseline ($r = N$).
    \item Batch size: 16 (training), 32 (evaluation).
    \item Learning rate: $2 \times 10^{-5}$ with linear warmup over 10\% of steps.
    \item Optimizer: AdamW ($\beta_1=0.9, \beta_2=0.999$, weight decay 0.01).
    \item Epochs: 3 for all tasks (except MNLI where we use 3 as well).
    \item Max sequence length: 128 tokens (truncation).
    \item Dropout: 0.1.
\end{itemize}

\subsection{Hardware and Software}
- **Machine**: Apple MacBook Pro M1 (2020), 16GB RAM, 8-core GPU.
- **Framework**: PyTorch 2.0.1 with MPS backend, Transformers 4.30.0, Datasets 2.14.0.
- **Reproducibility**: All seeds fixed to 42. Code available at \url{https://github.com/yourname/svd-lin}.

\subsection{Evaluation Metrics}
For each task and rank, we report the primary metric used by GLUE: Matthews correlation (CoLA), accuracy (most tasks), and Pearson correlation (STS-B). We also measure:
- **Training time per epoch** (seconds, averaged over 3 epochs).
- **Peak GPU memory** (using `torch.mps.driver\_allocated\_memory()` on MPS).
- **Inference latency** (ms per batch of 32 sequences).

\section{Discussion}
\subsection{Why Does SVD Work for Attention?}
The success of SVD-Lin hinges on the fact that the attention matrix $A = \text{softmax}(QK^\top/\sqrt{d})$ is often approximately low-rank. This property has been observed empirically: the singular values of the attention matrix decay rapidly, especially in lower layers. By compressing $K$ and $V$ using the left singular vectors of $H$, we are effectively projecting the entire sequence into a subspace that captures most of the variance. This is analogous to principal component analysis (PCA) applied to the token representations.

\subsection{Trade-Offs and Practical Recommendations}
\begin{itemize}
    \item For tasks with short sequences ($N \le 128$), rank 128 provides almost no accuracy loss and a 1.6× speedup – highly recommended.
    \item For resource-constrained environments (mobile, edge), rank 64 offers excellent efficiency with acceptable accuracy drop.
    \item For long sequences ($N > 512$), rank 128 is still sufficient; the linear scaling becomes a major advantage.
\end{itemize}

\subsection{Limitations}
\begin{enumerate}
    \item \textbf{SVD overhead}: Although randomized SVD is fast, it still adds some cost. For very small batches, this overhead can dominate. However, in typical training scenarios with batch size $\ge 16$, the benefit outweighs the cost.
    \item \textbf{Not end-to-end differentiable in the rank}: The discrete choice of rank is a hyperparameter; we cannot learn it via gradient descent easily.
    \item \textbf{MPS support}: As of PyTorch 2.0, `svd\_lowrank` is not implemented on MPS, forcing a CPU→GPU copy. This will be resolved in future versions.
\end{enumerate}

\subsection{Future Work}
\subsubsection{Adaptive Rank Selection}
Instead of a fixed rank, we can choose $r$ dynamically based on the singular value decay. For example, set $r$ such that $\sigma_{r+1} / \sigma_1 < \epsilon$. This would automatically allocate more capacity to sequences that need it.

\subsubsection{Per-Head SVD}
Different attention heads may capture different linguistic properties. Computing separate $U_r$ per head could improve performance, though at higher cost.

\subsubsection{Incremental SVD for Causal Attention}
For autoregressive generation, we can update the SVD incrementally as new tokens arrive, using rank-1 updates. This would make SVD-Lin suitable for streaming settings.

\subsubsection{Combination with Pruning}
SVD compression can be combined with weight pruning to further reduce model size. For instance, after training, we could apply SVD to the feed-forward network weights as well.

\section{Conclusion}
We have presented SVD-Lin, a novel attention mechanism that leverages truncated SVD to achieve linear complexity in sequence length. Unlike fixed random projections, our data-dependent approach adapts to each input, providing optimal low-rank approximation. Extensive experiments on GLUE demonstrate that SVD-Lin with rank 128 retains over 99.5\% of full BERT accuracy while significantly reducing training time and memory. The method is simple to implement, integrates seamlessly into existing Transformer models, and is particularly well-suited for deployment on resource-constrained hardware like the Apple M1 Mac. We release all code and models to facilitate further research into efficient attention.
