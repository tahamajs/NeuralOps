### 4. Git Architecture: Nested Repositories vs. Git Submodules
- **Fact**: Each of the 217 paper directories contains a full `.git/` folder with its own commit history.
- **Finding**: `.gitmodules` does **not** exist in the top-level repository.
- **Implication**: These 217 repositories were created as standalone Git repositories rather than submodules registered via `git submodule add`. A recursive clone of the top-level repository (`git clone --recursive`) will **not** automatically pull these nested `.git` repositories unless `.gitmodules` is generated.
