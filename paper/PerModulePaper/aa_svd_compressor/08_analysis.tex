\section{08 Analysis}

 8. Detailed Analysis

 8.1 Activation Whitening Impact
Traditional SVD truncates based solely on weight singular value spectra. However, input activations $X$ are non-spherical. By multiplying $W$ by $C\_X^{1/2}$, singular vectors corresponding to high-variance activation directions are amplified, ensuring that the truncated rank-$r$ subspace preserves the components most responsible for signal propagation.

 8.2 Conv1D Transposition Handling
In causal models such as GPT-2, projections are parameterized as `Conv1D(nf, nx)` where weights have shape $(nx, nf)$ rather than PyTorch's conventional `nn.Linear` shape $(nf, nx)$. `aa\_svd\_compressor` detects 1D convolutions and applies explicit weight transposition prior to covariance multiplication and factor assignment.


 4. Parameter Savings \& Memory Footprint Profiling


 4.1 Memory \& FLOP Formulas
When AASVD is deployed as a weight reconstruction mechanism (overwriting `module.weight.data` in-place), parameter memory remains identical to the original uncompressed model ($d\_{\text{out}} \times d\_{\text{in}}$). When deployed as a factorized linear layer ($U\_r \operatorname{diag}(S\_r) V\_r^T$):

Specifically, regarding \textbf{Original Parameters}, $P\_{\text{orig}} = d\_{\text{out}} \cdot d\_{\text{in}}$ Furthermore, regarding \textbf{Factorized Parameters}, $P\_{\text{AASVD}} = r(d\_{\text{out}} + d\_{\text{in}} + 1)$ Concurrently, regarding \textbf{Inference FLOPs / Token}, $2 r (d\_{\text{out}} + d\_{\text{in}})$


 4.2 Benchmark Footprint Table ($d\_{\text{out}} = 4096, d\_{\text{in}} = 4096$, Rank $r = 128$)

| Stage / Component | Operation | Matrix Dimensions | Tensor Element Count | Memory (FP16) |
|-------------------|-----------|-------------------|----------------------|---------------|
| **Calibration Activation** | Flatten Input | $128 \times 4096$ | 524,288 | 1.05 MB |
| **Anchor Basis $A\_{\text{anchor}}$** | Activation Basis | $4096 \times 128$ | 524,288 | 1.05 MB |
| **Anchored Weight $W\_{\text{anchored}}$** | $W P\_{\text{anchor}}$ | $4096 \times 4096$ | 16,777,216 | 33.55 MB |
| **Factorized $U\_r$** | Left Basis | $4096 \times 128$ | 524,288 | 1.05 MB |
| **Factorized $V\_r^T$** | Right Basis | $128 \times 4096$ | 524,288 | 1.05 MB |
| **Total Factorized Layer** | $U\_r, S\_r, V\_r^T$ | -- | **1,048,704** | **2.10 MB (93.7% savings)** |

 5. Precision Loss, Perplexity \& Sensitivity Bounds


 5.1 Error Bound relative to Activation Space
Let $X$ be the activation tensor with principal covariance $C\_X = X^T X$. The output error norm $\|E\_{\text{out}}\|\_F^2 = \|X W^T - X \hat{W}^T\|\_F^2$ under AASVD satisfies:

\[
\|E\_{\text{out}}\|\_F^2 \le \|X (I - P\_{\text{anchor}}) W^T\|\_F^2 + \|X P\_{\text{anchor}} (W - \hat{W}\_{\text{AASVD}})^T\|\_F^2
\]

By selecting $A\_{\text{anchor}}$ as the top-$r$ eigenvectors of $C\_X$, the term $\|X (I - P\_{\text{anchor}})\|\_F^2 = \sum\_{i=r+1}^{d\_{\text{in}}} \lambda\_i(C\_X)$ is minimized. Consequently, AASVD guarantees lower activation output distortion than standard static SVD:

\[
\|X W^T - X \hat{W}\_{\text{AASVD}}^T\|\_F^2 \le \|X W^T - X \hat{W}\_{\text{SVD}}^T\|\_F^2
\]

 5.2 Failure Modes
1. **Out-of-Distribution Calibration Drift**: If calibration text sequences do not match deployment token distributions, $A\_{\text{anchor}}$ isolates irrelevant activation subspaces, degrading real-world inference accuracy.
2. **Small Calibration Sample Size**: Calibrating with short sequence lengths ($K < d\_{\text{in}}$) causes rank deficiency in $\bar{X}$, generating spurious zero singular values in $V\_X^T$.
