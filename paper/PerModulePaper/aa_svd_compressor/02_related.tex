\section{Related Work and Theoretical Foundations}

\subsection{Model Compression Paradigms}
Transformer compression literature focuses on parameter and memory reduction through distinct architectural mechanisms:
\begin{enumerate}
\item \textbf{Low-Rank Decomposition:} Decomposing high-dimensional weight matrices into rank-$r$ bottleneck factors via truncated SVD~\citep{eckart1936}, randomized linear algebra~\citep{halko2011}, or Tensor-Train decompositions~\citep{novikov2015tensor}. Modern approaches adapt singular projections to transformer parameter dynamics, as seen in ALBERT cross-layer sharing~\citep{lan2020albert}, SVD-LLM~\citep{wang2024svdllm}, ASVD~\citep{yuan2023asvd}, FWSVD~\citep{hsu2022fwsvd}, and DRONE~\citep{chen2021drone}. Low-rank methods exploit the empirical observation that overparameterized weight matrices possess rapidly decaying singular spectra.
\item \textbf{Quantization and Discretization:} Mapping continuous parameters into low-bit integers (INT8, INT4) or vector-quantized codebooks. Prominent methods include GPTQ~\citep{frantar2023gptq}, AWQ~\citep{lin2024awq}, and SmoothQuant~\citep{xiao2023smoothquant}, which address activation outliers to retain representation fidelity.
\end{enumerate}

\subsection{Sensitivity-Aware Saliency Metrics}
Weight magnitude alone often fails to correlate with functional layer saliency~\citep{kirkpatrick2017, molchanov2019}. Modern compression systems leverage activation covariance statistics to preserve salient subspace representations under aggressive parameter reduction. Rather than crude element-wise magnitude approximations, data-driven low-rank compression weights projection parameters using empirical activation covariances:
\begin{align}
C_X &= \frac{1}{N} \sum_{i=1}^N X_i^\top X_i \\
W_w &= W C_X^{1/2} \\
\operatorname{SVD}(W_w) &= U \Sigma V^\top \\
U_r &= U_{:, :r} \Sigma_r^{1/2} \\
V_r &= \Sigma_r^{1/2} V^\top C_X^{-1/2}
\end{align}
Following Low-Rank Adaptation (LoRA) formulations~\citep{hu2022lora}, low-rank factorizations can be augmented with lightweight trainable adapter bypasses to recover expressive capacity without re-training full base weights.

\subsection{Efficient Attention Formulations}
Standard softmax attention requires computing an $N \times N$ dense matrix:
\[
\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{Q K^\top}{\sqrt{d}}\right) V
\]
Linear attention reformulates this via positive feature maps $\phi(\cdot)$, enabling associative evaluation~\citep{katharopoulos2020, choromanski2021, xiong2021nystromformer}:
\[
(Q K^\top) V = Q (K^\top V)
\]
This shifts computational complexity from quadratic $\mathcal{O}(N^2 d)$ to linear $\mathcal{O}(N d^2)$. The \texttt{AASVD} module leverages these structural properties to optimize inference speed and VRAM overhead.
