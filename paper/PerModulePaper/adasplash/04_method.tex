
\section{Method}

\subsection{Overview}

AdaSplash replaces the attention mechanism of a pretrained transformer with 
four modifications:

\begin{enumerate}
\item \textbf{$\alpha$-Entmax normalization} ( 4.2) replaces softmax.
\item \textbf{Local splash masking} ( 4.3) restricts attention to a sliding window
  plus sink tokens.
\item \textbf{Frozen base weights + LoRA} ( 4.4) preserves pretrained representations
  while providing trainable capacity.
\item \textbf{Multi-architecture weight transfer} ( 4.5) enables drop-in replacement.

\end{enumerate}
\textbf{Figure 4.1} shows the pipeline.

\begin{lstlisting}
    +------------------------------------------+
    |  Pretrained attention A with Q, K, V, O  |
    +------------------+-----------------------+
                       |
                        
    +------------------------------------------+
    |  AdaSplash attention A':                 |
    |    1. Project with frozen base + LoRA    |
    |    2. Apply splash mask                  |
    |    3. Apply $\alpha$-entmax                     |
    |    4. Compute context, apply out_proj    |
    +------------------+-----------------------+
                       |
                        
    +------------------------------------------+
    |  Compressed attention with:              |
    |    - Frozen base weights (exact copy)    |
    |    - Trainable LoRA adapters (rank r_L)  |
    |    - $\alpha$-entmax sparse activations         |
    |    - Local splash window                 |
    +------------------------------------------+
\end{lstlisting}

\subsection{Phase 1: $\alpha$-Entmax Normalization}

\subsubsection{Problem Statement}

Given scores $s \in \mathbb{R}^{L}$, compute:

\[
p_i = \max(0, (\alpha - 1) s_i - \tau)^{1/(\alpha - 1)}
\tag{4.1}
\]

with $\tau$ chosen so that $\sum_i p_i = 1$.

\subsubsection{Bisection Algorithm}

\textbf{Algorithm 1:} $\alpha$-Entmax via bisection
\begin{lstlisting}
Input: scores s $\in$ R^{B$\times$H$\times$L_q$\times$L_k}, $\alpha$, valid_mask, n_iter
Output: p $\in$ R^{B$\times$H$\times$L_q$\times$L_k} with sum_i p_i = 1

1:  if |$\alpha$ - 1| < $\epsilon$:                          Softmax case
2:      return softmax(s, masked)
3:
4:  s_masked $\leftarrow$ mask_invalid(s, -10000)
5:  s_shift $\leftarrow$ s_masked - max(s_masked)
6:  scaled $\leftarrow$ s_shift * ($\alpha$ - 1)
7:
8:  $\tau$_lo $\leftarrow$ min(scaled) - 1
9:  $\tau$_hi $\leftarrow$ 0
10:
11: for _ in range(n_iter):
12:     $\tau$ $\leftarrow$ ($\tau$_lo + $\tau$_hi) / 2
13:     p $\leftarrow$ max(0, scaled - $\tau$)^{1/($\alpha$-1)}
14:     p $\leftarrow$ mask_invalid(p, 0)
15:     sum_p $\leftarrow$ sum(p)
16:     if sum_p > 1:
17:         $\tau$_lo $\leftarrow$ $\tau$
18:     else:
19:         $\tau$_hi $\leftarrow$ $\tau$
20:
21: $\tau$ $\leftarrow$ ($\tau$_lo + $\tau$_hi) / 2
22: p $\leftarrow$ max(0, scaled - $\tau$)^{1/($\alpha$-1)}
23: p $\leftarrow$ mask_invalid(p, 0)
24: p $\leftarrow$ p / sum(p)                            Normalize
25:
26: if sum(p) < $\epsilon$:                             Support empty
27:     p $\leftarrow$ softmax(s_masked)                   Fallback
28:
29: return p
\end{lstlisting}

\textbf{Convergence.} Bisection on $[\tau_\text{lo}, \tau_\text{hi}]$ converges 
to precision $(\tau_\text{hi} - \tau_\text{lo}) / 2^{n_\text{iter}}$. With 
25 iterations and initial range $O(1)$, precision is $O(10^{-7})$.

\textbf{Numerical stability.}

\begin{enumerate}
\item \textbf{Shift scores.} Subtract $\max_i s_i$ to bound $(\alpha - 1) s_i$.
\item \textbf{Mask invalid keys.} Set to $-10000$ before the algorithm.
\item \textbf{Softmax fallback.} If the support is empty (all p\_i = 0), fall back
  to softmax.

\end{enumerate}
\subsubsection{Complexity}

\begin{itemize}
\item \textbf{Time:} $O(n_\text{iter} \cdot L^2)$ for sequence length $L$.
\item \textbf{Memory:} $O(L^2)$ for the attention matrix.

\end{itemize}
For $L = 128$ and $n_\text{iter} = 25$: ~$4 \times 10^5$ operations per head, 
comparable to 25 softmaxes.

\subsubsection{Sparsity Pattern}

For $\alpha = 1.5$, the support size depends on the score distribution:

\begin{itemize}
\item \textbf{Uniform scores:} ~50\% sparsity (barely sparse).
\item \textbf{Peaked scores:} ~80\% sparsity.
\item \textbf{Real attention scores:} ~40\% sparsity empirically.

\end{itemize}
\textbf{Figure 4.2} shows sparsity vs $\alpha$ for a typical attention layer.

\subsection{Phase 2: Local Splash Masking}

\subsubsection{Splash Mask Definition}

For causal decoders, we restrict attention to a local window of radius $W$ 
plus the first $S$ sink tokens:

\[
\text{splash}(i, j) = \begin{cases}
1 & \text{if } 0 \leq i - j \leq W \\
1 & \text{if } j < S \\
0 & \text{otherwise}
\end{cases}
\tag{4.2}
\]

Keys outside the splash mask are set to $-10000$ before entmax.

\subsubsection{Non-Causal Models}

For bidirectional encoders (DistilBERT, RoBERTa), we \textbf{do not} apply 
splash masking. The full attention is used with $\alpha$-entmax. This preserves 
global context.

\textbf{Rationale.} Splash masking is a \textbf{decoder-specific} technique for 
long-context inference. On short sequences (L $\le$ 128), the window radius 
$W = 32$ would restrict attention unnecessarily for encoders.

\subsubsection{Interaction with Attention Sinks}

The sink tokens ($j < S$, default $S = 4$) are always preserved, even outside 
the splash window. This maintains the stability property discovered by 
Xiao et al. (2024).

\subsection{Phase 3: Frozen Base Weights + LoRA}

\subsubsection{Base Weight Transfer}

For each projection $P \in \{Q, K, V, O\}$, we copy $W_P$ from the pretrained 
attention module. The exact copy procedure depends on the architecture:

\begin{itemize}
\item \textbf{DistilBERT:} Direct copy from \texttt{q\_lin}, \texttt{k\_lin}, \texttt{v\_lin}, \texttt{out\_lin}.
\item \textbf{RoBERTa:} Copy from \texttt{self.query}, \texttt{self.key}, \texttt{self.value}; leave
  \texttt{out\_proj} identity (outer \texttt{output.dense} applies it).
\item \textbf{GPT-2:} Split fused \texttt{c\_attn.weight} (transposed) into Q, K, V; copy
  \texttt{c\_proj.weight}.
\item \textbf{Qwen:} Direct copy from \texttt{q\_proj}, \texttt{k\_proj}, \texttt{v\_proj}, \texttt{o\_proj}.

\end{itemize}
\subsubsection{Freezing Base}

After copying, base weights are frozen (\texttt{requires\_grad = False}). Biases are 
also frozen if present.

\subsubsection{LoRA Adapters}

For each projection, we add a rank-$r_L$ adapter:

\[
\Delta W_P = B_P A_P, \quad A_P \in \mathbb{R}^{r_L \times d_\text{in}}, \quad B_P \in \mathbb{R}^{d_\text{out} \times r_L}
\tag{4.3}
\]

with initialization:

\[
A_P \sim \mathcal{N}(0, \sigma^2), \quad B_P = 0
\tag{4.4}
\]

At initialization, $\Delta W_P = 0$, so the forward pass matches the 
pretrained model exactly.

\subsubsection{Forward Pass}

\[
\text{Proj}_P(x) = x W_P^\top + x (B_P A_P)^\top + b_P
\tag{4.5}
\]

\[
\text{Proj}_P(x) = x W_P^\top + (x A_P^\top) B_P^\top + b_P
\tag{4.6}
\]

\subsubsection{Parameter Count}

\begin{table}[H]
\centering
\small
\begin{tabular}{ll}
\toprule
\textbf{Configuration} & \textbf{Parameters} \\
\midrule
Original & $d_\text{in} d_\text{out}$ \\
AdaSplash base (frozen) & $d_\text{in} d_\text{out}$ (same) \\
AdaSplash + LoRA & $d_\text{in} d_\text{out} + r_L (d_\text{in} + d_\text{out})$ \\
\textbf{Parameter change} & \textbf{+$r_L (d_\text{in} + d_\text{out})$} \\
\bottomrule
\end{tabular}
\end{table}

For $d = 768$, $r_L = 16$: each projection adds $16 \times 1536 = 24{,}576$ 
parameters. Across 4 projections $\times$ $N_l$ layers: significant addition.

\textbf{AdaSplash is not a compression method.}

\subsection{Phase 4: Multi-Architecture Weight Transfer}

\subsubsection{Architecture Detection}

\begin{lstlisting}
# Nested encoder detection
is_nested = (
    hasattr(src, "self") and hasattr(src, "output") and
    hasattr(src.self, "query")
)
\end{lstlisting}

For nested encoders, we extract $Q, K, V$ from \texttt{src.self} and set 
\texttt{out\_proj} to identity (the outer \texttt{output.dense} applies the projection).

\subsubsection{Frobenius Validation}

After copying, we verify:

\[
\|W_P\|_F > 10^{-4} \quad \forall P \in \{Q, K, V\}
\tag{4.7}
\]

If a projection has near-zero norm, we raise an error and skip injection.

\subsection{The Full Algorithm}

\textbf{Algorithm 2:} AdaSplash forward pass
\begin{lstlisting}
Input:  hidden_states X $\in$ R^{B$\times$L$\times$d}
        attention_mask, position_embeddings
        hyperparameters $\alpha$, W, S, r_L
Output: output Y $\in$ R^{B$\times$L$\times$d}

 1: Q $\leftarrow$ X W_Q^T + (X A_Q^T) B_Q^T
 2: K $\leftarrow$ X W_K^T + (X A_K^T) B_K^T
 3: V $\leftarrow$ X W_V^T + (X A_V^T) B_V^T
 4:
 5: if position_embeddings: (Q, K) $\leftarrow$ apply_rotary(Q, K, cos, sin)
 6: if H_kv < H: K, V $\leftarrow$ repeat_kv(K, V)
 7:
 8: S $\leftarrow$ (Q @ K^T) / $\sqrt{}$d_h
 9: S $\leftarrow$ apply_attention_mask(S, mask)
10:
11: if is_decoder:
12:     causal_mask $\leftarrow$ tril(ones(L, L))
13:     splash_mask $\leftarrow$ (0 $\le$ i - j $\le$ W) | (j < S)
14:     S $\leftarrow$ S.masked_fill(~(causal \& splash), -10000)
15:
16: A $\leftarrow$ $\alpha$_entmax(S, $\alpha$)
17: A $\leftarrow$ dropout(A)
18:
19: C $\leftarrow$ A @ V
20: C $\leftarrow$ C.view(B, L, H   d_h)
21:
22: if is_nested: Y $\leftarrow$ C
23: else:        Y $\leftarrow$ C W_O^T + (C A_O^T) B_O^T + b_O
24:
25: return Y
\end{lstlisting}

\subsubsection{Time Complexity}

\begin{table}[H]

\midrule
Q/K/V projection & $O(L d^2)$ \\

\textbf{Compared to softmax:} AdaSplash adds $n_\text{iter} \times L^2$ operations 
for entmax bisection. For $n_\text{iter} = 25$, this is ~25$\times$ 
slower attention.

\textbf{For causal decoders with splash masking,} the mask restricts nonzero 
entries to $\sim W \cdot L$, reducing effective attention cost. In practice, 
this is not leveraged by PyTorch dense matmul.

\subsubsection{Space Complexity}

\textbf{Attention matrix:} $O(L^2)$ -- same as softmax attention.

\subsection{Theoretical Notes}

\subsubsection{$\alpha$-Entmax Support Sparsity}

\textbf{Claim.} For $\alpha > 1$, the support of $\alpha$-entmax output has size at most 
$L - k$ where $k$ is the number of scores below the threshold $\tau^*$.

\textbf{Proof.} Any score $s_i$ with $(\alpha - 1) s_i < \tau^*$ yields $p_i = 0$. 
The support is exactly $S = \{i : (\alpha - 1) s_i \geq \tau^*\}$. $\square$

\subsubsection{Entmax vs Softmax on Peaked Distributions}

\textbf{Claim.} For scores with high variance, $\alpha$-entmax with $\alpha = 1.5$ 
produces sparser outputs than softmax.

\textbf{Proof sketch.} The Tsallis entropy with $\alpha > 1$ penalizes spread 
more than Shannon entropy. When score variance is high, the argmax pushes 
mass to the top scores. $\square$

\subsubsection{Attention Sink Preservation}

\textbf{Claim.} Masking first $S$ tokens as sinks does not break causality.

\textbf{Proof.} Sink tokens have $j < S \leq i$ for all queries $i \geq S$. 
For $i < S$, causality is enforced by the lower triangular mask. $\square$

\subsubsection{Approximation Error}

We provide no bound on downstream accuracy loss. The approximation error is 
determined by $\alpha$, $W$, and the interaction with LoRA recovery.

\subsection{Hyperparameter Guidance}

\begin{table}[H]
\centering
\small
\begin{tabular}{lll}
\toprule
\textbf{Hyperparameter} & \textbf{Default} & \textbf{Effect} \\
\midrule
$\alpha$ & 1.5 \& Higher = sparser (up to 2.0 = sparsemax) \\
$W$ (splash radius) & 32 \& Higher = more context, less sparsity \\
$S$ (sink count) & 4 \& Higher = more global context \\
$r_L$ (LoRA rank) & 16 \& Higher = more recovery capacity \\
\bottomrule
\end{tabular}
\end{table}

\textbf{Choosing $\alpha$:}

\begin{itemize}
\item $\alpha = 1.0$: softmax (no sparsity, baseline)
\item $\alpha = 1.2$: mild sparsity
\item $\alpha = 1.5$: balanced (default)
\item $\alpha = 1.8$: sparse, may destabilize
\item $\alpha = 2.0$: sparsemax, sparse but non-smooth

\end{itemize}
\textbf{Choosing $W$:}

\begin{itemize}
\item $W = 16$: very local (encoder-only)
\item $W = 32$: balanced (default)
\item $W = 64$: broader context
\item $W = L$: no windowing (baseline attention)

\end{itemize}
\textbf{Note:} Splash masking is only applied to causal decoders. Encoders use 
full attention.
