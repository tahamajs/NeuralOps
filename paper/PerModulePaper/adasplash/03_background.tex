
\section{Background}

\subsection{Standard Softmax Attention}

For query-key scores $s = Q K^\top / \sqrt{d_h}$, softmax produces:

\[
p_i = \frac{e^{s_i}}{\sum_j e^{s_j}}, \quad p_i > 0, \quad \sum_i p_i = 1
\tag{3.1}
\]

Two properties matter here:

\begin{enumerate}
\item \textbf{Strict positivity.} Every $p_i > 0$; no exact zeros.
\item \textbf{Max-entropy solution.} Softmax solves:

\end{enumerate}
\[
\text{softmax}(s) = \arg\max_{p \in \Delta^{d-1}} \langle p, s \rangle + H(p)
\tag{3.2}
\]

where $H$ is Shannon entropy. The entropy regularization spreads mass 
uniformly.

\subsection{The $\alpha$-Entmax Family}

Replacing Shannon entropy with \textbf{Tsallis entropy} $H_\alpha^T$:

\[
H_\alpha^T(p) = \begin{cases}
\frac{1}{\alpha (\alpha - 1)} \sum_i (p_i - p_i^\alpha) & \alpha \neq 1 \\
-\sum_i p_i \log p_i & \alpha = 1
\end{cases}
\tag{3.3}
\]

gives the $\alpha$-entmax family:

\[
\text{$\alpha$-entmax}(s) = \arg\max_{p \in \Delta^{d-1}} \langle p, s \rangle + H_\alpha^T(p)
\tag{3.4}
\]

\textbf{Closed form.} For $\alpha > 1$:

\[
\text{$\alpha$-entmax}(s)_i = \max\!\left(0, (\alpha - 1) s_i - \tau\right)^{1/(\alpha - 1)}
\tag{3.5}
\]

where $\tau$ is chosen so that $\sum_i p_i = 1$.

\textbf{Support.} The value $\tau$ determines the \textbf{support} of the output:

\[
S = \{i : (\alpha - 1) s_i > \tau\}
\tag{3.6}
\]

For $\alpha = 1.5$: $p_i \propto \max(0, 0.5 s_i - \tau)^2$.

\subsection{Bisection for $\tau$}

Solving for $\tau$ is a one-dimensional root-finding problem:

\[
f(\tau) = \sum_i \max(0, (\alpha - 1) s_i - \tau)^{1/(\alpha - 1)} - 1 = 0
\tag{3.7}
\]

$f$ is monotone decreasing in $\tau$: at $\tau = -\infty$, $f = +\infty$; 
at $\tau = +\infty$, $f = -1$. Bisection converges in $\log_2(1/\epsilon)$ 
iterations. Our implementation uses 25 iterations, giving precision 
$\sim 10^{-7}$.

\textbf{Initial bounds.}

\begin{itemize}
\item $\tau_\text{hi} = 0$ (a natural upper bound since scores are typically
  shifted so max = 0).
\item $\tau_\text{lo} = \min_i (\alpha - 1) s_i - 1$ (a lower bound below which
  all weights are positive).

\end{itemize}
\subsection{Numerical Stability}

\textbf{Score shifting.} To avoid overflow in $(\alpha - 1) s_i$, we shift scores 
by subtracting $\max_i s_i$. This preserves the argmax but bounds the 
exponent.

\textbf{Fallback.} If the support is empty (all weights zero), the output would be 
ill-defined. We fall back to softmax on the same masked scores.

\subsection{Attention Sinks}

\textbf{Definition.} Xiao et al. (2024) define attention sinks as tokens that 
receive high attention regardless of query content. In pretrained transformers, 
the first few tokens act as sinks because:

\begin{enumerate}
\item Positional embeddings for position 0 are unique.
\item Token 0 is often \texttt{[CLS]} or \texttt{<s>}, a natural aggregator.

\end{enumerate}
\textbf{Empirical observation.} Removing sink tokens causes measurable accuracy 
degradation. Preserving them (first 4 in our implementation) maintains 
stability.

\subsection{Local Splash Radius}

For causal decoders, we restrict attention to:

\[
\text{mask}(i, j) = \begin{cases}
1 & \text{if } 0 \leq i - j \leq W \\
1 & \text{if } j < S \\
0 & \text{otherwise}
\end{cases}
\tag{3.8}
\]

where $W$ is the splash radius (default 32) and $S = 4$ is the sink count. 
Non-causal (bidirectional) models use the full attention (no windowing).

\subsection{LoRA Adapters}

LoRA (Hu et al., 2021) parameterizes a weight update:

\[
W_\text{effective} = W_\text{frozen} + B A
\tag{3.9}
\]

with $A \in \mathbb{R}^{r_L \times d_\text{in}}$, $B \in \mathbb{R}^{d_\text{out} \times r_L}$, 
$B = 0$ at initialization.

\textbf{In AdaSplash.} LoRA is added to each attention projection. The 
initial forward pass equals the pretrained model (since $B = 0$).
