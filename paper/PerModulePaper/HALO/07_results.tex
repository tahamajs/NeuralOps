\subsection{Summary}

\begin{itemize}
\item \textbf{Accuracy:} drops -1.2\%---1.9\%.
\item \textbf{Gate distribution:} bimodal (some heads dense, some linear).
\item \textbf{No parameter reduction} (only gate added).
\item \textbf{No speedup without hard routing.}
\item \textbf{All models pass quality gate.}
\end{itemize}
