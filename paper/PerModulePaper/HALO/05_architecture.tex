\subsection{Weight Transfer}

\subsubsection{DistilBERT (Flat)}

Direct copy of \texttt{q\_lin, k\_lin, v\_lin, out\_lin}. \texttt{is\_nested\_encoder = False}.

\subsubsection{RoBERTa (Nested)}

Extract from inner \texttt{self}. \texttt{is\_nested\_encoder = True}; skip own \texttt{out\_proj}.

\subsubsection{GPT-2 (Causal)}

Split fused \texttt{c\_attn}:

\begin{lstlisting}
w = src.c_attn.weight.t()
q_w, k_w, v_w = w.chunk(3, dim=0)
\end{lstlisting}

\subsubsection{Qwen3.5 (GQA + RoPE)}

Direct copy. \texttt{repeat\_kv} for GQA. RoPE applied to Q, K.

\subsection{Handling Nested Encoders}

For RoBERTa/BERT, HALO-ReGLA is injected into \texttt{attention.self}. The 
\texttt{is\_nested\_encoder = True} flag ensures:
\begin{itemize}
\item No \texttt{out\_proj} is applied inside HALO-ReGLA.
\item The outer \texttt{attention.output.dense} applies the output projection.

\end{itemize}
\subsection{Causality}

For decoders, causal masking is applied in the \textbf{dense stream} via:

\begin{lstlisting}
causal_mask = torch.triu(torch.full((L, L), -1e4), diagonal=1)
dense_scores = dense_scores + causal_mask
\end{lstlisting}

For the \textbf{linear stream}, causality is enforced by the prefix sum.

\subsection{Padding Masking}

Both streams handle padding:
\begin{itemize}
\item Dense: \texttt{masked\_fill} with \texttt{-inf}.
\item Linear: zero out invalid K, V before cumsum.

\end{itemize}
\subsection{RoPE Integration}

RoPE is applied to Q, K \textbf{before} both streams:

\begin{lstlisting}
Q, K = apply_rotary_pos_emb(Q, K, cos, sin, position_ids)
\end{lstlisting}

Then dense and linear streams process the rotated Q, K.

\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject HALO-ReGLA into a full model
\begin{lstlisting}
Input:  model M, config c
Output: M with HALO-ReGLA attention

1:  for   in transformer_layers(M) do
2:      src $\leftarrow$ extract_attention( )
3:      if src is None: continue
4:      new $\leftarrow$ HALOReGLAAttention(config=c, pretrained_attn=src)
5:      replace_attention( , new)
6: end for
\end{lstlisting}

\subsection{Failure Handling}

\texttt{inject\_halo\_regla} returns \texttt{None} on failure:

\begin{lstlisting}
try:
    new_layer = HALOReGLAAttention(...)
except Exception:
    raise RuntimeError("copy_weights failed")
\end{lstlisting}
