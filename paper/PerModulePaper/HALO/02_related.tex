
\section{2. Related Work}

\subsection{2.1 Linear Attention}

\textbf{Linear Transformer} (Katharopoulos et al., 2020) replaces softmax with 
$\phi(x) = \mathrm{elu}(x) + 1$, achieving $\mathcal{O}(L)$ complexity via 
the associativity of matrix multiplication.

\textbf{Performer} (Choromanski et al., 2021) uses positive orthogonal random 
features (PORF) for unbiased approximation of softmax.

\textbf{Liquid} (Anonymous et al., 2024) uses a learned kernel for linear attention.

\textbf{HALO-ReGLA's linear branch} uses the same $\mathrm{elu} + 1$ kernel, but 
in a \textbf{hybrid} setting with a \textbf{dense branch} and \textbf{learnable gates}.

\subsection{2.2 Hybrid Attention}

\textbf{H-Transformer} (Zhu \& Soricut, 2021) alternates linear and dense layers.

\textbf{Hyena} (Poli et al., 2023) interleaves implicit convolutions with attention.

\textbf{NHA} (our framework) uses local windows + global RFF.

\textbf{HALO-ReGLA} differs by running the two streams **in parallel within the 
same layer\textbf{ and combining them via }per-head learnable gates**.

\subsection{2.3 Gated Attention}

\textbf{FLASH} (Hua et al., 2022) uses gated attention with learned gates between 
linear and softmax branches. \textbf{HALO-ReGLA} is closely related but 
distinguishes itself by:
\begin{itemize}
\item Rectified kernel (positive features).
\item Explicit prefix-sum formulation.
\item Per-head gating with bias initialization.
\end{itemize}

\textbf{GLA} (Yang et al., 2023) uses gated linear attention with data-dependent 
decay, which is orthogonal to our fusion gate.

\subsection{2.4 Pretrained Weight Transfer}

\textbf{LoRA} (Hu et al., 2021) enables training adapters on frozen base weights.

\textbf{HALO-ReGLA} transfers Q, K, V, O projections from pretrained weights and 
trains only LoRA + gate parameters, preserving the pretrained knowledge.
