
\section{Discussion}

\subsection{Key Takeaways}

\subsubsection{Takeaway 1: Gates Reveal Head Structure}

The learned gates show which heads benefit from dense attention and which 
can use linear. This is a useful \textbf{interpretability} signal.

\subsubsection{Takeaway 2: Layered Hybrid Works}

Early layers need global context; late layers can use linear. This 
validates architectural priors from prior work.

\subsubsection{Takeaway 3: No Speedup Without Hard Routing}

HALO-ReGLA computes both streams. To realize speedup:
\begin{enumerate}
\item Train with both streams.
\item Identify heads where $\bar{g}_h < \theta$.
\item Convert to pure linear inference.

\end{enumerate}
Expected speedup: up to 3$$\times$ if all heads convert.

\subsection{When to Use HALO-ReGLA}

\subsubsection{Recommended}

\begin{itemize}
\item \textbf{Long-context inference} where some heads can be linearized
\item \textbf{Interpretability studies} of head specialization
\item \textbf{Base for hard routing} to linear-only inference

\end{itemize}
\subsubsection{Not Recommended}

\begin{itemize}
\item \textbf{Short sequences} (no benefit)
\item \textbf{Parameter reduction} (use A3/AASVD)
\item \textbf{Immediate speedup} (use pure linear or sparse)

\end{itemize}

\subsection{Open Questions}

\begin{enumerate}
\item \textbf{Learned threshold for hard routing:} Can we learn $\theta$?
\item \textbf{Interaction with KV cache:} Does HALO-ReGLA reduce KV cache?
\item \textbf{Long-context scaling:} How do gates evolve at $L = 4096$?
\item \textbf{Cross-task transfer:} Do gates transfer between tasks?

\end{enumerate}
\subsection{Broader Impact}

\subsubsection{Positive}
\begin{itemize}
\item \textbf{Long-context inference:} Enables more capable applications.
\item \textbf{Interpretability:} Reveals head structure.
\item \textbf{Foundation for routing:} Basis for efficient deployment.

\end{itemize}
\subsubsection{Negative}
\begin{itemize}
\item \textbf{Dual-use:} Enables surveillance at scale.
\item \textbf{Concentration:} Favors large labs.

\end{itemize}
