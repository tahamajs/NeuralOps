\subsection{Known Issues}

\begin{itemize}
\item Windows: \texttt{cp1256} codec issues; set \texttt{PYTHONIOENCODING=utf-8}.
\item CUDA: FP8 requires CUDA >= 11.8.
\item Driver: consumer Ada GPUs may not expose FP8 via driver.

\end{itemize}
