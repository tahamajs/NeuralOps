 2.1 Low-Rank SVD Factorization with LoRA Residuals

For any linear projection $W \in \mathbb{R}^{D\_{\text{in}} \times D\_{\text{out}}}$ with rank bottleneck $r \ll \min(D\_{\text{in}}, D\_{\text{out}})$:
$$W\_1 \in \mathbb{R}^{D\_{\text{in}} \times r}, \quad W\_2 \in \mathbb{R}^{r \times D\_{\text{out}}}$$
Given pretrained weight matrix $W\_{\text{base}}$, singular value decomposition yields:
$$W\_{\text{base}} = U \Sigma V^\top = \sum\_{i=1}^{\min(D\_{\text{in}}, D\_{\text{out}})} \sigma\_i u\_i v\_i^\top$$
Truncating to rank $r$ gives the optimal Frobenius-norm low-rank approximation by the Eckart-Young-Mirsky Theorem:
$$W\_1 = U\_{:, :r} \Sigma\_{:r, :r}^{1/2}, \quad W\_2 = \Sigma\_{:r, :r}^{1/2} V\_{:, :r}^\top$$
To guarantee that the factorized module can adapt to non-linear distribution shifts induced by hybrid attention, each `FactorizedLinear` incorporates a parallel trainable LoRA adapter:
$$Y = X \left( W\_1 W\_2 \right) + \frac{\alpha\_{\text{lora}}}{r} X \left( A B \right) + b$$
where $A \in \mathbb{R}^{D\_{\text{in}} \times r\_{\text{lora}}}$ is initialized via Kaiming uniform distribution and $B \in \mathbb{R}^{r\_{\text{lora}} \times D\_{\text{out}}}$ is initialized to zero ($B \equiv 0$). Consequently, at initialization $t=0$:
$$\Delta W = \frac{\alpha\_{\text{lora}}}{r} A B = 0 \implies Y(0) = X W\_1 W\_2 + b$$
During backpropagation, base factorized matrices $W\_1$ and $W\_2$ remain frozen, while gradients $\frac{\partial \mathcal{L}}{\partial A}$ and $\frac{\partial \mathcal{L}}{\partial B}$ update the adapter parameters.

 2.2 Local Window Attention Formulation

Let $Q, K, V \in \mathbb{R}^{B \times H \times L \times d\_h}$ denote the projected query, key, and value tensors. For local window radius $W$:
$$S\_{i, j}^{\text{local}} = \frac{Q\_i K\_j^\top}{\sqrt{d\_h}} + M\_{i, j}^{\text{local}}$$
where the local attention mask $M\_{i, j}^{\text{local}}$ is defined conditionally:
- **Bidirectional Encoders** (BERT, RoBERTa):
  $$M\_{i, j}^{\text{local}} = \begin{cases}
  0 & \text{if } |i - j| \le W \\
  -10000.0 & \text{otherwise}
  \end{cases}$$
- **Autoregressive Decoders** (GPT-2, Qwen3.5):
  $$M\_{i, j}^{\text{local}} = \begin{cases}
  0 & \text{if } 0 \le i - j \le W \\
  -10000.0 & \text{otherwise (future tokens or beyond window)}
  \end{cases}$$
The local context representation is computed via numerically stabilized softmax:
$$A\_{i, :}^{\text{local}} = \operatorname{softmax}\left(S\_{i, :}^{\text{local}}\right), \quad O\_i^{\text{local}} = \sum\_{j=1}^L A\_{i, j}^{\text{local}} V\_j$$

 2.3 Global Kernelized Linear Attention with Token Pruning

Global linear attention maps queries and keys into an implicit reproducing kernel Hilbert space using the non-negative feature map:
$$\phi(u) = \operatorname{ELU}(u) + 1.0 = \begin{cases}
u + 1.0 & \text{if } u > 0 \\
e^u & \text{if } u \le 0
\end{cases}$$
Notice that $\phi(u) > 0$ strictly for all $u \in \mathbb{R}$, guaranteeing non-negativity without upper-bound saturation.

 Token Pruning Mechanism:
A lightweight projection $W\_p \in \mathbb{R}^{D \times 1}$ with sigmoid activation computes importance score $g\_t$:
$$g\_t = \sigma(x\_t W\_p + b\_p) \in (0, 1)$$
The projected keys and values are modulated prior to accumulation:
$$K\_{g, t} = g\_t \odot K\_t, \quad V\_{g, t} = g\_t \odot V\_t$$

 Bidirectional Mode (Encoders):
Under bidirectional attention, the associative property of matrix multiplication allows global pre-accumulation of key-value and key-normalizer statistics:
$$S = \sum\_{j=1}^L \phi(K\_{g, j})^\top V\_{g, j} \in \mathbb{R}^{B \times H \times d\_h \times d\_h}, \quad Z = \sum\_{j=1}^L \phi(K\_{g, j})^\top \in \mathbb{R}^{B \times H \times d\_h \times 1}$$
The global output for query token $i$ is evaluated in $\mathcal{O}(1)$ tensor operations:
$$O\_i^{\text{global}} = \frac{\phi(Q\_i) S}{\phi(Q\_i) Z + \epsilon\_{\text{norm}}}$$
Time complexity is $\mathcal{O}(B \cdot H \cdot L \cdot d\_h^2)$ with memory $\mathcal{O}(B \cdot H \cdot d\_h^2)$ independent of sequence length $L$.

 2.4 Mathematical Proofs

 Theorem 1 (Strict Positivity and Numerical Invertibility of ELU+1 Normalizer)
*Let $\phi(u) = \operatorname{ELU}(u) + 1.0$. For any query $Q \in \mathbb{R}^{d\_h}$ and keys $K\_j \in \mathbb{R}^{d\_h}$ with $g\_j > 0$, the denominator:*
$$D\_i = \phi(Q\_i) Z\_i + \epsilon = \sum\_{d=1}^{d\_h} \phi(Q\_{i, d}) \left( \sum\_{j=1}^i \phi(K\_{g, j, d}) \right) + \epsilon$$
*satisfies $D\_i \ge \epsilon > 0$. Consequently, division by zero or NaN gradients cannot occur.*

**Proof:**
1. By definition of ELU:
   - For $u > 0$, $\phi(u) = u + 1 > 1 > 0$.
   - For $u \le 0$, $\phi(u) = e^u \in (0, 1]$.
   Thus, $\phi(u) > 0$ strictly for all $u \in \mathbb{R}$.
2. For all valid tokens $j$, key gating $g\_j = \sigma(\cdot) \in (0, 1)$, so $K\_{g, j} = g\_j K\_j \in \mathbb{R}^{d\_h}$. Since $\phi(K\_{g, j, d}) > 0$ and $\phi(Q\_{i, d}) > 0$, each product term $\phi(Q\_{i, d}) \phi(K\_{g, j, d}) > 0$.
3. Summing across valid head dimensions $d \in \{1, \dots, d\_h\}$ and sequence indices yields a strictly non-negative inner product:
   $$\sum\_{d=1}^{d\_h} \phi(Q\_{i, d}) Z\_{i, d} \ge 0$$
4. Adding $\epsilon = 10^{-6}$ strictly bounds the denominator from below: $D\_i \ge \epsilon > 0$. Division by zero is mathematically impossible. $\blacksquare$

 Theorem 2 (Zero Future-Token Information Leakage in Causal Decoders)
*In autoregressive mode (`is\_decoder=True`), the output $O\_t$ at time step $t$ has zero gradient with respect to any future input $X\_{t+k}$ ($k \ge 1$):*
$$\frac{\partial O\_t}{\partial X\_{t+k}} \equiv 0, \quad \forall k \ge 1$$

**Proof:**
1. In causal mode, $O\_t = O\_t^{\text{local}}$.
2. In the local pathway:
   $$S\_{t, j}^{\text{local}} = \frac{Q\_t K\_j^\top}{\sqrt{d\_h}} + M\_{t, j}^{\text{local}}$$
   For all $j > t$, $M\_{t, j}^{\text{local}} = -10000.0$. In softmax:
   $$\exp(S\_{t, j}^{\text{local}}) = \exp\left(\frac{Q\_t K\_j^\top}{\sqrt{d\_h}} - 10000\right) \approx 0 \implies A\_{t, j}^{\text{local}} = 0, \quad \forall j > t$$
   Hence $O\_t^{\text{local}} = \sum\_{j=1}^t A\_{t, j}^{\text{local}} V\_j$, which is independent of $X\_{t+k}$.
3. Applying the chain rule:
   $$\frac{\partial O\_t}{\partial X\_{t+k}} = \frac{\partial O\_t^{\text{local}}}{\partial X\_{t+k}} = 0$$
   Strict causality is preserved. $\blacksquare$
