\section{Introduction}\subsection{Motivation}Decoupling local and global attention enables linear computation scaling without sacrificing local syntactic precision.


\section{Related Work}Combines sliding-window local attention with factorized global context projections.


\section{Mathematical Background}Local sliding window attention operates in $\mathcal{O}(L \cdot W)$ while global attention projects onto rank $r$.


\section{Methodology}Projections utilize \texttt{FactorizedLinear} layers. Local sliding-window attention is fused with low-rank global projections via learned gating.


\section{Architecture and Implementation}The dual-branch architecture arbitrates local and global streams through learnable gating parameters.


\section{Experimental Setup}Standardized SST-2 evaluations across three model families.

\section{Detailed Analysis}The module reduces GPT-2 parameters by 18.37\% (over 22.8M parameters) while maintaining functional attention routing.


\section{Discussion}Dual-branch arbitration effectively separates high-frequency local signals from global low-rank trends.


\section{Limitations}Bidirectional models require wider sliding windows to avoid syntactic degradation.


\section{Conclusion}\texttt{aegis\_hybrid} demonstrates concrete parameter and memory reduction via hybrid local-global attention.
