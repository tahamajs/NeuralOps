\section{05 Architecture}

 5. Architecture and Implementation
Projections use `FactorizedLinear` ($r=128, r\_{	ext{lora}}=32$). The gating network dynamically arbitrates between local and global representations.


 4. Step-by-Step Tensor Execution Trace \& Dimensions


```
Given: Batch Size B=8, Sequence Length L=128, Hidden Dim D=768, Heads H=12, Head Dim d\_h=64, Window W=128

1. Input Tensor:
   X ∈ ℝ^{8 \times  128 \times  768}

2. Projection Stage (FactorizedLinear with LoRA):
   q = X W\_Q1 W\_Q2 + (α/r) X A\_Q B\_Q + b\_Q    -->  [8, 128, 768]
   k = X W\_K1 W\_K2 + (α/r) X A\_K B\_K + b\_K    -->  [8, 128, 768]
   v = X W\_V1 W\_V2 + (α/r) X A\_V B\_V + b\_V    -->  [8, 128, 768]

3. Head Splitting \& Reshaping:
   Q: [8, 12, 128, 64]
   K: [8, 12, 128, 64]
   V: [8, 12, 128, 64]

4. Positional Embedding Application:
   Q\_rope, K\_rope = apply\_rotary\_emb(Q, K, position\_ids)  -->  [8, 12, 128, 64]

5. Local Window Attention Pathway:
   scores = (Q\_rope @ K\_rope^T) / √64                      -->  [8, 12, 128, 128]
   scores = scores.masked\_fill(~band\_mask, -10000.0)      -->  [8, 12, 128, 128]
   attn\_local = softmax(scores, dim=-1)                   -->  [8, 12, 128, 128]
   out\_local = attn\_local @ V                             -->  [8, 128, 12, 64]

6. Global Linear Pathway (Bidirectional Encoders):
   phi\_Q = ELU(Q\_rope) + 1.0                              -->  [8, 12, 128, 64]
   phi\_K = ELU(K\_rope) + 1.0                              -->  [8, 12, 128, 64]
   KV = phi\_K^T @ V                                       -->  [8, 12, 64, 64]
   K\_sum = phi\_K.sum(dim=2)                               -->  [8, 12, 64]
   out\_global = (phi\_Q @ KV) / (phi\_Q @ K\_sum + ε)        -->  [8, 128, 12, 64]

7. Gated Convex Fusion:
   α = σ(X @ W\_fusion + 1.8)                              -->  [8, 128, 12, 1]
   fused = α * out\_local + (1 - α) * out\_global           -->  [8, 128, 12, 64]

8. Concatenation \& Output Factorized Projection:
   fused = fused.reshape(8, 128, 768)
   Output = fused W\_O1 W\_O2 + (α/r) fused A\_O B\_O + b\_O   -->  [8, 128, 768]
```
