\section{01 Intro}

 1. Introduction
Structured pruning enforces hardware-efficient patterns (such as NVIDIA 2:4 sparsity) but can severely disrupt intermediate representations. `admm\_pruner` introduces dynamic $
ho$ adjustment and layer-wise feature distillation to steer weight updates towards sparse projection manifolds without sacrificing task accuracy.



\subsection{1. Executive Abstract \& Theoretical Motivation}
Pruning neural network weight tensors without sacrificing performance is a fundamental challenge in model compression. Standard magnitude pruning suffers from greedy decisions that create unrecoverable optimization bottlenecks. \textbf{ADMM Pruner} addresses this problem by formulating model pruning as a constrained non-convex optimization problem solved via the \textbf{Alternating Direction Method of Multipliers (ADMM)} with dynamic penalty parameter ($\rho$) scheduling and Straight-Through Estimator (STE) gradient backpropagation.

By decomposing the hard structural sparsity constraint into a sequence of tractable subproblems, ADMM decouples continuous parameter optimization from discrete combinatorial structural pruning. The algorithm alternates between updating continuous weights $W$, projecting onto the sparse constraint set $Z$ (unstructured, block, or 2:4 semi-structured), and updating a dual multiplier tensor $U$ that tracks constraint residual drift.
