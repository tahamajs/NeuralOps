\subsection{Summary}

\begin{itemize}
\item Encoder path: \textbf{fails} (25--30\% drop)
\item Decoder fallback: \textbf{no-op} (0\% delta)
\item Parameters: \textbf{increase} by ~0.9\%
\item Verdict: \textbf{not recommended for any use case tested}
\end{itemize}
