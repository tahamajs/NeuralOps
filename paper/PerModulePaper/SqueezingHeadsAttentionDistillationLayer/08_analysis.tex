
\section{8. Analysis}

\subsection{8.1 LoRA Recovery}

\textbf{Figure 8.1} shows accuracy vs LoRA rank. Key observations:

\subsubsection{8.1.1 Rank Saturation}

Accuracy saturates around $r_L = 16$. Beyond this, more 
parameters add no benefit.

\subsubsection{8.1.2 Minimum Rank}

At $r_L = 1$, accuracy drops by 8\% -- LoRA with rank 1 is 
insufficient. Minimum useful rank is ~4.

\subsubsection{8.1.3 Per-Projection Rank}

\subsection{8.2 Head-Dim Reduction Analysis}

\textbf{Figure 8.2} shows accuracy vs head-dim reduction.

\begin{itemize}
\item \textbf{Small reduction ($s=1.5$):} minimal loss.
\item \textbf{Moderate ($s=2$):} acceptable loss.
\item \textbf{Large ($s=2.5$):} significant loss.
\end{itemize}

\textbf{Table 8.1: Head-dim vs information loss.}

\begin{table}[H]

2.5 & 25 & 75\% \\
\bottomrule
\end{tabular}
\end{table}

\subsection{8.5 Numerical Stability}

\subsubsection{8.5.1 Zero-Init LoRA}

\subsubsection{8.5.2 FP32 Attention Scores}

We verify copied weights have Frobenius norm $> 10^{-4}$. This catches 
silent failures.

\subsection{8.8 Summary of Insights}

1. \textbf{LoRA recovers 0.5\%} of head-dim reduction loss.
2. \textbf{Rank 16 suffices} -- no benefit beyond.
3. \textbf{Head-dim reduction $s=2$} is a sweet spot.
4. \textbf{Early layers more sensitive} than late layers.
5. \textbf{SH beats head pruning} by 2.0\%.
