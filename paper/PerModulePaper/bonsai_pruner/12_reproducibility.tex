\section{Reproducibility Statement}
All code, model weights, and benchmark evaluation scripts are packaged to guarantee exact reproducibility:
\begin{lstlisting}[language=bash]
# 1. Run unified compression sweep
python -u Codes/framework/run_compressor.py \
    --model distilbert-base-uncased \
    --compressor bonsai\_pruner \
    --dataset sst2 \
    --batch_size 64 \
    --recovery_steps 50 \
    --output_dir results/unified_bonsai\_pruner

# 2. Run multi-model verification suite
python -u scripts/run_all_4_bonsai\_pruner.py \
    --models distilbert,roberta,gpt2 \
    --recovery_steps 50
\end{lstlisting}
