\section{Introduction}\subsection{Motivation}Static attention arbitration fails to adapt to token content. AEGIS-V3 introduces dynamic token-wise context gating.


\section{Related Work}Dynamic context gating provides content-aware arbitration between local and global attention paths.


\section{Mathematical Background}Token-level gating arbitrates between local sliding window and global linear streams.


\section{Methodology}Projections combine factorized base weights with LoRA adapters. Token gating arbitrates local and global streams.


\section{Architecture and Implementation}Universal multi-architecture support across DistilBERT, RoBERTa, GPT-2, and Qwen.


\section{Experimental Setup}Standardized SST-2 evaluation across three representative model families.

\section{Detailed Analysis}Token gating effectively routes syntax-heavy tokens to local sliding-window heads while preserving bounded memory.


\section{Discussion}Dynamic interpolation avoids rigid head partitioning artifacts.


\section{Limitations}Additional gating parameters increase optimization dimensionality during fine-tuning.


\section{Conclusion}\texttt{aegis\_v3} validates learnable gating for dynamic local-global attention integration.
