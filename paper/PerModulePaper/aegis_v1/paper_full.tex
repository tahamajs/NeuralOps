\section{Introduction}\subsection{Motivation}Quadratic self-attention imposes uniform compute across token interactions. AEGIS-V1 decomposes attention heads into localized sliding-window and global linear kernel branches.


\section{Related Work}AEGIS-V1 integrates sliding-window sparse attention with kernelized linear attention and factorized projections.


\section{Mathematical Background}Local attention computes exact softmax within window $W$, while linear kernel attention achieves $\mathcal{O}(L \cdot d)$ sequence scaling.


\section{Methodology}Projections utilize factorized base tensors with LoRA adapters. Attention heads are split into local sliding-window and global linear kernel subsets.


\section{Architecture and Implementation}The module provides full support for RoPE rotary embeddings, GQA head replication, and cross-architecture injection.


\section{Experimental Setup}Standardized SST-2 benchmark suite across DistilBERT, RoBERTa, and GPT-2 backbones.

\section{Detailed Analysis}On RoBERTa, AEGIS-V1 achieves 79.13\% accuracy, surpassing the dense baseline (78.56\%) while maintaining bounded memory consumption.


\section{Discussion}Split-head partitioning isolates localized syntactic heads from long-range associative aggregations.


\section{Limitations}Shallow architectures (DistilBERT) experience capacity constraints when heads are split across local and global duties.


\section{Conclusion}\texttt{aegis\_v1} demonstrates the viability of hybrid split-head attention across modern language backbones.
