 2.2 Spectron Spectral Entropy Router (Lagrangian Formulation)

Rather than treating routing as an unconstrained classification problem, Spectron formulates routing as a **Lagrangian-regularized resource allocation problem**.

For token vector $x\_t \in \mathbb{R}^D$:
1. **Spectral Feature Energy Distribution**:
   $$p\_{t, d} = \frac{x\_{t, d}^2}{\sum\_{k=1}^D x\_{t, k}^2 + \epsilon}, \quad d \in \{1, \dots, D\}$$

2. **Per-Token Spectral Entropy**:
   $$\mathcal{S}(x\_t) = -\sum\_{d=1}^D p\_{t, d} \ln(p\_{t, d} + \epsilon)$$
   High entropy $\mathcal{S}(x\_t)$ indicates rich, multi-modal semantic representations requiring expressive local or global attention; low entropy indicates concentrated, low-rank representations suitable for linear recurrence.

3. **Cost-Regularized Routing Logits**:
   Given computational branch costs $\mathbf{c} = [c\_{\text{loc}}, c\_{\text{glob}}, c\_{\text{lin}}]^\top$:
   $$\mathbf{z}\_t = \frac{\left(W\_h x\_t + b\_h\right) \cdot \mathcal{S}(x\_t) - \lambda \mathbf{c}}{\tau}$$
   $$\boldsymbol{\alpha}\_t = \operatorname{Softmax}(\mathbf{z}\_t) = [\alpha\_{t, \text{loc}}, \alpha\_{t, \text{glob}}, \alpha\_{t, \text{lin}}]^\top$$
   where $\tau$ denotes temperature and $\lambda$ denotes the Lagrange multiplier controlling cost penalization.

---

 2.3 Branch 1: Local Sliding-Window Attention ($\mathcal{O}(N \cdot W)$)

Computes full-rank, exact softmax attention within a localized receptive window of radius $W$:
$$A\_{i, j} = \frac{Q\_i K\_j^\top}{\sqrt{d}} + M\_{i, j}$$

Where the band-limiting and causal mask $M\_{i, j}$ is defined as:
$$M\_{i, j} = \begin{cases}
0, & \text{if } |i - j| \le W \quad (\text{and } j \le i \text{ for decoders}) \\
-\infty, & \text{otherwise}
\end{cases}$$

$$\operatorname{Out}\_{\text{loc}} = \operatorname{Softmax}(A) V$$

---

 2.4 Branch 2: True $\mathcal{O}(N)$ Global Low-Rank SVD Linear Attention

Standard linear attention uses kernel feature mapping $\phi(x) = \operatorname{ELU}(x) + 1.0 > 0$.
The flattened projections are mapped to a rank-$r$ subspace using orthogonal matrix $U \in \mathbb{R}^{D \times r}$:
$$\phi\_Q = \phi(Q\_{\text{flat}} U), \quad \phi\_K = \phi(K\_{\text{flat}} U)$$

 Causal Decoders (Prefix Cumulative Sum Formulation)
For autoregressive generation, the associative prefix states are accumulated causal-first without materializing the $N \times N$ matrix:
$$S\_t = \sum\_{j=1}^t \phi\_K(x\_j)^\top V\_j \in \mathbb{R}^{r \times D}$$
$$z\_t = \sum\_{j=1}^t \phi\_K(x\_j)^\top \in \mathbb{R}^{r \times 1}$$
$$\operatorname{Out}\_{\text{glob}}(x\_t) = \frac{\phi\_Q(x\_t) S\_t}{\phi\_Q(x\_t) z\_t + \epsilon}$$

Implemented via `torch.cumsum(phi\_K.unsqueeze(-1) * V.unsqueeze(-2), dim=1)` with strict $\mathcal{O}(N \cdot r \cdot D)$ complexity.

 Bidirectional Encoders (Associative Matrix Multiplication)
For bidirectional models, the full sequence prefix matrix is associative:
$$K V = \phi\_K^\top V \in \mathbb{R}^{r \times D}$$
$$Z = \sum\_{j=1}^N \phi\_K(x\_j) \in \mathbb{R}^{1 \times r}$$
$$\operatorname{Out}\_{\text{glob}} = \frac{\phi\_Q (K V)}{\phi\_Q Z^\top + \epsilon}$$

---

 2.5 Branch 3: True $\mathcal{O}(N)$ Linear State Recurrence

Linear state-space recurrence computes an Exponential Moving Average (EMA) representation governed by learnable decay $\gamma = \sigma(A) \in (0, 1)$:
$$y\_t = \gamma y\_{t-1} + B x\_t, \quad \text{Out}\_{\text{lin}}(x\_t) = C y\_t$$

Using the unrolled recurrence identity $y\_t = \gamma^t \sum\_{i=1}^t (B x\_i) \gamma^{-i}$, this is vectorized in $\mathcal{O}(N)$ parallel time:
$$y = \gamma^{\text{pos}} \odot \operatorname{cumsum}\left( (B X) \odot \gamma^{-\text{pos}}, \text{dim}=1 \right)$$
$$y = y \odot C$$

For bidirectional encoders, a mirrored anti-causal backward pass is computed on reversed sequences, fused via a learnable bidirectional gate $g \in [0, 1]$:
$$\operatorname{Out}\_{\text{lin}} = g \cdot y\_{\text{fwd}} + (1 - g) \cdot y\_{\text{bwd}}$$

---

 2.6 Functional FP8 Quantization Simulation

To accurately model 8-bit inference without hardware dependency, `fp8\_cast\_simulate` provides dynamic range scaling for both E4M3 and E5M2 standard formats:
$$s = \frac{V\_{\max}}{\max(|X|) + \epsilon}$$
$$X\_{\text{scaled}} = \operatorname{clip}\left(X \cdot s, -V\_{\max}, V\_{\max}\right)$$
$$X\_{\text{sim}} = \frac{\operatorname{quantize}(X\_{\text{scaled}})}{s}$$

- **E4M3** ($V\_{\max} = 448.0$, 3 mantissa bits): Highest precision, suitable for weights and attention activations.
- **E5M2** ($V\_{\max} = 57344.0$, 2 mantissa bits): Extended dynamic range, suitable for gradients and linear recurrence states.
