\section{Discussion}

\subsection{Key Takeaways}

\subsubsection{Takeaway 1: Truly O(1) Memory}

DecayLinearAttention uses 16 KB of state memory per layer, independent of 
sequence length. This is a strict improvement over CHELA-SLAY and other 
cumsum-based methods.

\subsubsection{Takeaway 2: Data-Dependent Decay Works}

The learned per-token decay $\lambda_{h,t}$ improves accuracy by 
2.0\% over fixed decay.

\subsubsection{Takeaway 3: Cross-Attention Support}

The same recurrence works for cross-attention, enabling encoder-decoder 
models.

\subsection{When to Use DecayLinearAttention}

\subsubsection{Recommended}
\begin{itemize}
\item \textbf{Long-context inference} ($L \geq 512$).
\item \textbf{Memory-constrained environments.}
\item \textbf{Encoder-decoder models} (cross-attention).
\item \textbf{Streaming decoding.}

\end{itemize}
\subsubsection{Not Recommended}
\begin{itemize}
\item \textbf{Very short sequences} ($L \leq 256$).
\item \textbf{When softmax is essential.}

\end{itemize}
\subsection{Decision Flowchart}

\begin{lstlisting}
Need O(1) memory at long L? --- Yes --- Use DecayLinear
  | No
   
Need softmax behavior? --- Yes --- Use standard attention
  | No
   
Consider CHELA-SLAY (hybrid)
\end{lstlisting}

\subsection{Broader Impact}

\subsubsection{Positive}
\begin{itemize}
\item Enables long-context on consumer hardware.
\item Reduces memory footprint dramatically.
\item Cross-attention support broadens applicability.

\end{itemize}
\subsubsection{Negative}
\begin{itemize}
\item Linear attention may not capture all softmax behaviors.
\item Feature map choice affects accuracy.

\end{itemize}
