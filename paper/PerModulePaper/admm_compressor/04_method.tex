 2. Mathematical Formulations \& Matrix Decompositions


 2.1 Optimization Objective

Let $W \in \mathbb{R}^{N \times M}$ be the target weight matrix of a linear layer. We define a joint operator $\Phi\_{S, b}(W)$ that maps continuous weights into a sparse $b$-bit quantized matrix.

1. **Sparsity Mask Selection**:
   Let $k = \lfloor (1 - S) \cdot N \cdot M \rfloor$ be the number of non-zero parameters to retain. The magnitude threshold $\tau$ is defined by:
   $$\tau = \text{TopK}\_{k} \left( \{ |W\_{i,j}| \}\_{i=1, j=1}^{N, M} \right)$$
   The binary mask matrix $M \in \{0, 1\}^{N \times M}$ is:
   $$M\_{i,j} = \begin{cases} 1 & \text{if } |W\_{i,j}| \ge \tau \\ 0 & \text{otherwise} \end{cases}$$
   The intermediate pruned weight matrix is $W\_{\text{pruned}} = W \odot M$.

2. **Symmetric Low-Bit Quantization**:
   Given target bit width $b \in \{2, 4, 8\}$, the maximum discrete integer representation is:
   $$Q\_{\text{max}} = 2^{b - 1} - 1$$
   The continuous weights are scaled and clamped into $[-Q\_{\text{max}}, Q\_{\text{max}}]$:
   $$W\_{\text{scaled}} = \text{Clamp}\left( W\_{\text{pruned}} \cdot Q\_{\text{max}}, -Q\_{\text{max}}, Q\_{\text{max}} \right)$$
   $$W\_{\text{quant}} = \frac{\lfloor W\_{\text{scaled}} \rceil}{Q\_{\text{max}}}$$
