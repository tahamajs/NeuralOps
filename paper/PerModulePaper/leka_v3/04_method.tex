\section{Method}

\subsection{Overview}

LEKAv3 replaces standard attention with a two-branch mechanism:

\begin{lstlisting}
    Q, K, V
        |
         
    +---------------------------+
    | RoPE (if applicable)      |
    +-----------+---------------+
                |
        +-------+-------+
                         
    +-----------+  +---------------+
    | Global    |  | Local         |
    | Landmark  |  | Sliding       |
    | Branch    |  | Window        |
    +-----+-----+  +-------+-------+
          |                |
          +--------+-------+
                    
          +-----------------+
          | Gated Fusion    |
          | $\sigma$(g) per head   |
          +--------+--------+
                    
             Output
\end{lstlisting}

\subsection{Kernel Feature Map}

We map each head vector $x \in \mathbb{R}^{d_h}$ to feature space:

\[
\phi(x) = \frac{1}{\sqrt{d_\text{feat}}} \begin{pmatrix} \cos(W_1 x) \\ \sin(W_1 x) \end{pmatrix}
\tag{4.1}
\]

where $W_1 \in \mathbb{R}^{d_h \times d_\text{feat}/2}$ is a random 
projection matrix. Feature dimension is $d_\text{feat}$ (default 128).

\textbf{Multi-scale.} We use two projections $W_1, W_2$ with different scales 
$\sqrt{d_h/2}$ and $\sqrt{d_h/4}$. The concatenated feature dimension is 
$d_\text{feat} + d_\text{feat}/2 = 1.5 d_\text{feat}$.

\textbf{Why cos/sin?} These provide a bounded, well-conditioned approximation 
of the softmax kernel without the exploding variance of pure RFF.

\subsection{Landmark Selection}

\subsubsection{Scorer}

A small MLP scores each key-feature:

\[
s_i = f_\theta(K_\text{feat}[i]) \in \mathbb{R}
\tag{4.2}
\]

where $f_\theta$ is: Linear($2 d_\text{feat}$, 64) $\to$ GELU $\to$ Linear(64, 1).

\subsubsection{Selection}

We retain the top-$L_\text{land}$ indices:

\[
\mathcal{L} = \text{TopK}(s, L_\text{land})
\tag{4.3}
\]

with the constraint that index 0 is always included:

\[
s_0 \leftarrow 10^4
\tag{4.4}
\]

Padding tokens are masked:

\[
s_i \leftarrow -10^4 \quad \text{for padding}
\tag{4.5}
\]

\subsubsection{Effective Landmark Count}

To balance compute and accuracy across sequence lengths:

\[
L_\text{land} = \min(N, \max(L_0, \lceil N/2 \rceil))
\tag{4.6}
\]

where $L_0$ is the base budget (default 64). This means:
\begin{itemize}
\item Short sequences ($N \leq L_0$): $L_\text{land} = L_0$
\item Medium ($L_0 < N \leq 2 L_0$): $L_\text{land} = N/2$
\item Long ($N > 2 L_0$): $L_\text{land} = N/2$

\end{itemize}
\subsection{Global Landmark Attention}

\subsubsection{Landmark Features}

Gather landmark features and values:

\[
K_\mathcal{L} = K_\text{feat}[\mathcal{L}], \qquad V_\mathcal{L} = V[\mathcal{L}]
\tag{4.7}
\]

\subsubsection{Correlation Matrix}

LEKAv3 applies a per-head learnable correlation:

\[
V_\mathcal{L}^\text{adj} = V_\mathcal{L} \cdot W_\text{corr}
\tag{4.8}
\]

where $W_\text{corr} \in \mathbb{R}^{d_h \times d_h}$ is initialized to 
identity. This lets each head adjust the landmark values.

\subsubsection{Attention}

\[
\text{attn}_{ij} = \text{softpick}\!\left(\phi(q_i) \cdot \phi(k_{\mathcal{L}_j})\right)
\tag{4.9}
\]

The output:

\[
\text{Out}_\text{land}[i] = \sum_j \text{attn}_{ij} \cdot V_\mathcal{L}^\text{adj}[j]
\tag{4.10}
\]

\subsubsection{Causal Masking}

For decoders:

\[
\text{attn}_{ij} \leftarrow -\infty \quad \text{if } \mathcal{L}_j > i
\tag{4.11}
\]

The mask uses original positions from \texttt{land\_idx}.

\subsection{Local Sliding Window}

\subsubsection{Window Definition}

\[
\text{window}(i, j) = |i - j| \leq W/2
\tag{4.12}
\]

\subsubsection{Local Attention}

Standard scaled dot-product:

\[
\text{scores}_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_h}} \cdot \mathbb{1}[\text{window}(i,j)]
\tag{4.13}
\]

For decoders, additionally mask $j > i$:

\[
\text{scores}_{ij} \leftarrow -\infty \quad \text{if } j > i
\tag{4.14}
\]

\subsubsection{Output}

\[
\text{Out}_\text{local} = \text{softmax}(\text{scores}) \cdot V
\tag{4.15}
\]

\subsection{Gated Fusion}

The final output combines the two branches:

\[
\text{Out} = \sigma(g) \cdot \text{Out}_\text{land} + (1 - \sigma(g)) \cdot \text{Out}_\text{local}
\tag{4.16}
\]

where $g \in \mathbb{R}^H$ is a per-head learnable bias. We initialize 
$g = 2.0$ so that $\sigma(g) \approx 0.88$, biasing the model toward the 
global branch initially.

\textbf{Why this initialization?} The landmark branch provides global context 
which is more important at the start. As training progresses, the gate can 
shift toward local.

\subsection{Full Algorithm}

\textbf{Algorithm 1:} LEKAv3 forward
\begin{lstlisting}
Input:  X $\in$ R^{B$$\times$L$$\times$d}, attention_mask
Output: Y $\in$ R^{B$$\times$L$$\times$d}

1:  Q $\leftarrow$ X W_Q; K $\leftarrow$ X W_K; V $\leftarrow$ X W_V
2:  if RoPE: Q, K $\leftarrow$ RoPE(Q, K)
3:  if GQA: K, V $\leftarrow$ repeat_kv(K, V)
4:  Q_feat $\leftarrow$  (Q); K_feat $\leftarrow$  (K)
5:  s $\leftarrow$ landmark_scorer(K_feat)
6:  s[0] $\leftarrow$ 1e4; s[padding] $\leftarrow$ -1e4
7:  L $\leftarrow$ TopK(s, L_land)
8:  K_L $\leftarrow$ K_feat[L]; V_L $\leftarrow$ V[L]
9:  attn_land $\leftarrow$ softpick(Q_feat @ K_L^T)
10: if causal: attn_land $\leftarrow$ mask(attn_land, L > i)
11: Out_land $\leftarrow$ attn_land @ (V_L @ W_corr)
12: scores_local $\leftarrow$ Q @ K^T / $\sqrt{}$d_h
13: scores_local $\leftarrow$ mask_window(scores_local)
14: if causal: scores_local $\leftarrow$ mask_causal(scores_local)
15: Out_local $\leftarrow$ softmax(scores_local) @ V
16: g $\leftarrow$ $\sigma$(gate)
17: Out $\leftarrow$ g   Out_land + (1-g)   Out_local
18: Y $\leftarrow$ Out_proj(Out)
19: return Y
\end{lstlisting}

\textbf{Comparison to standard attention:} $\mathcal{O}(L^2 d_h)$. LEKAv3 is linear 
when $L_\text{land}, W \sim \mathcal{O}(1)$.

For $L = 128$:
\begin{itemize}
\item Standard: $L^2 = 16{,}384$
\item LEKAv3: $L \cdot L_\text{land} + L \cdot W = 128 \cdot 64 + 128 \cdot 16 = 10{,}240$

\end{itemize}
For $L = 512$:
\begin{itemize}
\item Standard: $262{,}144$
\item LEKAv3: $512 \cdot 256 + 512 \cdot 16 = 139{,}264$

\end{itemize}
Speedup grows with $L$.

\subsection{Theoretical Notes}

\subsubsection{Kernel Approximation}

Under the RFF guarantee (Rahimi \& Recht, 2007):

\[
\sup_{x, y} |\phi(x)^\top \phi(y) - e^{x \cdot y}| \leq \epsilon
\tag{4.17}
\]

with $d_\text{feat} = \mathcal{O}(d_h \log(1/\epsilon^2))$.

\subsubsection{Landmark Selection Guarantee}

\textbf{Claim.} If landmarks are chosen to maximize coverage of the key 
distribution, then landmark attention approximates full attention.

\textbf{Sketch.} Given the query's attention concentrates on a small set of 
keys (Zhang et al., 2023), selecting those keys as landmarks preserves 
the output. $\square$

\subsubsection{Causality}

\textbf{Claim.} For decoders, output at position $i$ depends only on inputs 
$j \leq i$.

\textbf{Proof.} Both the landmark attention (via causal mask on original 
positions) and the local attention (via triangular mask) enforce $j \leq i$. 
The gate is a scalar independent of positions. $\square$
