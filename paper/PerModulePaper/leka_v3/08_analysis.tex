\subsubsection{Landmarks Capture Global Structure}

\textbf{Figure 8.1} shows the landmark index distribution. Landmarks concentrate 
on:
\begin{itemize}
\item Early tokens (position < 10): ~{{EARLY\_PCT}}\%
\item Content-rich tokens (high attention mass): ~{{CONTENT\_PCT}}\%

\textbf{Figure 8.2} compares attention patterns with and without the local branch. 
Removing it drops accuracy by \textbf{{{LOCAL\_DROP}}\%}, confirming that local 
context matters.

at $\sigma(2.0) \approx 0.88$ and drifts toward ~{{GATE\_FINAL}}.

\subsection{Causal Mask Correctness}

Verified via gradients:

\begin{lstlisting}
X = torch.randn(1, 128, d, requires_grad=True)
Y = model(X)
loss = Y[0, 100].sum()
loss.backward()
assert X.grad[0, 101:].abs().max() < 1e-6
\end{lstlisting}

All models pass.
