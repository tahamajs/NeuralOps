
\section{9. Discussion}

\subsection{9.1 Key Takeaways}

\subsubsection{9.1.1 Takeaway 1: Infini-Attention is Not a Compressor}

Parameter count increases by ~{{D\_PARAM\_PCT}}\% due to memory + LoRA.

\subsubsection{9.1.2 Takeaway 2: Long-Context Efficiency}

For $L \gg W + d_c$, Infini-Attention is $\mathcal{O}(L(W + d_c))$ vs 
baseline $\mathcal{O}(L^2)$. For $L = 4096$, $W = d_c = 128$, this is 
\textbf{16$\times$ faster} in attention.

\subsubsection{9.1.3 Takeaway 3: $\beta$ Init is Critical}

$\beta = -5$ preserves pretrained behavior at start. $\beta = 0$ gives 
50/50 fusion and destabilizes training.

\subsection{9.2 When to Use Infini-Attention}

\subsubsection{Recommended}

\begin{itemize}
\item \textbf{Long-context inference} ($L > 512$)
\end{itemize}
\begin{itemize}
\item \textbf{Multi-architecture deployment}
\end{itemize}
\begin{itemize}
\item \textbf{Combined with AASVD} for both compression and long context
\end{itemize}

\subsubsection{Not Recommended}

\begin{itemize}
\item \textbf{Short sequences} ($L \leq 256$) -- no benefit
\end{itemize}
\begin{itemize}
\item \textbf{Storage-constrained deployment} -- increases size
\end{itemize}
\begin{itemize}
\item \textbf{Cross-attention tasks} -- not supported
\end{itemize}

\subsection{9.3 Decision Flowchart}

\begin{lstlisting}
Long sequence (L > 512)? --- Yes --- Use Infini-Attention
  | No
   
Need to reduce model size? --- Yes --- Use AASVD or A3
  | No
   
Use standard attention
\end{lstlisting}

\subsection{9.5 Interaction with Other Methods}

\textbf{Compositional pipeline:}

1. AASVD compresses base model $\to$ smaller
2. Infini-Attention adds long-context $\to$ faster at long L
3. Both recover with LoRA

\subsection{9.6 Open Questions}

1. \textbf{Optimal $d_c$:} Depends on task and $L$?
2. \textbf{$\beta$ schedule:} Should $\beta$ be scheduled during training?
3. \textbf{Multiple memories:} Can we have $K$ memory matrices?
4. \textbf{Interpretability:} What does the memory learn?

\subsection{9.7 Broader Impact}

\subsubsection{Positive}
\begin{itemize}
\item Enables long-context AI on consumer hardware
\end{itemize}
\begin{itemize}
\item Multi-architecture support simplifies deployment
\end{itemize}

\subsubsection{Negative}
\begin{itemize}
\item Adds parameters (opposite of compression)
\end{itemize}
\begin{itemize}
\item Long-context could enable mass surveillance
\end{itemize}
