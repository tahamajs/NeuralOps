\subsection{9.1 Key Takeaways}

\subsubsection{9.1.1 Takeaway 1: Real Compression is Possible}

Unlike attention-replacement methods that preserve parameter count, A3 
achieves \textbf{{{D\_RATIO}}$\times$--{{G\_RATIO}}$\times$} parameter reduction with \textbf{<5\%} 
accuracy drop. This is a genuine reduction in storage, memory, and load time.

\subsubsection{9.1.2 Takeaway 2: Weighting Matters}

Fisher weighting reduces reconstruction error by \textbf{{{FISHER\_REDUCTION}}\%} at 
the same rank. This is a free win -- no additional computation beyond the 
calibration pass.

\subsubsection{9.1.3 Takeaway 3: LayerNorm Recalibration is Cheap and Effective}

A single recalibration pass, costing \textbf{{{LN\_TIME}}s}, recovers 
\textbf{{{LN\_RECOVERY}}\%} of the accuracy drop on average.

\subsection{9.2 When to Use A3}

\subsubsection{9.2.1 Recommended}

\begin{itemize}
\item \textbf{Storage-constrained deployment:} Mobile, edge, browser.
\end{itemize}
\begin{itemize}
\item \textbf{Load-time-sensitive applications:} Cold-start latency matters.
\end{itemize}
\begin{itemize}
\item \textbf{Combined with quantization:} A3 + INT8 $\to$ 8$\times$ compression.
\end{itemize}
\begin{itemize}
\item \textbf{Base for further compression:} A3 then prune then quantize.
\end{itemize}

\subsubsection{9.2.2 Not Recommended}

\begin{itemize}
\item \textbf{Extremely small models:} <10M params; overhead dominates.
\end{itemize}
\begin{itemize}
\item \textbf{Extremely large models:} >10B; SVD time dominates.
\end{itemize}
\begin{itemize}
\item \textbf{Latency-critical applications:} Factorized layers are slower than dense
\end{itemize}
  layers on GPUs (two matmuls instead of one).
\begin{itemize}
\item \textbf{Models with non-linear attention:} A3 only compresses linear layers.
\end{itemize}

\subsection{9.6 Deployment Considerations}

\subsubsection{9.6.1 Storage}

A3's main benefit is storage. For a 100M-parameter model:

\begin{itemize}
\item Baseline: 200 MB FP16
\end{itemize}
\begin{itemize}
\item A3 (r=64): ~{{D\_DISK}} MB
\end{itemize}
\begin{itemize}
\item A3 + INT8: ~{{D\_DISK\_INT8}} MB
\end{itemize}

\subsubsection{9.6.2 Latency}

A3's factorized layers are \textbf{~{{D\_LATENCY\_RATIO}}$\times$} slower on GPU because 
they require two sequential matmuls. On CPU, they may be \textbf{faster} because 
smaller matrices fit in cache better.

\subsubsection{9.6.3 Batching}

A3 layers benefit more from larger batches because the smaller matrices 
amortize better.

\subsection{9.7 Open Questions}

4. \textbf{Fisher proxy accuracy:} How does $\mathbb{E}[x^2]$ compare to the true Fisher?
