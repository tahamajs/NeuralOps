\subsection{Calibration Data}

For A3's activation statistics, we use the \textbf{training set} as calibration 
source. This is legitimate because:

\begin{itemize}
\item The calibration pass is a forward-only pass (no gradient)
\item It uses unlabeled inputs (labels not required)
\item It is not a form of test set leakage

\end{itemize}
We use \textbf{1000 examples} (a subsample of the training set) for 
calibration to keep memory bounded.

\subsection{Evaluation Metrics}

\subsubsection{Quality Metrics}

\begin{itemize}
\item \textbf{Accuracy:} $\text{Acc} = \frac{\text{correct}}{\text{total}}$
\item \textbf{F1:} Binary and macro-averaged
\item \textbf{Precision, Recall}

\end{itemize}
\subsubsection{Efficiency Metrics}

\begin{itemize}
\item \textbf{Total parameters:} \texttt{sum(p.numel() for p in model.parameters())}
\item \textbf{Trainable parameters}
\item \textbf{Peak VRAM:} \texttt{torch.cuda.max\_memory\_allocated()}
\item \textbf{Inference time:} Median of 20 forward passes
\item \textbf{Throughput:} Tokens/sec

\end{itemize}
\subsubsection{Compression Metrics}

\begin{itemize}
\item \textbf{Compression ratio:} Baseline params / compressed params
\item \textbf{Reconstruction error:} $\|W - UV\|_F / \|W\|_F$
\item \textbf{Compressed layers:} Count of successfully factorized layers
\item \textbf{Fallback layers:} Count of layers preserved

\end{itemize}
