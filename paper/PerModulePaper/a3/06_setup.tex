\subsection{Calibration Data}

For A3's activation statistics, we use the \textbf{training set} as calibration 
source. This is legitimate because:

\begin{itemize}
\item The calibration pass is a forward-only pass (no gradient)
\item It uses unlabeled inputs (labels not required)
\item It is not a form of test set leakage
\end{itemize}
We use \textbf{1000 examples} (a subsample of the training set) for 
calibration to keep memory bounded.
