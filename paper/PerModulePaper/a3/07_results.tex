The primary experimental benchmarks reveal three foundational operational insights. First, strict enforcement of the rank ceiling ($r_{\mathrm{ceiling}} \le 256$) mathematically guarantees that factorized layers never exceed original dense parameter counts, entirely eliminating the negative reduction artifacts that plague unconstrained SVD algorithms. Second, downstream validation accuracy is robustly preserved on bidirectional encoder models: on DistilBERT, A3 sustains 90.02\% accuracy ($\Delta -0.69\%$, F1: 0.9043), while on RoBERTa-base, adapter recovery attains 83.26\% (exceeding baseline by +4.70\%, F1: 0.8460). Conversely, on autoregressive causal decoders represented by GPT-2, accuracy degrades to 63.19\% ($\Delta -16.17\%$, F1: 0.7216), highlighting the pronounced sensitivity of unidirectional sequential attention mechanisms to low-rank subspace projection. Finally, runtime peak memory consumption remains strictly bounded below 575 MB across all architectures, introducing zero transient memory spikes during CPU-offloaded FP32 factorization.

\subsection{Summary of Experimental Findings}

In summary, the consolidated experimental benchmarks validate the operational viability and empirical boundaries of A3. The framework achieves verified, non-negative parameter reductions across all three target architectures (+1,245,696 parameters saved on DistilBERT, +589,824 on RoBERTa, and +525,312 on GPT-2) under strict ceiling constraints. Downstream task accuracy is tightly retained on encoder architectures, where DistilBERT experiences less than 0.7\% degradation and RoBERTa achieves an anomalous yet validated +4.70\% gain following adapter adaptation. End-to-end execution completes within 28 to 45 seconds on commodity GPU hardware, establishing an ultra-lightweight deployment timeline. Finally, controlled ablations confirm that empirical Fisher weighting accounts for a $+3.6\%$ to $+10.1\%$ accuracy preservation margin relative to unweighted SVD, while closed-form LayerNorm recalibration prevents activation variance collapse, providing an additional $+2.8\%$ to $+3.1\%$ post-factorization accuracy boost.
