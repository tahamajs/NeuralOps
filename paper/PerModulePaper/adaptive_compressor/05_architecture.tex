\subsubsection{3.2 Detailed Trace Execution Steps}
1. \textbf{Module Scanning}: Traverse PyTorch model hierarchy to identify all instances of \texttt{nn.MultiheadAttention}.
2. \textbf{Spectral Profiling}: Extract projection parameters $W_Q, W_K, W_V, W_O$. Run single-precision SVD to compute singular values $\sigma_i$.
3. \textbf{Adaptive Rank Search}: Calculate cumulative energy vectors $E_k$. Determine optimal rank $r^* = \max(r_{\min}, \text{search}(E_k \ge \eta))$.
4. \textbf{Submodule Instantiation}: Instantiate \texttt{CompressedAttentionLayer}, assign truncated SVD parameters ($U_r, S_r, V_r^T$), and compute layer compression statistics.
5. \textbf{In-Place Swap}: Replace original \texttt{nn.MultiheadAttention} module in parent architecture using \texttt{setattr(parent, child_name, compressed)}.
