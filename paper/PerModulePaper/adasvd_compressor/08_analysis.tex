 4. Parameter Savings \& Memory Footprint Profiling


 4.1 Global Parameter Budget Formulas
Let $P\_{\text{total}} = \sum\_{l=1}^L (M\_l \cdot N\_l)$ be the initial total linear parameter count.
Target parameter removal fraction $\rho \in (0, 1)$ establishes the compression objective:

\[
P\_{\text{target\\_retained}} = (1 - \rho) \cdot P\_{\text{total}}
\]

Under adaptive allocation $r\_l$, the retained parameter count $P\_{\text{retained}}$ is:

\[
P\_{\text{retained}} = \sum\_{l=1}^{L} r\_l (M\_l + N\_l + 1)
\]

 5. Precision Loss, Perplexity \& Sensitivity Bounds


 5.1 Error Bounding via Adaptive Rank Allocation
Under AdaSVD's nuclear norm rank distribution, the overall model Frobenius error sum $\mathcal{E}\_{\text{global}}$ is upper-bounded by:

\[
\mathcal{E}\_{\text{global}} = \sum\_{l=1}^{L} \|W^{(l)} - \hat{W}^{(l)}\|\_F^2 \le \sum\_{l=1}^{L} \sum\_{i=r\_l + 1}^{\min(M\_l, N\_l)} (\sigma\_i^{(l)})^2
\]

Because $r\_l$ scales monotonically with total spectral energy $\sum \sigma\_i^{(l)}$, high-entropy layers retain a larger fraction of their tail singular values, preventing error spikes in sensitive layers.

 5.2 Failure Modes \& Edge Cases
1. **Degenerate Uniform Spectrum**: If a layer has flat singular values ($\sigma\_1 \approx \sigma\_2 \approx \dots \approx \sigma\_R$), nuclear norm weighting allocates high rank, but low-rank truncation still loses substantial energy proportional to $(R - r\_l) \cdot \sigma\_1$.
2. **Matrix Inverse Instability**: During iterative refinement, computing $(U\_{r\_l}^T U\_{r\_l} + \epsilon I)^{-1}$ can become ill-conditioned if $\epsilon$ is too small ($< 10^-8$) and $U\_{r\_l}$ loses rank, requiring robust Tikhonov regularization.
