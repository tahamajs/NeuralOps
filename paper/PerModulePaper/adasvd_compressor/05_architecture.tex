\section{05 Architecture}

 5. Architecture and Implementation
Dense layers are replaced with `SVDLinear` modules ($y = (x B^	op) A^	op + b$). Supports Conv1D transposition for GPT-2 and preservation of LoRA adapters.


 3. Step-by-Step Calibration \& Execution Trace


 3.1 Calibration Dataflow \& Rank Assignment Pipeline

```
              Full Uncompressed Model
                         |
                         v
  +----------------------------------------------+
  | Layer-wise SVD \& Nuclear Norm Extraction     |
  |   For l = 1..L:                              |
  |     S = svdvals(W\_l)                         |
  |     I\_l = sum(S)                             |
  +----------------------+-----------------------+
                         |  [Layer Importance Array I]
                         v
  +----------------------------------------------+
  | Global Importance Normalization              |
  |   alpha\_l = I\_l / sum(I\_1..I\_L)              |
  +----------------------+-----------------------+
                         |  [Normalized Ratios alpha]
                         v
  +----------------------------------------------+
  | Adaptive Rank Allocation Calculation         |
  |   r\_l = clamp(max\_rank * (1 - ratio) * alpha)|
  +----------------------+-----------------------+
                         |  [Allocated Ranks r\_1..r\_L]
                         v
  +----------------------------------------------+
  | Loop over layers l = 1..L:                   |
  |  1. Extract initial U\_r, S\_r, Vt\_r           |
  |  2. Execute T iterations of Alternating Refinement:|
  |      U\_r <- W @ V\_r @ (diag(S\_r) + eps I)^-1  |
  |      Vt\_r <- (U\_r^T @ U\_r + eps I)^-1 @ U\_r^T @ W|
  |      S\_r <- diag(U\_r^T @ W @ V\_r)            |
  |  3. Synthesize W\_approx = U\_r @ diag(S\_r) @ Vt\_r|
  +----------------------+-----------------------+
                         |
                         v
               Compressed PyTorch Model
```

 3.2 Detailed Step-by-Step Execution Sequence
1. **Spectral Profiling Phase**: Iterate over all `nn.Linear` layers in the model, execute standard CPU/GPU SVD to collect singular value vectors, and compute $\|W^{(l)}\|\_*$.
2. **Global Budgeting Phase**: Aggregate total nuclear norm $\sum\_{l=1}^L \mathcal{I}\_l$. Compute relative ratios $\alpha\_l$ and assign layer-specific ranks $r\_l$.
3. **Iterative Refinement Phase**: For each linear layer:
Slice top-$r\_l$ components from initial SVD matrices. Furthermore, Run $T = 5$ iterations of alternating matrix inverse updates to solve the regularized least-squares factor refinement problem. Concurrently, Multiply factors back to form the updated weight tensor $\hat{W}^{(l)}$ and overwrite `module.weight.data`.
