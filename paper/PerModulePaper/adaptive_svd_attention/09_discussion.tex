\section{Discussion}

\subsection{Key Takeaways}

\subsubsection{Takeaway 1: Adaptive Rank is Better Than Fixed}

Energy thresholding selects different ranks for Q, K, V, O -- allocating 
capacity based on the intrinsic spectrum of each projection.

\subsubsection{Takeaway 2: All Four Projections Can Be Factorized}

Unlike SOA Fused Attention, we compress $W_O$ too. The residual adapter 
absorbs the additional error.

\subsubsection{Takeaway 3: T5 and Cross-Attention Work}

The method supports T5 relative attention bias and encoder-decoder cross-
attention, making it applicable to a broader range of models.

\subsection{When to Use Adaptive SVD Attention}

\subsubsection{Recommended}
\begin{itemize}
\item \textbf{Models with heterogeneous projection spectra} (where fixed rank
  under-performs).
\item \textbf{T5-family models} (relative bias support).
\item \textbf{Encoder-decoder models} (cross-attention).
\item \textbf{Zero-shot deployments} (no calibration).
\item \textbf{Parameter-sensitive applications} (2-3$\times$ attention reduction).

\end{itemize}
\subsubsection{Not Recommended}
\begin{itemize}
\item \textbf{Long-context inference} (attention still quadratic).
\item \textbf{Models where attention is a small fraction} (FFN dominates).

\end{itemize}
\subsection{Decision Flowchart}

\begin{lstlisting}

\subsection{Composition with Other Methods}

Adaptive SVD Attention composes with:

\begin{itemize}
\item \textbf{GQA:} further reduces KV projection size.
\item \textbf{KV quantization:} INT8 on factorized weights.
\item \textbf{Token compression} (TCA): reduces KV length.
\item \textbf{FFN compression} (A3/AASVD): compresses the other half.

\end{itemize}
A combined pipeline could achieve \textbf{4-5$\times$ total compression}.

\subsection{Broader Impact}

\subsubsection{Positive}
\begin{itemize}
\item Principled rank selection.
\item Broad architecture support (T5, cross-attention).
\item Zero-shot -- no calibration data.
\item Real parameter reduction.

\end{itemize}
\subsubsection{Negative}
\begin{itemize}
\item Attention remains quadratic.
\item Requires more code than fixed-rank methods.

\end{itemize}
