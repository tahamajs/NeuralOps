\section{Method}

\subsection{Overview}

Adaptive SVD Attention replaces each of the four attention projections 
$\{W_Q, W_K, W_V, W_O\}$ with:

\begin{equation}
W \approx U_r V_r + B A
\end{equation}

where:

\begin{itemize}
\item $r$ is \textbf{adaptively selected per projection} via energy thresholding.
\item $U_r, V_r$ are frozen SVD factors.
\item $B A$ is a trainable residual adapter with $B = 0$ initially.

\end{itemize}
\textbf{Figure 4.1} shows the pipeline.

\begin{lstlisting}
    Weight W $\in$ R^{d$\times$d}
              |
               
    +-------------------+
    |  SVD              |
    |  U $\Sigma$ V^T          |
    +---------+---------+
              |
               
    +-------------------+
    |  Energy-based     |
    |  rank selection   |
    |  r* : E(r*) $\ge$ $\tau$   |
    +---------+---------+
              |
               
    +-------------------+
    |  Symmetric split  |
    |  U_r = U $\sqrt{}$$\Sigma$       |
    |  V_r = $\sqrt{}$$\Sigma$ V^T     |
    +---------+---------+
              |
               
    +-------------------+
    |  Freeze U_r, V_r  |
    |  Add LoRA BA      |
    +-------------------+
\end{lstlisting}

\subsection{Energy-Thresholded Rank Selection}

For each projection $W$:

\textbf{Step 1:} Compute SVD: $W = U \Sigma V^\top$.

\textbf{Step 2:} Compute cumulative energy:

\begin{equation}
E(r) = \frac{\sum_{i=1}^{r} \sigma_i^2}{\sum_{j=1}^{d} \sigma_j^2}
\end{equation}

\textbf{Step 3:} Find minimal rank:

\begin{equation}
r^* = \min\{r : E(r) \geq \tau\}
\end{equation}

\textbf{Step 4:} Clamp to $[\min\_rank, \max\_rank]$:

\begin{equation}
r^* \leftarrow \max(\min(r^*, \text{max\_rank}), \text{min\_rank})
\end{equation}

We use $\tau = 0.92$, $\min\_rank = 16$, $\max\_rank = d$.

\subsubsection{Why Energy Thresholding?}

Energy thresholding is \textbf{principled} -- it directly bounds the relative 
Frobenius error:

\begin{equation}
\frac{\|W - W_{r^*}\|_F}{\|W\|_F} \leq \sqrt{1 - \tau}
\end{equation}

For $\tau = 0.92$: error $\le$ 28.3\% of the Frobenius norm. This is a **hard 
guarantee**, unlike a fixed rank which gives no such bound.

\subsubsection{Why Per-Projection?}

Different projections have different spectral decay:

\begin{itemize}
\item \textbf{Attention Q, K:} often have rapidly decaying spectra (low intrinsic rank).
\item \textbf{Attention V, O:} sometimes flatter (higher intrinsic rank).

\end{itemize}
A fixed rank either over-compresses V and O or under-compresses Q and K. 
Adaptive rank allocates capacity where it's needed.

\subsection{Symmetric $\sqrt{\Sigma}$ Split}

Given the selected rank $r^*$, we compute:

\begin{equation}
U_r = U_{:, :r^*} \Sigma_{:r^*, :r^*}^{1/2}
\end{equation}

\begin{equation}
V_r = \Sigma_{:r^*, :r^*}^{1/2} V_{:r^*, :}^\top
\end{equation}

Then $W \approx U_r V_r$.

\textbf{Why symmetric?} Both factors have singular values bounded by $\sqrt{\sigma_1}$, 
which keeps FP16 underflow risk low for both.

\subsection{Residual Adapter}

We freeze $U_r, V_r$ and add a trainable residual:

\begin{equation}
\Delta W = B A, \quad A \in \mathbb{R}^{r_a \times d}, \quad B \in \mathbb{R}^{d \times r_a}
\end{equation}

with:

\begin{itemize}
\item $A \sim \text{Kaiming-Uniform}$
\item $B = 0$ (so $\Delta W = 0$ at init)
\item $r_a = 16$ (residual rank)

\end{itemize}
The full forward pass:

\begin{equation}
y = U_r V_r x + B A x + b
\end{equation}

\subsection{T5 Relative Bias Preservation}

T5's relative attention bias is stored as an embedding \texttt{relative\_attention\_bias} 
of shape $(num\_buckets, num\_heads)$. We copy it to the new module:

\begin{lstlisting}
if hasattr(src, "relative_attention_bias") and src.relative_attention_bias is not None:
    self.relative_attention_bias = src.relative_attention_bias
    self.has_relative_attention_bias = True
\end{lstlisting}

The bias is added to attention scores after the Q, K projections (which are 
factorized).

\subsection{Cross-Attention Support}

For encoder-decoder attention:

\begin{lstlisting}
key_value_states = kwargs.get("key_value_states", encoder_hidden_states)
is_cross_attention = key_value_states is not None
kv_input = key_value_states if is_cross_attention else hidden_states
\end{lstlisting}

K, V are projected from \texttt{kv\_input}; Q from \texttt{hidden\_states}. Factorized 
projections work uniformly.

\subsection{Algorithm}

\textbf{Algorithm 1:} Adaptive SVD Attention forward pass
\begin{lstlisting}
Input:  X, attention_mask, position_embeddings (optional)
        encoder_hidden_states (optional, for cross-attention)
Output: Y

 1: if cross_attention: kv_input $\leftarrow$ encoder_hidden_states
 2: else: kv_input $\leftarrow$ X
 3: Q $\leftarrow$ query(X)                       U_r V_r + B A
 4: K $\leftarrow$ key(kv_input)
 5: V $\leftarrow$ value(kv_input)
 6: Q, K, V $\leftarrow$ reshape to multi-head
 7: if RoPE: Q, K $\leftarrow$ rotary(Q, K)
 8: if GQA:  K, V $\leftarrow$ repeat_kv(K, V)
 9: scores $\leftarrow$ Q K^T / $\sqrt{}$d_h
10: if relative_bias: scores += bias
11: if causal: scores += causal_mask
12: scores = mask(scores, attention_mask)
13: A = softmax(scores)
14: context $\leftarrow$ A V
15: context $\leftarrow$ reshape
16: if nested: return context
17: out $\leftarrow$ out_proj(context)
18: return out
\end{lstlisting}
