\section{Introduction}

\subsection{Motivation}

The four attention projections $W_Q, W_K, W_V, W_O$ account for the majority 
of parameters in the attention block of a transformer. For a 768-dim model 
with 12 heads, these contribute $4 d^2 = 2.36$M parameters -- comparable to 
the FFN in DistilBERT and a significant fraction in GPT-2.

\textbf{Low-rank factorization} is a natural approach: replace $W \in \mathbb{R}^{d \times d}$ 
with $U V$ where $U \in \mathbb{R}^{d \times r}$ and $V \in \mathbb{R}^{r \times d}$ 
for $r \ll d$. Parameter count drops from $d^2$ to $2 r d$.

\textbf{The rank $r$ is critical.} Too small $\to$ severe approximation error. Too 
large $\to$ poor compression. Two existing approaches dominate:

\begin{enumerate}
\item \textbf{Fixed rank} (SOA Fused Attention, vanilla SVD): choose a global $r$
  (e.g., 128) and apply it to all projections.
\item \textbf{Empirical tuning} (A3, AASVD): run ablations to find $r$ per model.

\end{enumerate}
Both ignore that \textbf{each projection has a different intrinsic rank}. A 
projection with rapidly decaying singular values can be compressed more 
aggressively than one with a flat spectrum.

\subsection{Problem Statement}

Given a pretrained attention with projections $\{W^{(i)} \in \mathbb{R}^{d_i \times d_i}\}$, 
we seek factorizations $\{U^{(i)} V^{(i)}\}$ such that:

\begin{enumerate}
\item \textbf{Parameter reduction:} $2 r^{(i)} d_i < d_i^2$ for each projection.
\item \textbf{Adaptive rank:} $r^{(i)}$ differs per projection based on its spectrum.
\item \textbf{Spectral fidelity:} the retained energy fraction satisfies:
  
  $$\frac{\sum_{j=1}^{r^{(i)}} \sigma_j^2}{\sum_{j=1}^{d_i} \sigma_j^2} \geq \tau$$
  
  for a threshold $\tau$ (e.g., 0.92).
\item \textbf{No calibration data required:} initialization is zero-shot.
\item \textbf{Learnable recovery:} adapters provide fine-tuning capacity.
\item \textbf{Full architecture support:} T5 relative bias, cross-attention, GQA, RoPE.

\end{enumerate}
\subsection{Our Approach}

We propose \textbf{Adaptive SVD Attention}, which combines three ideas:

\subsubsection{Energy-Thresholded Rank Selection}

For each projection $W$, we compute the SVD:

\[
W = U \Sigma V^\top
\tag{1.1}
\]

and select the \textbf{smallest rank} $r$ such that the cumulative squared 
singular value energy reaches $\tau$:

\[
r^* = \min\left\{ r : \frac{\sum_{i=1}^{r} \sigma_i^2}{\sum_{j=1}^{d} \sigma_j^2} \geq \tau \right\}
\tag{1.2}
\]

This is principled: it directly bounds the Frobenius reconstruction error 
relative to the total matrix energy.

\subsubsection{Symmetric $\sqrt{\Sigma}$ Split}

We split the singular values symmetrically:

\[
U_r = U_{:, :r} \Sigma_r^{1/2}, \quad V_r = \Sigma_r^{1/2} V_{:r, :}^\top
\tag{1.3}
\]

This balances magnitudes between the two factors, which is numerically 
favorable.

\subsubsection{Residual Adapters}

We freeze the SVD base and add a trainable low-rank residual:

\[
W_\text{eff} \approx U_r V_r + B A
\tag{1.4}
\]

where $A \in \mathbb{R}^{r_a \times d}$, $B \in \mathbb{R}^{d \times r_a}$, and 
$B = 0$ initially.

\subsubsection{All Four Projections}

Unlike SOA Fused Attention (Q/K/V only), we factorize \textbf{all four} including 
$W_O$. This is possible because the residual adapter absorbs the additional 
error introduced by factorizing $W_O$.

\subsection{Contributions}

\begin{itemize}
\item \textbf{Adaptive rank selection.} We introduce energy-thresholded rank
  selection per projection, replacing fixed-rank heuristics.
\item \textbf{All-four-projection factorization.} We compress $W_Q, W_K, W_V, W_O$
  using the same primitive.
\item \textbf{T5 and cross-attention support.} We handle T5 relative attention bias
  and encoder-decoder cross-attention -- a capability lacking in prior
  attention-compression methods.
\item \textbf{A production-hardened implementation.} Supports DistilBERT, RoBERTa,
  GPT-2, Qwen3.5, and T5 with robust weight extraction.
\item \textbf{A comprehensive evaluation.} We benchmark on three models on SST-2 with
  ablations over energy threshold, residual rank, and rank policy.
\item \textbf{Full reproducibility.} Code, weights, and scripts released under {{LICENSE}}.

\end{itemize}
