\section{Introduction}\subsection{Motivation}Prior hybrid attention models add adapter parameters. AEGIS-V2 enforces structural low-rank parameter reduction directly within projection layers.


\section{Related Work}Combines structural low-rank weight factorization with sliding-window context gating.


\section{Mathematical Background}Low-rank factorization replaces $d_{\text{in}} \times d_{\text{out}}$ dense matrices with rank-$r$ factors.


\section{Methodology}Projections enforce rank-$r$ factorizations. Local sliding-window attention is combined with global linear kernel streams.


\section{Architecture and Implementation}Universal multi-architecture support across DistilBERT, RoBERTa, GPT-2, and Qwen.


\section{Experimental Setup}Standardized SST-2 evaluation across three representative model families.

\section{Detailed Analysis}The module sheds 11.4M parameters from DistilBERT and 15.7M parameters from RoBERTa while maintaining functional accuracy.


\section{Discussion}AEGIS-V2 provides real parameter reduction through factorized linear projections.


\section{Limitations}Causal autoregressive models require higher factorization rank to prevent representation drift.


\section{Conclusion}\texttt{aegis\_v2} validates structural parameter compression within hybrid attention.
