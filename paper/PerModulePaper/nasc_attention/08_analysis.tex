\subsection{Sparse Block Python Loop}

The \texttt{\_sparse\_block\_attention} uses a Python \texttt{for i in range(nb)} loop. For 
$L = 128$, $B_s = 32$: 4 iterations. Each iteration does gather + matmul.

\textbf{Overhead.} ~4 extra kernel launches per forward.

\subsection{Summary of Insights}

\begin{enumerate}
\item \textbf{Three branches provide redundancy.} If one fails, others compensate.
\item \textbf{Batch-level gate is a simplification.} Per-token would be more
  adaptive.
\item \textbf{Encoder path defaults to dense.} NASC's benefit is on decoders.
\item \textbf{Sparse block loop adds overhead.} Vectorization would help.
\item \textbf{Causal RFF cumsum is memory-heavy.} OOM risk at long sequences.
\item \textbf{\texttt{inject\_nasc} raises on failure.} This is a robustness regression.
\end{enumerate}
