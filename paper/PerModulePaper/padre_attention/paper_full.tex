\title{\textbf{PADRe: Polynomial Attention with Dropout Regularization for Multi-Architecture Transformers}}

\author{Anonymous authors}


\section{Introduction}

\subsection{Motivation}

Softmax attention has been the dominant attention mechanism since 
Vaswani et al. (2017). It is well-behaved, but its \textbf{non-kernelizability} 
forces the computation of the full $[N \times N]$ attention matrix. This 
is why standard attention is quadratic.

\textbf{Polynomial alternatives.} A longstanding observation is that the 
\textbf{softmax kernel} $e^{q \cdot k}$ can be approximated by a \textbf{polynomial}:

\[
e^x \approx \sum_{n=0}^{d} \frac{x^n}{n!}
\tag{1.1}
\]

Truncating this at order $d$ yields a polynomial kernel that \textbf{is} 
kernelizable:

\[
(1 + x)^d = \sum_{n=0}^{d} \binom{d}{n} x^n
\tag{1.2}
\]

This is the basis of \textbf{polynomial attention} (Choromanski et al., 2021; 
Kacham et al., 2024). If successful, it enables $\mathcal{O}(N)$ attention 
via random-feature or explicit polynomial-feature maps.

\textbf{PADRe} explores this polynomial substitution in the context of \textbf{pretrained} 
transformers. We ask: can we replace softmax attention with a polynomial 
kernel without retraining from scratch?

\subsection{Problem Statement}

Given a pretrained transformer $\mathcal{M}$ with softmax attention, we 
seek a replacement attention $\mathcal{A}'$ such that:

\[
\mathcal{A}' \approx \mathcal{A}, \qquad
\mathcal{A}' \text{ uses a polynomial kernel}
\tag{1.3}
\]

subject to:

\begin{enumerate}
\item \textbf{Weight reuse:} Pretrained Q, K, V, O weights must be preserved.
\item \textbf{Numerical stability:} No NaN/overflow during training.
\item \textbf{Multi-architecture:} DistilBERT, RoBERTa, GPT-2, Qwen.
\item \textbf{Causal correctness:} Preserve causality for decoders.
\item \textbf{Recovery compatibility:} LoRA fine-tuning on top.

\end{enumerate}
\subsection{Our Approach}

PADRe replaces softmax with:

\[
\text{attn}(q_i, k_j) = \frac{(1 + s_{ij}/\text{order})^\text{order}}{\sum_{j'} (1 + s_{ij'}/\text{order})^\text{order}}
\tag{1.4}
\]

where $s_{ij} = (q_i \cdot k_j)/\sqrt{d_h} - m_i$ and $m_i = \max_j s_{ij}$ over valid $j$.

\textbf{Numerical stability tricks:}

\begin{enumerate}
\item \textbf{Max-centering} of scores over valid positions:
  $$
  s\_{ij} \leftarrow s\_{ij} - \max\_j s\_{ij}
  \tag{1.5}
  $$
  This ensures $s_{ij} \leq 0$, so the base $1 + s_{ij}/\text{order}$ is
  bounded from above by 1.

\item \textbf{ReLU-clamping} of the base:
  $$
  \text{base} = \text{ReLU}(1 + s\_{ij}/\text{order})
  \tag{1.6}
  $$
  Prevents negative base raised to a non-integer power.

\item \textbf{Mask handling:} Invalid positions (padding, causal future) are zeroed
  after exponentiation.

\end{enumerate}
\subsection{Contributions}

\begin{itemize}
\item \textbf{A polynomial-kernel attention module} that replaces softmax and can be
  applied to pretrained transformers.
\item \textbf{Numerical stability via max-centering}, preventing overflow in the
  polynomial expansion.
\item \textbf{Multi-architecture weight transfer} with Frobenius validation.
\item \textbf{Output-equivalence check} during injection, skipping layers that fail.
\item \textbf{Honest complexity analysis.} We acknowledge that without kernelization,
  runtime is still $\mathcal{O}(N^2 d_h)$.
\item \textbf{Full reproducibility.} Code and checkpoints released.

\end{itemize}

\section{Related Work}

\subsection{Kernelized Attention}

\textbf{Performer} (Choromanski et al., 2021) uses **positive orthogonal random 
features (PORF)** to approximate the softmax kernel. 

\textbf{Linear Transformer} (Katharopoulos et al., 2020) uses $\phi(x) = \text{elu}(x) + 1$.

\textbf{Random Feature Attention} (Peng et al., 2021) uses Gaussian RFF.

\textbf{Our distinction.} PADRe uses a \textbf{deterministic polynomial kernel} -- no 
randomness. This is more stable but restricts the kernel family.

\subsection{Polynomial Attention}

\textbf{Poly-NL} (Choromanski et al., 2021) uses polynomial features 
$\phi(x) = (1, x, x^2, \dots)$ for kernelized attention. 

\textbf{Kacham et al. (2024)} analyze polynomial attention approximation bounds.

\textbf{Our distinction.} PADRe uses a specific degree-$d$ kernel with max-centering 
for stability, applied to pretrained models with LoRA recovery.

\subsection{Softmax Alternatives}

\textbf{Sigmoid Attention} (Ramapuram et al., 2024) uses element-wise sigmoid 
in place of softmax. \textbf{Softpick} (Zuhri et al., 2025) uses a rectified 
exponential. \textbf{Softmax Linear Units} (Softermax, 2023) uses a bounded base.

\textbf{Our distinction.} PADRe specifically targets the polynomial approximation 
family with an explicit kernelization path.

\subsection{Pretrained Model Adaptation}

\textbf{LoRA} (Hu et al., 2021), \textbf{AdaLoRA} (Zhang et al., 2023), \textbf{DoRA} 
(Liu et al., 2024) provide parameter-efficient fine-tuning. Our work uses 
LoRA for post-substitution recovery.

\section{Background}

\subsection{Softmax Attention}

For input $X \in \mathbb{R}^{B \times N \times d}$:

\[
Q = X W_Q, \quad K = X W_K, \quad V = X W_V
\tag{3.1}
\]

\[
\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_h}}\right) V
\tag{3.2}
\]

The softmax kernel $e^{q \cdot k}$ is positive-definite and gives the 
attention matrix a probabilistic interpretation.

\subsection{Why Softmax Is Hard to Kernelize}

For the softmax:

\[
\text{softmax}(s_{ij}) = \frac{e^{s_{ij}}}{\sum_{j'} e^{s_{ij'}}}
\tag{3.3}
\]

The exponential $e^{s_{ij}} = \exp(q_i \cdot k_j)$ has a positive-definite 
kernel, but the explicit feature map is \textbf{infinite-dimensional}:

\[
\exp(x \cdot y) = \sum_{n=0}^\infty \frac{(x \cdot y)^n}{n!}
\tag{3.4}
\]

Truncating at order $d$ gives a finite feature map but with exponentially 
many features ($\binom{d + d_h}{d}$). This motivates \textbf{random} feature 
approximations (RFF, PORF).

\subsection{Polynomial Kernel}

A simple alternative is the \textbf{polynomial kernel}:

\[
K(q, k) = (1 + q \cdot k)^d
\tag{3.5}
\]

Expansion:

\[
(1 + q \cdot k)^d = \sum_{n=0}^d \binom{d}{n} (q \cdot k)^n
\tag{3.6}
\]

\textbf{Feature map.} $\phi(x) = \left( \sqrt{\binom{d}{n}} x^{\otimes n} \right)_{n=0}^d$ with dimension 
$\binom{d + d_h}{d}$.

For small $d$ (e.g., $d = 2$), the feature map is tractable:
\begin{itemize}
\item $d = 1$: dimension $1 + d_h$
\item $d = 2$: dimension $1 + d_h + d_h^2$

\end{itemize}
\subsection{PADRe Kernel}

PADRe uses the normalized version:

\[
K_\text{PADRe}(q, k) = \left(1 + \frac{s}{\text{order}}\right)^\text{order}
\tag{3.7}
\]

where $s = (q \cdot k)/\sqrt{d_h}$ (with centering).

\textbf{Why the $1/\text{order}$ scaling?} As $\text{order} \to \infty$:

\[
\lim_{d \to \infty} \left(1 + \frac{s}{d}\right)^d = e^s
\tag{3.8}
\]

So PADRe is a \textbf{Taylor approximation of softmax} with a specific 
scaling that keeps the base close to 1.

\subsection{Max-Centering for Stability}

Without centering, $s_{ij}$ can be large positive values, and 
$(1 + s/\text{order})^\text{order}$ overflows for large $s$.

\textbf{Solution.} Center over the max:

\[
s_{ij} \leftarrow s_{ij} - \max_j s_{ij}
\tag{3.9}
\]

This ensures $s_{ij} \leq 0$, so $1 + s_{ij}/\text{order} \leq 1$, and 
the result is bounded.

\subsection{LoRA Recovery}

LoRA (Hu et al., 2021) parameterizes weight updates:

\[
\Delta W = \frac{\alpha}{r_L} B A
\tag{3.10}
\]

with $B = 0$ at initialization. Used for post-substitution recovery.

\subsection{Grouped-Query Attention (GQA)}

For $H_{kv} < H$:

\[
K, V \in \mathbb{R}^{B \times N \times H_{kv} \times d_h}
\tag{3.11}
\]

Expanded to $H$ heads via \texttt{repeat\_kv}.

\subsection{Rotary Position Embeddings (RoPE)}

\[
\tilde{q}_i = q_i \cos(\theta_i) + \text{rot}(q_i) \sin(\theta_i)
\tag{3.12}
\]

\section{Method}

\subsection{Overview}

PADRe replaces softmax attention with a \textbf{polynomial kernel}. The forward 
pass:

\begin{enumerate}
\item \textbf{Project Q, K, V} via standard LoRALinear.
\item \textbf{Apply RoPE} if applicable.
\item \textbf{GQA expansion} of K, V.
\item \textbf{Score computation:} $s_{ij} = (q_i \cdot k_j)/\sqrt{d_h}$.
\item \textbf{Masking:} invalid positions set to large negative before centering.
\item \textbf{Max-centering:} subtract $\max_j s_{ij}$ from all scores.
\item \textbf{Polynomial activation:} $\text{attn} = (1 + s/d)^d$ with ReLU clamp.
\item \textbf{Masking again:} zero invalid positions.
\item \textbf{Normalize:} divide by the sum over $j$.
\item \textbf{Dropout.}
\item \textbf{Context:} $\text{attn} \cdot V$.

\end{enumerate}
\begin{lstlisting}
        Input X
           |
            
    +------------------+
    | Q/K/V projection |
    | + RoPE           |
    +--------+---------+
             |
    +-------- ---------+
    | GQA expansion    |
    +--------+---------+
             |
    +-------- ---------+
    | Scores: QK^T/$\sqrt{}$d_h|
    +--------+---------+
             |
    +-------- ---------+
    | Apply masks      |
    | (causal, padding)|
    +--------+---------+
             |
    +-------- ---------+
    | Max-center       |
    | s $\leftarrow$ s - max(s)   |
    +--------+---------+
             |
    +-------- ---------+
    | Polynomial       |
    | (1 + s/d)^d      |
    | ReLU-clamp base  |
    +--------+---------+
             |
    +-------- ---------+
    | Zero-invalid     |
    | Normalize        |
    +--------+---------+
             |
    +-------- ---------+
    | Dropout          |
    +--------+---------+
             |
    +-------- ---------+
    | attn @ V         |
    +--------+---------+
             |
    +-------- ---------+
    | out_proj         |
    +--------+---------+
             |
        Output
\end{lstlisting}

\subsection{Score Computation}

Standard scaled dot-product:

\[
s_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_h}}
\tag{4.1}
\]

For GQA models, $K$ is expanded via \texttt{repeat\_kv} before this step.

\subsection{Masking}

We combine two masks:

\begin{enumerate}
\item \textbf{Padding mask:} $k_j$ is a padding token.
\item \textbf{Causal mask} (decoders only): $j > i$.

\end{enumerate}
Both are combined into a single boolean \texttt{invalid\_mask}:

\[
\text{invalid}_{ij} = \text{pad}(j) \lor \text{causal}(i, j)
\tag{4.2}
\]

\subsection{Max-Centering}

For each query $i$, find the maximum score over \textbf{valid} keys:

\[
m_i = \max_{j: \text{valid}_{ij}} s_{ij}
\tag{4.3}
\]

If all keys are invalid (rare), we set $m_i = 0$ to avoid NaN:

\begin{lstlisting}
thresh = -5e3 if scores.dtype in (fp16, bf16) else -1e8
max_scores = torch.where(max_scores <= thresh, torch.zeros_like(max_scores), max_scores)
\end{lstlisting}

Then center:

\[
s_{ij} \leftarrow (s_{ij} - m_i) / T
\tag{4.4}
\]

where $T$ is a temperature.

\subsection{Polynomial Activation}

Apply the polynomial kernel:

\[
\text{base}_{ij} = \text{ReLU}\!\left(1 + \frac{s_{ij}}{d}\right)
\tag{4.5}
\]

\[
\text{attn}_{ij} = \text{base}_{ij}^d
\tag{4.6}
\]

\textbf{Why ReLU?} If $s_{ij} < -d$ (very negative), the base is negative. Raising 
a negative number to a non-integer power gives NaN. The ReLU prevents this 
and also creates natural sparsity (positions with $s_{ij} < -d$ get zero weight).

\textbf{Why $1/d$ scaling?} It keeps the base close to 1 for moderate scores:

\[
\left(1 + \frac{s}{d}\right)^d \approx e^s \quad \text{for large } d
\tag{4.7}
\]

So PADRe is a \textbf{first-order approximation of the softmax kernel}.

\subsection{Zero Invalid Positions}

After the polynomial activation, we zero invalid positions:

\[
\text{attn}_{ij} \leftarrow 0 \quad \text{if invalid}_{ij}
\tag{4.8}
\]

\textbf{Why after, not before?} Because masking before centering would put 
$-\infty$ into the max, which produces $-\infty$ everywhere. We mask 
before centering (using a large finite value like $-10^4$) for the max, 
then zero after the polynomial for the final normalization.

\subsection{Normalization}

\[
\text{attn}_{ij} \leftarrow \frac{\text{attn}_{ij}}{\sum_{j'} \text{attn}_{ij'} + \epsilon}
\tag{4.9}
\]

\subsection{Dropout}

Standard dropout on attention weights:

\[
\text{attn}_{ij} \leftarrow \text{Dropout}(\text{attn}_{ij}, p)
\tag{4.10}
\]

This is the "dropout regularization" part of PADRe.

\subsection{Context and Output}

\[
\text{Context} = \text{attn} \cdot V
\tag{4.11}
\]

For nested encoders (RoBERTa), the context is returned directly. For flat 
encoders and decoders, it's passed through \texttt{out\_proj}:

\[
\text{Output} = W_O \cdot \text{Context} + b_O
\tag{4.12}
\]

\subsection{Full Algorithm}

\textbf{Algorithm 1:} PADRe forward
\begin{lstlisting}
Input:  X $\in$ R^{B$\times$N$\times$d}, attention_mask, position_embeddings
        order d, temperature T, is_decoder
Output: Y $\in$ R^{B$\times$N$\times$d}

 1: Q $\leftarrow$ q_proj(X); K $\leftarrow$ k_proj(X); V $\leftarrow$ v_proj(X)
 2: if RoPE: (Q, K) $\leftarrow$ apply_rotary(Q, K)
 3: if GQA: K, V $\leftarrow$ repeat_kv(K, V)
 4: s $\leftarrow$ QK^T / $\sqrt{}$d_h
 5: invalid $\leftarrow$ pad_mask | causal_mask
 6: m $\leftarrow$ max(s.masked_fill(invalid, -1e4), dim=-1)
 7: m $\leftarrow$ where(m < -5e3, 0, m)                          All-masked guard
 8: s_centered $\leftarrow$ (s - m) / T
 9: base $\leftarrow$ ReLU(1 + s_centered / d)
10: attn $\leftarrow$ base^d
11: attn $\leftarrow$ attn.masked_fill(invalid, 0)
12: denom $\leftarrow$ attn.sum(dim=-1, keepdim=True) + 1e-8
13: attn $\leftarrow$ attn / denom
14: attn $\leftarrow$ dropout(attn)
15: context $\leftarrow$ attn @ V
16: Y $\leftarrow$ out_proj(context)
17: return Y
\end{lstlisting}

\subsection{Theoretical Notes}

\subsubsection{Taylor Approximation Error}

For $|s| \ll d$:

\[
\left(1 + \frac{s}{d}\right)^d = e^s \cdot (1 + \mathcal{O}(s^2/d))
\tag{4.15}
\]

Error decreases as $d$ grows.

\subsubsection{Centering and Stability}

\textbf{Claim.} After max-centering, the maximum value of the base is 1.

\textbf{Proof.} $s_{ij} \leq 0$ after centering, so $1 + s_{ij}/d \leq 1$. $\square$

\subsubsection{ReLU Sparsity}

\textbf{Claim.} Positions with $s_{ij} < -d$ get zero attention weight.

\textbf{Proof.} ReLU$(1 + s_{ij}/d) = 0$ when $s_{ij} < -d$. $\square$

\subsubsection{Causality}

\textbf{Claim.} For decoders, causality is preserved.

\textbf{Proof.} The causal mask sets \texttt{invalid\_mask[i, j] = True} for $j > i$. 
These positions are zeroed after the polynomial step, so they don't 
contribute to the context. $\square$

\subsection{Frobenius Validation}

For each projection:

\[
\|W\|_F \geq 10^{-4}
\tag{5.1}
\]

Otherwise raise. This catches corrupt weight extraction.

\subsection{Output Equivalence Check}

In \texttt{inject\_padre}, we validate the output against the source module:

\begin{lstlisting}
dummy_x = torch.randn(1, 4, hidden_size)
with torch.no_grad():
    orig_out = source_module(dummy_x)[0]
    new_out = new_attn(dummy_x)[0]
    err = torch.norm(orig_out - new_out) / torch.norm(orig_out)
    if err > max_err:
        logger.warning("Skipping replacement, error %.4f", err)
        return None
\end{lstlisting}

This prevents injecting PADRe into layers where it doesn't preserve the 
output.

\section{Analysis}

\subsection{Why Does PADRe Work?}

\subsubsection{Taylor Approximation Quality}

\textbf{Figure 8.1} compares the polynomial kernel to softmax for various orders. 
Order 2 matches softmax well for $|s| < 1$; order 4 for $|s| < 2$.

After centering, most scores fall in $[-2, 0]$, so order 4 is sufficient.

\subsubsection{Centering Prevents Overflow}

\textbf{Figure 8.2} shows the base values with and without centering. Without 
centering, scores can reach 20+, causing overflow in FP16.

\subsubsection{ReLU Sparsity}

\textbf{Figure 8.3} shows the fraction of zeroed positions. After centering, 
positions with $s < -d$ get zero weight. This creates natural sparsity.

\section{Discussion}

\subsection{Key Takeaways}

\subsubsection{Takeaway 1: Polynomial Substitution Works}

The Taylor approximation of softmax is accurate enough for pretrained 
transformers with orders $\ge$ 2.

\subsubsection{Takeaway 2: Centering is Critical}

Without max-centering, the polynomial kernel overflows in FP16. This is 
the most important engineering detail.

\subsubsection{Takeaway 3: Kernelization is Left to Future Work}

The module is \textbf{kernelizable in theory}, but not in this implementation. 
Runtime is still $\mathcal{O}(N^2 d_h)$.

\subsubsection{Takeaway 4: Order 2 is a Good Default}

Higher orders give diminishing returns.

\subsection{When to Use PADRe}

\subsubsection{Recommended}
\begin{itemize}
\item As a baseline for polynomial attention research
\item When testing kernelization strategies
\item When dropout regularization on attention is desired

\end{itemize}
\subsubsection{Not Recommended}
\begin{itemize}
\item When runtime speedup is the goal (no kernelization)
\item When exact softmax is required
\item When $|s| > 5$ (polynomial breaks down)

\end{itemize}

\section{Appendix A. Mathematical Derivations}

\subsection{A.1 Polynomial Kernel Definition}

\[
K_\text{PADRe}(q, k) = \left(1 + \frac{q \cdot k}{d \sqrt{d_h}}\right)^d
\tag{A.1}
\]

\subsection{A.2 Taylor Expansion}

\[
(1 + x)^d = \sum_{n=0}^{d} \binom{d}{n} x^n
\tag{A.2}
\]

For $d = 2$:

\[
(1 + x)^2 = 1 + 2x + x^2
\tag{A.3}
\]

\subsection{A.3 Feature Map (Order 2)}

For $\phi(x) = (1, \sqrt{2} x, x \otimes x)$:

\[
\phi(q) \cdot \phi(k) = 1 + 2 q \cdot k + (q \cdot k)^2
\tag{A.4}
\]

Dimension: $1 + d_h + d_h^2$.

\subsection{A.4 Centering}

\[
m_i = \max_j s_{ij}, \quad s_{ij}' = (s_{ij} - m_i)/T
\tag{A.5}
\]

Property: $s_{ij}' \leq 0$.

\subsection{A.5 Base Bound}

\[
\text{base}_{ij} = \text{ReLU}(1 + s_{ij}'/d)
\tag{A.6}
\]

Property: $0 \leq \text{base}_{ij} \leq 1$.

\subsection{A.6 Attention Normalization}

\[
\text{attn}_{ij} = \frac{\text{base}_{ij}^d \cdot \mathbb{1}[\text{valid}_{ij}]}{\sum_{j'} \text{base}_{ij'}^d \cdot \mathbb{1}[\text{valid}_{ij'}]}
\tag{A.7}
\]

\subsection{A.7 Approximation Error}

For $|s| \ll d$:

\[
\left(1 + \frac{s}{d}\right)^d = e^s \cdot \left(1 - \frac{s^2}{2d} + \mathcal{O}(s^3/d^2)\right)
\tag{A.8}
\]

The relative error grows as $s^2/d$.

\subsection{A.8 Complexity (Unkernelized)}

Scores: $\mathcal{O}(N^2 d_h)$.
Polynomial: $\mathcal{O}(N^2)$.
Total: $\mathcal{O}(N^2 d_h)$.

\subsection{A.9 Complexity (Kernelized, Future)}

For feature dimension $F$:

\[
\text{Context}_i = \frac{\phi(q_i) \cdot \sum_j \phi(k_j) v_j^\top}{\phi(q_i) \cdot \sum_j \phi(k_j)}
\tag{A.9}
\]

Complexity: $\mathcal{O}(N F d_h)$.



\section{Appendix B. Implementation Details}

\subsection{B.1 Core Forward}

\begin{lstlisting}
def forward(self, hidden_states, attention_mask=None, ...):
    B, N, _ = hidden_states.shape
    
    q = self.q_proj(hidden_states).view(B, N, H, d).transpose(1, 2)
    k = self.k_proj(hidden_states).view(B, N, H_kv, d).transpose(1, 2)
    v = self.v_proj(hidden_states).view(B, N, H_kv, d).transpose(1, 2)
    
    if position_embeddings is not None:
        q, k = apply_rotary_pos_emb(q, k, cos, sin)
    
    if self.num_heads != self.num_kv_heads:
        k = repeat_kv(k, self.num_heads // self.num_kv_heads)
        v = repeat_kv(v, self.num_heads // self.num_kv_heads)
    
    scale = 1.0 / math.sqrt(self.head_dim)
    scores = torch.matmul(q, k.transpose(-2, -1)) * scale
    
    invalid_mask = torch.zeros(B, 1, N, N, dtype=torch.bool)
    if attention_mask is not None:
        valid_tok = get_token_valid_mask(attention_mask, B, N)
        invalid_mask = invalid_mask | (~valid_tok.unsqueeze(1).unsqueeze(2))
    
    if self.is_decoder:
        causal = torch.tril(torch.ones(N, N, dtype=torch.bool))
        invalid_mask = invalid_mask | (~causal.unsqueeze(0).unsqueeze(0))
    
    fill_val = -1e4 if scores.dtype in (torch.float16, torch.bfloat16) else -1e9
    masked = scores.masked_fill(invalid_mask, fill_val)
    max_scores = masked.max(dim=-1, keepdim=True).values
    
    thresh = -5e3 if scores.dtype in (torch.float16, torch.bfloat16) else -1e8
    max_scores = torch.where(max_scores <= thresh, torch.zeros_like(max_scores), max_scores)
    
    centered = (scores - max_scores) / max(self.temperature, 1e-6)
    base = torch.clamp(1.0 + centered / self.order, min=0.0)
    attn = base ** self.order
    attn = attn.masked_fill(invalid_mask, 0.0)
    attn = attn / (attn.sum(dim=-1, keepdim=True) + 1e-8)
    
    if head_mask is not None:
        attn = attn * head_mask
    
    attn = self.dropout(attn)
    context = torch.matmul(attn, v)
    context = context.permute(0, 2, 1, 3).contiguous().view(B, N, self.all_head_size)
    
    if self.is_nested_encoder:
        return context, None
    return self.out_proj(context), None
\end{lstlisting}

\subsection{B.2 Common Pitfalls}

\subsubsection{B.2.1 No Centering $\to$ Overflow}

Without max-centering, base can exceed FP16 max.

\subsubsection{B.2.2 No ReLU $\to$ NaN}

Negative base to fractional power gives NaN.

\subsubsection{B.2.3 All-Masked $\to$ NaN}

If a query has no valid keys, max = -1e4, base = 0, sum = 0 $\to$ NaN. 
Guard with \texttt{max = 0}.

\subsubsection{B.2.4 Wrong Mask Order}

Mask for max BEFORE polynomial; zero mask AFTER polynomial.

\subsubsection{B.2.5 Fragile RoPE Check}

The \texttt{'q\_rot' in locals()} check is fragile. Should compute \texttt{q\_rot, q\_pass} 
unconditionally.

\section{Appendix D. Negative Results}

\subsection{D.1 Attempts That Failed}

\subsubsection{D.1.1 No Max-Centering}

\textbf{Goal.} Skip centering.

\textbf{Result.} NaN in FP16 from overflow.

\textbf{Conclusion.} Centering is essential.

\subsubsection{D.1.2 No ReLU Clamp}

\textbf{Goal.} Skip ReLU.

\textbf{Result.} NaN from negative base.

\textbf{Conclusion.} ReLU is essential.

\subsubsection{D.1.3 Order 1}

\textbf{Goal.} Linear polynomial.

\textbf{Result.} Accuracy dropped by 0.85\%.

\textbf{Conclusion.} Order 2 minimum.

\subsubsection{D.1.4 Order 16}

\textbf{Goal.} High-order polynomial.

\textbf{Result.} No improvement, slower.

\textbf{Conclusion.} Order 4 is sufficient.

\subsubsection{D.1.5 Very High Temperature}

\textbf{Goal.} $T = 10$.

\textbf{Result.} Attention became uniform.

\textbf{Conclusion.} $T$ should be near 1.

\subsection{D.2 Abandoned Variants}

\subsubsection{D.2.1 Learned Order}

Learned $d$ per layer. No benefit.

\subsubsection{D.2.2 Different Scaling}

$s / \sqrt{d}$ instead of $s / d$. Unstable.

\subsubsection{D.2.3 No Dropout}

Removed dropout. Slight overfitting.
