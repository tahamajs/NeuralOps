\subsection{Summary}

\begin{itemize}
\item PADRe maintains accuracy within -0.34\% on DistilBERT.
\item Order 2 is a good default.
\item Max-centering is essential.
\item Kernelization not yet implemented; runtime unchanged.

\end{itemize}
