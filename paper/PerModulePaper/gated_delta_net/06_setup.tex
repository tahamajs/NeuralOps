\subsection{Reproduction}

\begin{lstlisting}
python run_all_4_gated_delta_net.py \
    --models distilbert,roberta,gpt2 \
    --recovery_steps 50 \
    --lora_rank 8 \
    --batch_size 32
\end{lstlisting}

\textbf{Expected runtime:}
\begin{itemize}
\item DistilBERT: ~2.3 s minutes
\item RoBERTa: \textbf{OOM or timeout}
\item GPT-2: \textbf{OOM or timeout}

\end{itemize}
\subsection{Seeds}

Single seed (42). No multi-seed runs.

\subsection{Per-Step Timing Measurement}

We measure per-step training time:

\begin{lstlisting}
import time
start = time.time()
for step in range(5):
    ...  # training step
elapsed = time.time() - start
per_step = elapsed / 5
\end{lstlisting}
