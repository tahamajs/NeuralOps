\section{Related Work}

\subsection{Linear Attention}

\textbf{Linear Transformer} (Katharopoulos et al., 2020) first proposed 
replacing softmax with a kernel feature map. \textbf{Performer} (Choromanski 
et al., 2021) uses positive orthogonal random features (PORF). 
\textbf{cosFormer} (Qin et al., 2022) uses ReLU with a cosine reweighting. 
\textbf{Nystr mformer} (Xiong et al., 2021) uses Nystr m approximation.

LEKAv1 uses classical RFF for the Gaussian kernel with QR-orthogonalized 
projections.

\subsection{Random Fourier Features}

\textbf{Rahimi \& Recht (2007)} introduced RFF for kernel approximation:

\[
\kappa(x, y) \approx \phi(x)^\top \phi(y), \quad
\phi(x) = \sqrt{\frac{2}{F}} \cos(x \omega + b), \quad \omega \sim p(\omega)
\tag{2.1}
\]

where $p(\omega)$ is the spectral distribution of the kernel. For the 
Gaussian kernel $\exp(-\|x - y\|^2 / 2)$:

\[
p(\omega) = \mathcal{N}(0, I)
\tag{2.2}
\]

Our $\phi(x) = [\cos(xW), \sin(xW)]/\sqrt{F}$ is a variant with zero 
phase ($b = 0$) and separate sin/cos components.

\subsection{Kernel Methods in Attention}

\textbf{Kernelized attention} (Choromanski et al., 2021) uses $e^{x \cdot y}$ 
directly. \textbf{SOFTmax kernel} is not a valid PSD kernel in general, but 
its symmetric part is.
