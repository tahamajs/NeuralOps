\subsubsection{Padding/Repeating}

If source weight has $d_\text{out} < d$ (e.g., GQA K/V), we repeat:

\begin{lstlisting}
if w_main.shape[0] < D and D % w_main.shape[0] == 0:
    rep = D // w_main.shape[0]
    w_main = w_main.repeat(rep, 1)
\end{lstlisting}

\subsubsection{out\_proj Weight Layout}

Direct copy from $W_O$.

\subsubsection{Nested Encoder Output}

For nested encoders, \texttt{out\_proj} is set to identity:

\begin{lstlisting}
elif self.is_nested_encoder:
    nn.init.eye_(self.out_proj.weight)
    if self.out_proj.bias is not None:
        nn.init.zeros_(self.out_proj.bias)
\end{lstlisting}

\subsection{The A\_log Parameter}

\begin{lstlisting}
self.A_log = nn.Parameter(torch.log(torch.arange(1, self.d_model + 1, dtype=torch.float32)))
\end{lstlisting}

\textbf{Init.} $A_{\log, i} = \log(i)$, so $\gamma_i = \sigma(-i)$.

\textbf{Interpretation.} Higher dimensions have larger $A_{\log}$ $\to$ smaller $\gamma$ 
$\to$ faster forgetting.

\subsection{The Preservation Gate}

\begin{lstlisting}
self.pres_gate = nn.Parameter(torch.tensor(2.0))
\end{lstlisting}

At init, $\alpha = \sigma(2.0) \approx 0.88$. During training, the model can 
shift $\alpha$ toward 0 (rely on residual) or 1 (rely on SSM output).

\subsection{Injection Algorithm}

\textbf{Algorithm 2:} Inject Mamba-Inspired SSM Attention
\begin{lstlisting}
Input:  model M, config
Output: M with attention replaced

1: for   in transformer_layers(M) do
2:     src $\leftarrow$ get_attention( )
3:     new $\leftarrow$ Mamba(d_model, old_attn=src)
4:     replace( , new)
5: end for
6: return M
\end{lstlisting}

\subsection{Skip Logic}

The injection hook skips:

\begin{itemize}
\item Layers already injected (\texttt{isinstance(src, Mamba)})
\item Qwen3.5 hybrid DeltaNet/LinearAttention layers

\end{itemize}
\begin{lstlisting}
if "DeltaNet" in c_name or "LinearAttention" in c_name:
    return None
\end{lstlisting}

\subsection{Failure Modes}

\begin{table}[H]
\centering
\small
\begin{tabular}{lll}
\toprule
\textbf{Failure} & \textbf{Detection} & \textbf{Response} \\
\midrule
UniversalAdapter throws & try/except & \textbf{Raise RuntimeError} \\
Missing Q/K/V & \texttt{missing\_after} non-empty & \textbf{Raise RuntimeError} \\
Near-zero norm & Frobenius check & \textbf{Raise RuntimeError} \\
Injection fail & Exception & Log error, return None \\
\bottomrule
\end{tabular}
\end{table}

\textbf{Note.} \texttt{copy\_weights} raises exceptions (does not gracefully degrade). 
The injection hook catches them and returns None.
