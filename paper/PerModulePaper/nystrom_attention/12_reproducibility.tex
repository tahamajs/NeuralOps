\subsection{Known Issues}

\begin{itemize}
\item Windows: use \texttt{PYTHONIOENCODING=utf-8}
\item CUDA $\ge$ 11.8 recommended
\item Nystr m branch inactive for $N \leq 128$
\item Causal decoders always use dense fallback

\end{itemize}
