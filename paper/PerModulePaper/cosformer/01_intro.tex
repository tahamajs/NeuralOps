
\section{Introduction}

\subsection{Motivation}

Transformer self-attention computes pairwise interactions between all tokens 
in a sequence:

\[
\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V
\]

The intermediate attention matrix $A = \text{softmax}(QK^\top / \sqrt{d})$ 
requires $\mathcal{O}(L^2)$ time and memory. For $L = 4096$ and 16-bit 
precision, this is 32 MB per head -- the dominant cost for long-context 
inference.

\textbf{Linear attention} replaces softmax with a kernel feature map 
$\phi(\cdot)$ such that the attention can be decomposed:

\[
\text{Attn}(Q_i, K, V) \approx \frac{\phi(Q_i)^\top \sum_j \phi(K_j) V_j^\top}{\phi(Q_i)^\top \sum_j \phi(K_j)}
\]

The sums $\sum_j \phi(K_j) V_j^\top$ and $\sum_j \phi(K_j)$ can be computed 
once with $\mathcal{O}(L)$ complexity, then queried per-token.

\textbf{Problem.} Linear attention loses the \textbf{locality} of softmax attention. 
Softmax with a scale factor tends to concentrate mass on nearby tokens 
(especially with positional encodings); kernel-based linear attention 
spreads attention uniformly.

\subsection{Cosformer's Solution}

Qin et al. (2022) propose Cosformer, which recovers locality by 
\textbf{reweighting} the key and query features with cosine/sine of position:

\[
\tilde{q}_i = \phi(q_i) \cdot \cos\!\left(\frac{\pi i}{2 L}\right), \quad
\tilde{q}'_i = \phi(q_i) \cdot \sin\!\left(\frac{\pi i}{2 L}\right)
\]

The attention output becomes:

\[
\text{Attn}(Q_i, K, V) = \frac{\sum_j \tilde{q}_i^\top \tilde{k}_j V_j + \sum_j \tilde{q}_i'^\top \tilde{k}_j' V_j}{\sum_j \tilde{q}_i^\top \tilde{k}_j + \sum_j \tilde{q}_i'^\top \tilde{k}_j'}
\]

The cosine/sine weights decay with position, giving nearby tokens higher 
weights -- mimicking softmax's locality.

\subsection{Our Approach}

We present a \textbf{production-hardened port} of Cosformer to pretrained 
transformers. Key features:

\begin{enumerate}
\item \textbf{Exact weight transfer} via \texttt{copy\_weights} for four architecture families.
\item \textbf{Two computational paths:}
\end{enumerate}
\begin{itemize}
\item \textbf{Encoder:} associative accumulation via \texttt{KV = K^T V} matmul.
\item \textbf{Decoder:} chunked prefix-sum with \texttt{chunk\_size = 32}.
\end{itemize}
\begin{enumerate}
\item \textbf{RoPE support} for modern decoders (Qwen, LLaMA).
\item \textbf{GQA support} via \texttt{repeat\_kv}.
\item \textbf{LoRA recovery} at rank $r$.

\end{enumerate}
\subsection{Contributions}

\begin{itemize}
\item \textbf{A complete port of Cosformer} to four pretrained transformer families.
\item \textbf{Two implementations of the attention path:} bidirectional associative
  and causal chunked prefix-sum.
\item \textbf{An empirical evaluation} on DistilBERT, RoBERTa, and GPT-2 on SST-2.
\item \textbf{An honest assessment} of what works (encoder path) and what doesn't
  (RoBERTa's training instability).
\item \textbf{Full reproducibility}, including code, checkpoints, and evaluation scripts.

\end{itemize}
