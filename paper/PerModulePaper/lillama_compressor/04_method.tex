Registered in COMPRESSOR\_REGISTRY as 'lillama' and 'lillama\_compressor'.

Mathematical Formulation:
1. Input and Output Activations:
   $$X \\\\in \\\\mathbb{R}^{N \\\\times d\_{in}}, \\\\quad Y \\\\in \\\\mathbb{R}^{N \\\\times d\_{out}}$$
2. Empirical Cross-Covariance Matrix:
   $$C\_{YX} = \\\\frac{1}{N} Y^\\\\top X \\\\in \\\\mathbb{R}^{d\_{out} \\\\times d\_{in}}$$
3. Truncated Singular Value Decomposition:
   $$C\_{YX} = U \\\\Sigma V^\\\\top \\\\approx U\_r \\\\Sigma\_r V\_r^\\\\top$$
4. Optimal }\end{quote}

\subsection{Numerical Stability and Fallback Protection}
Before committing module replacements, the framework validates reconstruction error norms and parameter scaling factors. Should numerical instability arise or error ceilings be breached, safety guardrails maintain uncompressed execution or trigger localized LoRA adaptation.
