\subsubsection{3.2 Detailed Trace Execution Steps}
1. \textbf{Module Scanning}: Traverse named modules to find all instances of \texttt{nn.MultiheadAttention}.
2. \textbf{Singular Spectrum Analysis}: Perform SVD on projection weight tensors ($W_Q, W_K, W_V, W_O$). Calculate normalized cumulative energy vectors $E_k$.
3. \textbf{Adaptive Rank Assignment}: Determine optimal integer rank $r^* = \max(r_{\min}, \text{where}(E_k \ge \eta)[0] + 1)$.
4. \textbf{Layer Factorization}: Construct \texttt{CompressedAttentionLayer}, slice truncated SVD factors, and replace standard attention layers in-place.
5. \textbf{Stats Logging}: Log original vs compressed parameter counts and compression ratios $\mathcal{C}_R$.
