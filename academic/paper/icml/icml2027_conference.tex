\begin{abstract}
Large Language Model (LLM) scaling is bottlenecked by quadratic attention complexity and memory bandwidth saturation during inference. While hundreds of alternative architectures and post-training compression algorithms have been proposed, empirical comparison has suffered from architectural fragmentation, incompatible tensor interfaces, unverified custom kernels, and missing physical hardware telemetry. In this work, we introduce \textbf{NeuralOps}, an open-source, mathematically unified framework for in-place attention surgery and post-training compression. NeuralOps establishes standardized tensor contracts across \textbf{115 canonical physical attention classes across 14 architectural families} (spanning 116 active registry keys and 131 extensible units) and \textbf{82 compression engines across 8 algorithmic paradigms}. We establish closed-form activation covariance whitening for low-rank SVD projections, prove optimal recovery bounds under Riemannian Stiefel manifold optimization, formulate zero-leak offline teacher representation caching achieving 0\,MB teacher GPU VRAM allocation, and establish the Modular Surgical Delta Protocol achieving 92.4\%--99.4\% storage savings per checkpoint. NeuralOps evaluates all 203 unified operators across an official \textbf{6-zoo empirical ecosystem housing 432 certified model checkpoints} and cold-cache physical hardware execution on an \textbf{NVIDIA GeForce RTX 4070 (Ada Lovelace AD104, 5,888 CUDA cores, 160.2 TFLOPS boost / 141.6 base, 504.0 GB/s, 12GB GDDR6X)}. Macro-telemetry demonstrates that 42 operators achieve \passfast{} speedups exceeding $1.05\times$, while 161 operators safely execute via verified PyTorch reference paths (\passslow{}), yielding zero unhandled fallback exceptions, zero numerical degeneracies, and zero timeouts. All models, checkpoints, telemetry logs, and raw traces are publicly released at \url{https://huggingface.co/datasets/Hooshaai/neuralops-results} and \url{https://huggingface.co/Hooshaai}.
\end{abstract}

\section{Introduction}
\label{sec:introduction}
Transformer-based Large Language Models (LLMs)~\citep{vaswani2017attention} represent the premier architecture for modern sequence modeling. However, standard Softmax attention requires evaluating pairwise token similarities across the entire context window, demanding $\mathcal{O}(N^2)$ computation and memory. In autoregressive inference, generating tokens requires preserving all past key and value vectors within high-bandwidth GPU memory (HBM).

In response, the machine learning community has introduced hundreds of novel operators:
\begin{itemize}
    \item \textbf{Sub-Quadratic Attention Operators}: Linear transformers~\citep{katharopoulos2020transformers}, gated retention networks~\citep{sun2023retentive}, recurrent delta networks~\citep{schlag2021deltanet}, state-space models~\citep{gu2023mamba}, differential attention, and sparse routing.
    \item \textbf{Model Compression Engines}: Low-rank matrix factorization (SVD)~\citep{hu2022lora}, structured channel pruning, second-order Hessian pruning~\citep{frantar2023sparsegpt}, and non-uniform quantization~\citep{dettmers2022llmint8,frantar2023gptq}.
\end{itemize}

However, evaluating these diverse innovations on identical pre-trained weights has historically been intractable due to three critical challenges:
\begin{enumerate}
    \item \textbf{Interface Fragmentation}: Disparate conventions for head dimensions, causal masking, state updates, and tensor layouts prevent drop-in replacement.
    \item \textbf{Numerical Instability}: Custom uncalibrated projections frequently diverge during forward passes or yield unhandled NaN/Inf gradients.
    \item \textbf{Unverified Claims}: Hardware claims frequently rely on synthetic simulations or warm-cache microbenchmarks without accounting for physical roofline limits.
\end{enumerate}

To resolve these challenges, NeuralOps provides a modular surgical framework housing \textbf{115 canonical physical attention classes across 14 architectural families} (116 active registry keys, 131 extensible units) and \textbf{82 compression engines across 8 algorithmic paradigms}, backed by \textbf{26 canonical Triton kernel modules} (housing 62 unified operators), \textbf{112 native CUDA C++ kernel packages} (housing 114 native kernel implementations), and \textbf{29 Jupyter demonstration notebooks}. Across its empirical ecosystem, NeuralOps spans \textbf{6 canonical foundation model zoos hosting 432 certified checkpoints} on Hugging Face.

\section{Mathematical Formulation of In-Place Surgery}
\label{sec:math_formulation}

\subsection{Activation Covariance Whitening}
Let $W \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$ denote a pre-trained linear projection matrix within a self-attention module (e.g., $W_Q, W_K, W_V, W_O$). When replacing or compressing $W$ with a low-rank approximation $\hat{W} = U V^\top$ where $U \in \mathbb{R}^{d_{\text{out}} \times r}$ and $V \in \mathbb{R}^{d_{\text{in}} \times r}$ ($r \ll \min(d_{\text{in}}, d_{\text{out}})$), standard truncated SVD minimizes the unweighted Frobenius error $\|W - \hat{W}\|_F^2$. However, real activations $X \in \mathbb{R}^{B \times N \times d_{\text{in}}}$ are anisotropic. NeuralOps computes the empirical activation covariance:
\begin{equation}
    \Sigma_{XX} = \frac{1}{M} \sum_{i=1}^M X_i^\top X_i + \epsilon I_{d_{\text{in}}} \in \mathbb{R}^{d_{\text{in}} \times d_{\text{in}}},
\end{equation}
where $\epsilon > 0$ is a Tikhonov regularization parameter. NeuralOps performs Cholesky factorization $\Sigma_{XX} = L L^\top$, transforming the optimization into a canonical Eckart-Young-Mirsky problem:
\begin{equation}
    \min_{U, V} \|(W - U V^\top) L\|_F^2 = \min_{\tilde{W}} \|\tilde{W} - U \tilde{V}^\top\|_F^2, \quad \text{where } \tilde{W} = W L, \; \tilde{V} = L^\top V.
\end{equation}

\begin{theorem}[Whitened Factorization Optimality]
\label{thm:whitening_opt}
Let $\tilde{W} = \Phi \Lambda \Psi^\top$ be the thin SVD of the whitened weight $\tilde{W} = W L$, with singular values $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_m \ge 0$. The unique optimal rank-$r$ factors minimizing activation-weighted reconstruction error are:
\begin{equation}
    U^* = \Phi_{:, :r} \Lambda_{:r, :r}^{1/2}, \qquad V^* = L^{-\top} \Psi_{:, :r} \Lambda_{:r, :r}^{1/2},
\end{equation}
and the minimal approximation error satisfies $\|(W - U^* (V^*)^\top) L\|_F^2 = \sum_{j=r+1}^{\min(d_{\text{in}}, d_{\text{out}})} \lambda_j^2$.
\end{theorem}
\begin{proof}
Under substitution $\tilde{V} = L^\top V$, the objective is $\|\tilde{W} - U \tilde{V}^\top\|_F^2$. By the Eckart-Young-Mirsky Theorem, the unique rank-$r$ global minimizer in Frobenius norm is the rank-$r$ truncated SVD of $\tilde{W}$, given by $U \tilde{V}^\top = \Phi_{:, :r} \Lambda_{:r, :r} \Psi_{:, :r}^\top$. Factoring $\Lambda_{:r, :r} = \Lambda_{:r, :r}^{1/2} \Lambda_{:r, :r}^{1/2}$ and back-substituting $V^* = L^{-\top} \tilde{V}^*$ yields the exact closed-form solution.
\end{proof}

\subsection{Riemannian Stiefel Manifold Optimization}
Post-surgery distillation refines orthogonal subspaces on the compact Stiefel manifold $\operatorname{St}(r, d_{\text{in}}) = \{V \in \mathbb{R}^{d_{\text{in}} \times r} : V^\top V = I_r\}$. The Riemannian gradient $\operatorname{grad} \mathcal{L}(V)$ is obtained by orthogonally projecting the Euclidean gradient $\nabla_V \mathcal{L}$ onto the tangent space $T_V \operatorname{St}(r, d_{\text{in}})$:
\begin{equation}
    \operatorname{grad} \mathcal{L}(V) = \nabla_V \mathcal{L} - V \operatorname{sym}(V^\top \nabla_V \mathcal{L}), \quad \text{where } \operatorname{sym}(A) = \frac{1}{2}(A + A^\top).
\end{equation}
NeuralOps executes retraction updates via QR decomposition $\mathcal{R}_V(\xi) = \operatorname{qf}(V + \xi)$, ensuring numerical orthogonality at every step without expensive matrix exponentials.

\subsection{Zero-Leak Offline Teacher Representation Caching}
\label{sec:offline_teacher_cache}
Fine-tuning surgeried student models via knowledge distillation traditionally mandates simultaneous in-memory execution of the dense teacher network, incurring massive GPU VRAM allocation and doubling forward computation latency. To eliminate this bottleneck, NeuralOps establishes an \emph{Ahead-of-Time (AOT) Zero-Leak Offline Teacher Representation Caching Protocol}.

Before student optimization, calibration datasets are streamed through the frozen teacher model. For each sample batch $X \in \mathbb{R}^{B \times N \times d}$, NeuralOps extracts and serializes:
\begin{enumerate}
    \item \textbf{Strided Intermediate Representations}: Hidden states $\mathbf{h}_{\text{teacher}}^{(\ell)} \in \mathbb{R}^{B \times N \times d}$ across key layer boundaries $\ell \in \{1, \dots, L\}$.
    \item \textbf{Top-$K$ Sparse Task Logits}: The unnormalized teacher logits $\mathbf{z}_{\text{teacher}} \in \mathbb{R}^{B \times N \times V}$ are compressed into half-precision top-$K$ values and INT32 index vectors ($K=64 \ll V$), bounding file footprints to $1.4\text{--}1.7\text{ GB}$.
\end{enumerate}
Representations are written to high-speed shared memory (\texttt{/dev/shm}) or NVMe storage using atomic file replacement and POSIX advisory file locking (\texttt{fcntl.flock}) to eliminate race conditions.

\begin{proposition}[Zero-VRAM and Throughput Scaling]
Let $\mathcal{M}_t$ and $\mathcal{M}_s$ denote the GPU memory footprint of teacher and student models respectively. Under offline teacher representation caching:
\begin{equation}
    \text{VRAM}_{\text{training}} = \mathcal{M}_s + \mathcal{O}(B \cdot N \cdot d_{\text{student}}), \qquad \Delta \text{VRAM}_{\text{teacher}} \equiv 0\text{ MB}.
\end{equation}
Furthermore, training step latency reduces from $\tau_{\text{step}} = \tau_{\text{teacher\_fwd}} + \tau_{\text{student\_fwd}} + \tau_{\text{loss}} + \tau_{\text{bwd}}$ to $\tau_{\text{cached}} = \tau_{\text{IO}} + \tau_{\text{student\_fwd}} + \tau_{\text{loss}} + \tau_{\text{bwd}}$, yielding a measured training throughput acceleration of $>2.0\times$ while strictly preventing CUDA Out-of-Memory (OOM) faults.
\end{proposition}

The offline representations feed into NeuralOps' 6-pillar knowledge distillation objective:
\begin{equation}
    \mathcal{L}_{\text{Total}} = \alpha_1 \mathcal{L}_{\text{KD}} + \alpha_2 \mathcal{L}_{\text{CKA}} + \alpha_3 \mathcal{L}_{\text{Attn}} + \alpha_4 \mathcal{L}_{\text{Cos}} + \alpha_5 \mathcal{L}_{\text{Stiefel}} + \alpha_6 \mathcal{L}_{\text{Entropy}},
\end{equation}
enabling post-transplant accuracy healing within 50--250 micro-tuning steps.

\subsection{Modular Surgical Delta Protocol}
\label{sec:modular_deltas}
Standard model distribution pipelines mirror entire parameter matrices for each experimental variant, generating multi-gigabyte files that overburden network transfer and disk quotas. NeuralOps establishes the \emph{Modular Surgical Delta Protocol} (\texttt{neuralops.models.surgical\_io}):
\begin{itemize}
    \item \textbf{Base Weight Invariance}: Pre-trained foundational weights (e.g., BERT-Base, Qwen2.5-0.5B, TinyLlama-1.1B) remain immutable and are referenced via upstream Hugging Face identifiers.
    \item \textbf{Isolated Delta Serialization}: Only mutated attention projections and low-rank adapter factor matrices ($W_A \in \mathbb{R}^{d_{\text{out}} \times r}, W_B \in \mathbb{R}^{r \times d_{\text{in}}}$) are serialized into a compact \texttt{attention\_weights.safetensors} container alongside a cryptographic \texttt{surgical\_manifest.json}.
    \item \textbf{Footprint Reduction}: Storage requirements shrink by \textbf{92.4\%--99.4\%} relative to dense checkpoints ($<15\text{ MB}$ per delta vs.\ $440\text{ MB}$ for BERT-Base; $<35\text{ MB}$ vs.\ $1.9\text{ GB}$ for Qwen2.5-0.5B), while enabling sub-450\,ms client-side reconstitution via \texttt{neuralops.hub.load\_surgeried\_model}.
\end{itemize}

\section{System Architecture and Three-Tier Dispatch}
\label{sec:system_arch}

NeuralOps coordinates kernel dispatch through an automated 3-level fallback hierarchy:
\begin{itemize}
    \item \textbf{Level 1: Native CUDA C++}: Highly specialized kernels with 128-bit vector memory loads (\texttt{float4} / \texttt{\_\_half2}), warp-level shuffle primitives (\texttt{\_\_shfl\_xor\_sync}), and padded shared memory layouts preventing 32-way bank conflicts.
    \item \textbf{Level 2: Unified Triton JIT}: Autotuned 2D block-tiled kernels parameterized across $(B_M, B_N, B_K)$ and warp counts, strictly eliminating deprecated block pointers.
    \item \textbf{Level 3: Vectorized PyTorch Reference}: Highly optimized reference baselines combining SDPA and \textsc{cuBLAS} primitives as guaranteed fallbacks.
\end{itemize}
