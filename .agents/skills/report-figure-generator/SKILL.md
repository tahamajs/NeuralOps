# Skill: Publication Figure Generator and Visualization Pipeline

## When to use
Use this skill whenever producing visual evidence (Pareto curves, scaling plots, radar charts, distribution histograms, or performance heatmaps) for NeuralOps technical reports, doctoral dissertations, or conference manuscripts. It enforces strict publication aesthetics, deterministic plotting scripts, dual PDF/PNG export, and full audit traceability.

## Prerequisites
- Python 3.10+ environment with `matplotlib`, `numpy`, and `pandas`.
- System fonts compatible with modern LaTeX typography (Helvetica, Latin Modern, or Computer Modern).
- Read access to `results/registry/master_ledger.jsonl` and parsed audit records from `/tmp/citation_index.json`.
- Output destination directories: `thesis_final/figures/` and `paper/figures/`.

## The 8 Canonical Figure Types

### 1. Pareto Frontier (Latency vs. Accuracy)
Plots inference latency (ms) on the x-axis against model downstream accuracy (%) on the y-axis, highlighting the non-dominated Pareto frontier across compression engines:

```python
import matplotlib.pyplot as plt
from neuralops.core.results_ledger import get_default_ledger

def plot_pareto_compressor(output_pdf: str, output_png: str):
    ledger = get_default_ledger()
    records = ledger.query(category="compressor", only_active=True)
    
    plt.figure(figsize=(6, 4), dpi=300)
    plt.scatter([r["latency_ms"] for r in records], [r["accuracy"] for r in records], color="#1f77b4", alpha=0.7)
    plt.xlabel("Forward Latency (ms)", fontsize=10)
    plt.ylabel("Accuracy (%)", fontsize=10)
    plt.title("Compression Pareto Frontier", fontsize=11)
    plt.grid(True, linestyle="--", alpha=0.5)
    plt.tight_layout()
    plt.savefig(output_pdf)
    plt.savefig(output_png)
    plt.close()
```

### 2. Sequence Length Scaling (Log-Log)
Source: `AUDIT_04_SEQLEN_SCALING_AND_KV_CACHE_MEM.md` (Table 1).
Plots sequence lengths $N \in [128, 256, 512, 1024, 2048, 4096, 8192]$ against execution latency on logarithmic axes. Annotates the theoretical and empirical crossover point at $N \approx 2048$ where linear attention mechanisms surpass $\mathcal{O}(N^2)$ quadratic softmax attention:

```python
def plot_sequence_scaling(output_pdf: str, output_png: str):
    seqlens = [128, 256, 512, 1024, 2048, 4096, 8192]
    softmax_ms = [0.12, 0.28, 0.85, 2.94, 11.20, 44.80, 182.40]
    linear_ms = [0.25, 0.45, 0.88, 1.76, 3.52, 7.04, 14.10]
    
    plt.figure(figsize=(6, 4), dpi=300)
    plt.loglog(seqlens, softmax_ms, label="Softmax Attention O(N^2)", marker="o", color="#d62728")
    plt.loglog(seqlens, linear_ms, label="Linear Attention O(N)", marker="s", color="#2ca02c")
    plt.axvline(x=2048, linestyle=":", color="black", alpha=0.7, label="Crossover (N=2048)")
    plt.xlabel("Sequence Length (N)", fontsize=10)
    plt.ylabel("Latency (ms)", fontsize=10)
    plt.legend(fontsize=8)
    plt.grid(True, which="both", linestyle="--", alpha=0.4)
    plt.tight_layout()
    plt.savefig(output_pdf)
    plt.savefig(output_png)
    plt.close()
```

```python
def plot_speedup_histogram(speedups: list[float], output_pdf: str, output_png: str):
    plt.figure(figsize=(6, 4), dpi=300)
    plt.hist(speedups, bins=25, color="#1f77b4", edgecolor="black", alpha=0.8)
    plt.axvline(x=1.0, color="red", linestyle="--", label="PyTorch Baseline (1.0x)")
    plt.xlabel("Speedup Multiplier over PyTorch Baseline", fontsize=10)
    plt.ylabel("Number of Modules", fontsize=10)
    plt.title("Speedup Distribution Across 203 Operators (SM 8.9)", fontsize=11)

    plt.grid(True, linestyle=":", alpha=0.5)
    plt.tight_layout()

    plt.close()
```

## Plotting Workflow and Execution Standards

1. **Dedicated Script Isolation**: Every figure must be generated by a standalone script named `scripts/benchmarks/plot_<figure_name>.py`.
2. **Dual Vector and Raster Export**: Each script must export both a vector PDF (for inclusion in the PDF manuscript) and a high-resolution PNG (for web rendering and previews):
   ```python
   plt.savefig("thesis_final/figures/<name>.pdf", format="pdf", bbox_inches="tight")
   plt.savefig("thesis_final/figures/<name>.png", format="png", dpi=300, bbox_inches="tight")
   ```
3. **Typography and Style Guidelines**:
   - Font sizes: Title = 11pt, Axis Labels = 10pt, Tick Labels = 9pt, Legend = 8pt.
   - Line widths: Plot lines = 1.5pt, Grid lines = 0.5pt dashed.
   - Use colorblind-accessible color palettes (e.g., `tab10` or `Set2`).

## Common Pitfalls
- Hardcoding synthetic data arrays instead of querying `master_ledger.jsonl` or reading `citation_index.json`.
- Exporting raster graphics with low DPI ($<300$), causing blurriness in the final printed thesis.
- Overcrowding axis ticks on logarithmic plots without explicit formatting (`LogLocator`).
- Omitting the origin audit citation tag (e.g., `\texttt{AUDIT_04}`) in the LaTeX caption.
- Ignoring figure assignments specified in `AGENTS_FILE_ASSIGNMENT_AND_PROVENANCE_GUIDE.md`.
