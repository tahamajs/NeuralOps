# Skill — Tables

## Purpose

Generate paper-ready tables in CSV and Markdown format.

## Sub-skills

- `main-results.md`
- `per-layer-stats.md`
- `failure-taxonomy.md`
- `external-baselines.md`

## Rules

- Every table must have a caption
- Every column must have units
- Every row must be traceable to a source file
- Bold best value in each column
- Report mean ± std with n
- CSV for machine processing, Markdown for the paper
