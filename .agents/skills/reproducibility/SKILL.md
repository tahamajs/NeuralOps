# Skill — Reproducibility

## Purpose

Capture everything required to reproduce every number in the paper.

## Sub-skills

- `environment-capture.md`
- `model-cards.md`
- `dataset-hashes.md`
- `seed-management.md`

## Rules

- Every number in the paper must be reproducible from a single command
- Every dependency version must be pinned
- Every random seed must be documented
- Every dataset and checkpoint must have a hash
