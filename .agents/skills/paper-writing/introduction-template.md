# Introduction Template

## 1.1 Motivation (2-3 paragraphs)

- Concrete use case (not "transformers are popular")
- Cite 3+ papers on the underlying problem
- Explain why this problem matters NOW (deployment, cost, latency)
- Introduce the standard formulation

## 1.2 Problem Statement (1 paragraph)

- Formal statement with math
- List 3-5 constraints
- Define success metric

## 1.3 Our Approach (1 paragraph)

- High-level idea, no math
- Reference the method section

## 1.4 Contributions (4-6 bullets)

- Each bullet must be verifiable
- Each bullet must map to a section

## 1.5 Paper Organization (1 paragraph)

- One sentence per section

## Anti-patterns

- "In recent years, transformers have..." (overused)
- "To the best of our knowledge" (unverifiable)
- Claiming novelty without citing prior work
