# Limitations Template

List at minimum:

1. **Task Coverage** — which tasks were not tested
2. **Model Coverage** — which sizes were not tested
3. **Hardware Coverage** — which GPUs were not tested
4. **Inference Overhead** — if latency increased, say by how much
5. **Parameter Count** — if it increased, say by how much
6. **Recovery Stability** — if loss oscillated, say so
7. **Single-Seed or Multi-Seed** — state n
8. **No Theoretical Guarantee** — if there is no bound, say so
9. **No Comparison with Some Baselines** — list what is missing
10. **Failure Modes Not Fully Diagnosed** — list what remains unexplained

## Rules

- Limitations must be specific, not generic
- Never say "future work will address"
- Never say "minor limitation"
