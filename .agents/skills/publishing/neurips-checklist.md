# NeurIPS Reproducibility Checklist

## Claims

- [ ] All claims in abstract supported by experiments
- [ ] All claims in introduction supported by experiments
- [ ] Limitations stated honestly

## Experiments

- [ ] Hyperparameters reported
- [ ] Compute reported (GPU-hours, CO2)
- [ ] Seeds reported
- [ ] Error bars reported
- [ ] Statistical tests reported

## Data

- [ ] Dataset license stated
- [ ] Preprocessing described
- [ ] Splits described

## Code

- [ ] Code released
- [ ] Checkpoints released
- [ ] Environment documented

## Ethics

- [ ] Broader impact discussed
- [ ] Misuse risks stated
- [ ] Funding disclosed
- [ ] COI disclosed
