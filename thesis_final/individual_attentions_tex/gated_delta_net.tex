\section*{۲. مبانی تئوریک و انگیزه طراحی معماری}
Standard linear attention modules approximate softmax self-attention via associative outer-product state updates S t = S t-1 + k t v t top , suffering from **associative memory capacity saturation** where historical context is unselectively overwritten or unbounded memory accumulations drift. **Gated DeltaNet** resolves associative memory saturation through two fundamental innovations: 1. **Delta-Rule Error-Correction Associative Memory**: Rather than naive additive updates, DeltaNet writes information into orthogonal memory subspaces by minimizing retrieval prediction errors: e t = v t - S t-1 k t . 2. **Data-Dependent Retention Decay Gating**: A continuous sigmoid decay gate beta t = sigma(W beta x t + b beta) in (0, 1) enforces contractive Lyapunov state stability across arbitrary sequence lengths L = 1024 . 3. **Dual Forward-Backward Bidirectional Scanning**: Eliminates the representational blindness of causal recurrences on encoder classification tasks (which collapse to 50.92 on ), providing dense gradient paths across all tokens. 4. **Pretrained Attention Weight Transfer**: Seamlessly inherits pretrained Transformer projection weights ( W q, W k, W v, W o ) via .
