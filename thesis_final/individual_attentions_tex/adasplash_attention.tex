\section*{۲. مبانی تئوریک و انگیزه طراحی معماری}
Standard Multi-Head Attention employs the Softmax activation function, which maps unbounded dot-product affinities s ij = frac q i k j top sqrt d h into a probability distribution: [ operatorname softmax (s) i = frac exp(s i) sum j=1 L exp(s j) > 0, quad forall i in 1, dots, L ] Because the exponential function is strictly positive on the entire real line ( exp(x) > 0, forall x in mathbb R ), Softmax forces every single token in the sequence to assign a non-zero probability mass to all other tokens. In dense context representations, this leads to **diffuse attention leakage**, where background tokens, irrelevant punctuation, and distant padding contaminate the contextual embedding of salient tokens.
