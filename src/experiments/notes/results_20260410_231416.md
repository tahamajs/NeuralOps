The core issue is **"Overfitting to one class"** or, more accurately, **"Lack of Initial Training"**.
- Original Model: Predicts everything as Class 1.
- Compressed Model: Predicts everything as Class 0.
- **Neither** can distinguish between the two classes.

This confirms that the **`classifier` (Head) of the model has never been trained**. Raw BERT understands language but doesn't know how to classify sentiment. To work, it **must** undergo a Fine-Tuning phase on your dataset first.

To fix this and achieve >80-90% Accuracy, follow these steps:

You cannot evaluate an untrained model. You must add a step that:

5.  Evaluates both.

#### 2. Verify the Classifier Head
Ensure that when loading the model, the `classifier` layer is correctly initialized with `num_labels=2`. In your `bert_loader.py`, verify you are using `AutoModelForSequenceClassification` and that `num_labels` is set correctly.

Let's write a unified script that does the full cycle:
1.  Load Model.

3.  Compress Model (SVD Rank 32).
4.  **Train Compressed Model**.
5.  Evaluate and Compare.

If the Original Model's accuracy remains low *after* Fine-Tuning, the problem lies in your **dataset** (e.g., incorrect labels, corrupted text). But if accuracy goes up after training, the issue was simply the lack of training.
