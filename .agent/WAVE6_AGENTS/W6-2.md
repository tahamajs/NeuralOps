## 2. THE FIVE ABSOLUTE LAWS OF WAVE 6 (ZERO TOLERANCE)

Every file you touch or create MUST strictly adhere to these 5 operational invariants:

### LAW 1 — NO FAKE DATA FOR REAL EVALUATIONS
- If an example claims to demonstrate NIAH, serving, KD, quantization, or model surgery, it MUST use a real model and real input.
- `torch.randn` is STRICTLY FORBIDDEN for evaluation inputs, attention maps, or data simulation.
- `torch.randn` is ONLY permitted for standard weight initialization (`nn.init`) and CPU microbenchmarks explicitly titled "synthetic".

### LAW 2 — NO HARDCODED PASS STATUS
- Calling `pass_fail("Overall ...", True, ...)` with a literal `True` is FORBIDDEN.
- The overall status variable MUST be computed from actual sub-checks:
  ```python
  all_passed = p1 and p2 and p3
  pass_fail("Overall Status", all_passed, "All checks passed" if all_passed else "Sub-check failures detected")
  return 0 if all_passed else 1
  ```
- The `main()` function MUST return `0` on success and `1` on failure.

### LAW 3 — NO SILENT SKIP ON MISSING DEPENDENCIES
- Silent `try: import ... except ImportError: pass` blocks that hide missing modules or fake a successful run are FORBIDDEN.
- If a required dependency is missing:
  ```python
  try:
      from neuralops.module import Feature
  except ImportError as err:
      raise RuntimeError(
          f"This example requires neuralops.module.Feature, which is not available: {err}. "
          "Either implement the module or delete this example."
      ) from err
  ```
- For optional external engines (like vLLM or GGUF), explicitly print `skip(...)` and do not crash, but honestly state that the component was skipped.

### LAW 4 — NO REIMPLEMENTATION OF LIBRARY FEATURES
- If a feature belongs in `neuralops`, the example MUST import and use it.
- Defining inline mock algorithms (such as `def pillar1_...`, `def compress_hnc_svd`, `def prune_mlp_intermediate`) inside the example and claiming they demonstrate library features is FORBIDDEN.
- If the library lacks the capability, either raise `NotImplementedError("<detailed explanation>")` or delete the example.

### LAW 5 — EVERY REMAINING EXAMPLE MUST BE RUNNABLE ON CPU
- Every example remaining in `examples/` must execute cleanly on CPU:
  ```bash

  ```
- It must complete in <60 seconds and exit with returncode 0.

## 4. GRANULAR, FILE-BY-FILE AUDIT & REMEDIATION TASKS

### 4.1 Exact Code-Level Implementation for Baseline Audit Scanner (`scripts/audit_examples_baseline.py`)

#### Comprehensive AST and Subprocess Scanner Implementation:
```python
#!/usr/bin/env python3
import ast
import json
import re
import subprocess
import sys
import time
from pathlib import Path

EXAMPLES_DIR = Path("examples")
OUTPUT_JSON = Path("audits/wave6/baseline_raw.json")
OUTPUT_MD = Path("audits/wave6/baseline_audit.md")

OUTPUT_JSON.parent.mkdir(parents=True, exist_ok=True)

results = {}
for i in range(1, 21):
    ex_files = list(EXAMPLES_DIR.glob(f"{i:02d}_*.py"))
    if not ex_files:
        continue
    target = ex_files[0]
    code = target.read_text(encoding="utf-8")
    
    # 1. AST Analysis
    tree = ast.parse(code)
    randn_calls = []
    pass_fail_true = []
    silent_skips = []
    reimplemented_pillars = []
    fragile_paths = []
    
    for node in ast.walk(tree):
        # Detect torch.randn
        if isinstance(node, ast.Call):
            func_name = ast.unparse(node.func)
            if "torch.randn" in func_name:
                randn_calls.append(node.lineno)
            if "pass_fail" in func_name:
                args = [ast.unparse(a) for a in node.args]
                if len(args) >= 2 and args[1] == "True":
                    pass_fail_true.append(node.lineno)
        # Detect except ImportError: pass
        if isinstance(node, ast.ExceptHandler):
            if node.type and "ImportError" in ast.unparse(node.type):
                if len(node.body) == 1 and isinstance(node.body[0], ast.Pass):
                    silent_skips.append(node.lineno)
        # Detect def pillar...
        if isinstance(node, ast.FunctionDef):
            if node.name.startswith("pillar") or node.name.startswith("loss_pillar"):
                reimplemented_pillars.append((node.lineno, node.name))
    
    # Detect fragile paths
    for idx, line in enumerate(code.splitlines(), 1):
        if re.search(r"\.transformer\.layer\[|\._wrapped_attention", line):
            fragile_paths.append(idx)
            
    # 2. Execution timing
    t0 = time.time()
    try:
        proc = subprocess.run([sys.executable, str(target)], capture_output=True, text=True, timeout=60)
        ret_code = proc.returncode
        err_msg = proc.stderr[-200:] if ret_code != 0 else ""
    except subprocess.TimeoutExpired:
        ret_code = 124
        err_msg = "TIMEOUT (>60s)"
    elapsed = time.time() - t0
    
    results[target.name] = {
        "example_num": i,
        "exit_code": ret_code,
        "elapsed_seconds": round(elapsed, 2),
        "error_snippet": err_msg,
        "randn_lines": randn_calls,
        "pass_fail_true_lines": pass_fail_true,
        "silent_skip_lines": silent_skips,
        "inline_pillars": reimplemented_pillars,
        "fragile_paths": fragile_paths,
    }

OUTPUT_JSON.write_text(json.dumps(results, indent=2))
print(f"Wrote {OUTPUT_JSON}")
```
