## 2. THE FIVE ABSOLUTE LAWS OF WAVE 6 (ZERO TOLERANCE)

Every file you touch or create MUST strictly adhere to these 5 operational invariants:

### LAW 1 — NO FAKE DATA FOR REAL EVALUATIONS
- If an example claims to demonstrate NIAH, serving, KD, quantization, or model surgery, it MUST use a real model and real input.
- `torch.randn` is STRICTLY FORBIDDEN for evaluation inputs, attention maps, or data simulation.
- `torch.randn` is ONLY permitted for standard weight initialization (`nn.init`) and CPU microbenchmarks explicitly titled "synthetic".

### LAW 2 — NO HARDCODED PASS STATUS
- Calling `pass_fail("Overall ...", True, ...)` with a literal `True` is FORBIDDEN.
- The overall status variable MUST be computed from actual sub-checks:
  ```python
  all_passed = p1 and p2 and p3
  pass_fail("Overall Status", all_passed, "All checks passed" if all_passed else "Sub-check failures detected")
  return 0 if all_passed else 1
  ```
- The `main()` function MUST return `0` on success and `1` on failure.

### LAW 3 — NO SILENT SKIP ON MISSING DEPENDENCIES
- Silent `try: import ... except ImportError: pass` blocks that hide missing modules or fake a successful run are FORBIDDEN.
- If a required dependency is missing:
  ```python
  try:
      from neuralops.module import Feature
  except ImportError as err:
      raise RuntimeError(
          f"This example requires neuralops.module.Feature, which is not available: {err}. "
          "Either implement the module or delete this example."
      ) from err
  ```
- For optional external engines (like vLLM or GGUF), explicitly print `skip(...)` and do not crash, but honestly state that the component was skipped.

### LAW 4 — NO REIMPLEMENTATION OF LIBRARY FEATURES
- If a feature belongs in `neuralops`, the example MUST import and use it.
- Defining inline mock algorithms (such as `def pillar1_...`, `def compress_hnc_svd`, `def prune_mlp_intermediate`) inside the example and claiming they demonstrate library features is FORBIDDEN.
- If the library lacks the capability, either raise `NotImplementedError("<detailed explanation>")` or delete the example.

### LAW 5 — EVERY REMAINING EXAMPLE MUST BE RUNNABLE ON CPU
- Every example remaining in `examples/` must execute cleanly on CPU:
  ```bash
  python <example_file>.py
  ```
- It must complete in <60 seconds and exit with returncode 0.
