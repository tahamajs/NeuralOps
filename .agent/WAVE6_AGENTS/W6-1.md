## 3. ARCHITECTURAL CONTEXT & DEEP DOMAIN BACKGROUND

`examples/_shared/` is the bedrock of the entire NeuralOps examples suite. Every single example (from 01 to 20) imports reporting, benchmarking, mock models, data loaders, and verification utilities from this package.

Historically, utilities in this directory suffered from critical integrity flaws:
1. `pass_fail(name, condition, detail)` accepted any truthy value (e.g. non-empty strings, ints), causing accidental PASS reports. It never verified that `condition` is strictly boolean.
2. `TinyClassifier` had arbitrary parameter counting rather than reflecting actual torch module weights, and did not reliably behave like a standard torch `nn.Module`.
3. `assert_parity` did not rigorously enforce absolute and relative tolerances, allowing divergent outputs to pass silently.
4. `toy_dataloader` and `toy_calibration_loader` were occasionally returning unstructured random tensors instead of realistic integer token batches or feature batches.
5. `skip_if_missing` did not distinguish between missing optional extras and fatal dependency failures.

If `examples/_shared/` is broken or dishonest, all 20 examples will inherit those flaws. Therefore, W6-1 must harden, verify, and test every single function in `examples/_shared/` before Phase 2 begins.

```python
class TinyClassifier(torch.nn.Module):
    def __init__(self, vocab_size: int = 1000, hidden_dim: int = 64, num_classes: int = 2, n_layers: int = 2, seed: int = 42):
        super().__init__()
        torch.manual_seed(seed)
        self.config = type("Config", (), {
            "vocab_size": vocab_size,
            "hidden_size": hidden_dim,
            "num_hidden_layers": n_layers,
            "num_attention_heads": 4
        })()
        self.embedding = torch.nn.Embedding(vocab_size, hidden_dim)
        self.layers = torch.nn.ModuleList([
            torch.nn.TransformerEncoderLayer(d_model=hidden_dim, nhead=4, dim_feedforward=hidden_dim*2, batch_first=True)
            for _ in range(n_layers)
        ])
        self.head = torch.nn.Linear(hidden_dim, num_classes)

    def count_parameters(self) -> int:
        return sum(p.numel() for p in self.parameters())

    def count_trainable_parameters(self) -> int:
        return sum(p.numel() for p in self.parameters() if p.requires_grad)

    def forward(self, input_ids: torch.Tensor, attention_mask: torch.Tensor | None = None) -> torch.Tensor:
        x = self.embedding(input_ids)
        for layer in self.layers:
            x = layer(x)
        return self.head(x.mean(dim=1))
```

#### C. In `examples/_shared/verification.py`:
**Issue:** `assert_parity` called `pass_fail(label, True, ...)` unconditionally!
**Required Fix:**
```python
def assert_parity(actual: torch.Tensor, expected: torch.Tensor, atol: float = 1e-3, rtol: float = 1e-3, label: str = "Parity") -> bool:
    max_diff = (actual - expected).abs().max().item()
    is_close = bool(torch.allclose(actual, expected, atol=atol, rtol=rtol))
    pass_fail(label, is_close, f"max_abs_diff={max_diff:.6f}, atol={atol}")
    if not is_close:
        raise AssertionError(f"{label} failed: max_diff={max_diff:.6f} exceeds atol={atol}")
    return is_close
```
