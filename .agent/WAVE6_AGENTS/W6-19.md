## 4. GRANULAR, FILE-BY-FILE AUDIT & REMEDIATION TASKS

### 4.1 Exact CI Runner for Headless Log Capture

```bash
#!/usr/bin/env bash
set -uo pipefail

mkdir -p audits/wave6/logs
REPORT="audits/wave6/all_examples_run.md"

echo "# Full Headless Examples Execution Report" > "$REPORT"
echo "| File | Exit Code | Runtime (s) | Status |" >> "$REPORT"
echo "|---|---|---|---|" >> "$REPORT"

for f in examples/[0-9]*.py; do
    base=$(basename "$f")
    log_file="audits/wave6/logs/${base%.py}.log"
    echo "Executing $f..."
    
    t0=$(date +%s)
    if python "$f" > "$log_file" 2>&1; then
        code=0
        status="PASS"
    else
        code=$?
        status="FAIL"
    fi
    t1=$(date +%s)
    elapsed=$((t1 - t0))
    
    echo "| \`$base\` | $code | ${elapsed}s | $status |" >> "$REPORT"
done
```
