# NeuralOps v1.2.0 Release Report

## Release Summary

- **Version:** 1.2.0
- **Release Date:** 2026-10-09
- **PyPI URL:** https://pypi.org/project/neuralops/1.2.0/
- **GitHub Tag:** `v1.2.0`

## What's New

### Package & Dependency Architecture
- Modular backend extras: `cuda`, `rocm`, `mps`, `cpu`, `eval`, `benchmark`, `dev`, `docs`, `all`.
- Core dependencies trimmed to minimal pure-Python requirements (`packaging>=23.0`).
- Compact wheel distribution: **1.9 MB** (`dist/neuralops-1.2.0-py3-none-any.whl`).

### Documentation & Ecosystem
- Complete professional [README.md](README.md) with News, Architecture, Benchmark zoo, and Platform Support Matrix.
- [RENAME_MAP.md](docs/RENAME_MAP.md) detailing 657 deprecated alias mappings with active runtime redirection.
- [COMPARISON.md](docs/COMPARISON.md) and [COMPARISON_RESULTS.md](docs/COMPARISON_RESULTS.md) comparing capabilities against FlashAttention, FLA, xformers, and vLLM.
- [MEMORY_PROFILE.md](docs/MEMORY_PROFILE.md) verifying low CPU memory consumption (<0.1 MB peak overhead).
- Complete user manual suite: [QUICKSTART.md](docs/QUICKSTART.md), [ARCHITECTURE.md](docs/ARCHITECTURE.md), [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

### Hugging Face Hub Integration
- Pre-packaged model card template and deployment configuration at [`hf_upload/distilbert-svd-attention/README.md`](hf_upload/distilbert-svd-attention/README.md) and [`docs/HUGGINGFACE_UPLOAD.md`](docs/HUGGINGFACE_UPLOAD.md).
- Model reference: `tahamajs/distilbert-svd-attention`.

### Benchmarks & Performance
- Unified CLI runtime: `python3 -m neuralops.benchmarks run|resume|plan|list|verify|results`.
- Measured CPU latency: `decay_linear_attention` at 8.20 ms and `gated_linear_attention` at 13.17 ms with transparent fallback.

### Community & Standards
- Issue templates for Bug Reports, Feature Requests, and Documentation improvements.
- Contributor PR template (`.github/PULL_REQUEST_TEMPLATE.md`).
- Responsible vulnerability disclosure policy (`SECURITY.md`).
- GitHub Sponsors configuration (`.github/FUNDING.yml`).
