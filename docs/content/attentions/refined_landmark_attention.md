# Refined Landmark Attention: Multi-Scale Landmark Anchors

> **Family**: Memory-Augmented & External Latent Recurrences · **NeuralOps Registry ID**: `refined_landmark_attention`

## Executive Abstract

Hierarchical multi-level landmark attention building a multi-scale pyramidal token hierarchy. Enables context window expansion up to 128k tokens with logarithmic attention routing overhead.

In NeuralOps, `refined_landmark_attention` is integrated into the universal attention dispatch table, featuring full support for the 3-level fallback hierarchy, automatic shape validation, and end-to-end autograd backwards passes.

## Mathematical Formulation

The core operator computation is defined as:

$$
\mathcal{L}^{(l)} = \text{Pooling}(\mathcal{L}^{(l-1)}) \implies \text{Hierarchical Pyramidal Context}
$$

During execution, inputs $Q, K, V$ are projected to dimension $d$. In the causal configuration, lower-triangular masking ensures that tokens only attend to past and current time-steps, preserving autoregressive invariants.

## Implementation Details

Usage via the NeuralOps Python API:

```python
import torch

# Instantiate standalone operator
```
