# Hybrid Attention: Softmax + Linear Gated Multi-Branch Fusion

> **Family**: Hybrid Linear-Recurrent & Attention-SSM Architectures · **NeuralOps Registry ID**: `hybrid_attention`

## Executive Abstract

Hybrid attention architecture that blends exact local softmax attention with linear recurrent attention using a learnable gating network $g = \sigma(W_g x)$. Delivers the exact associative recall of softmax alongside the infinite context efficiency of linear recurrence.

In NeuralOps, `hybrid_attention` is integrated into the universal attention dispatch table, featuring full support for the 3-level fallback hierarchy, automatic shape validation, and end-to-end autograd backwards passes.

## Mathematical Formulation

The core operator computation is defined as:

$$
O = g \odot \text{Softmax}\left(\frac{Q K^T}{\sqrt{d}}\right) V + (1 - g) \odot \text{LinearAttn}(Q, K, V)
$$

During execution, inputs $Q, K, V$ are projected to dimension $d$. In the causal configuration, lower-triangular masking ensures that tokens only attend to past and current time-steps, preserving autoregressive invariants.

## Implementation Details

Usage via the NeuralOps Python API:

```python
import torch
from neuralops import attention, replace_attention

# Instantiate standalone operator
attn = attention("hybrid_attention", dim=512, heads=8)
x = torch.randn(2, 64, 512, device="cuda" if torch.cuda.is_available() else "cpu")
out = attn(x)
```
