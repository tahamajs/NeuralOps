## 5. Known Limitations & Mathematical Trade-offs

1. **Hardware Kernel Acceleration vs. Portability**:
   - Triton JIT acceleration is strictly compiled on Linux with NVIDIA GPUs (CUDA compute capability ≥ 7.0). On macOS (Darwin) and non-CUDA hosts, calls automatically route to standard PyTorch SDPA or custom vectorized fallback implementations.
2. **Precision and Autocast Invariants**:
   - Low-rank SVD decompositions (`direct_svd`, `randomized_svd`) must accumulate intermediate matrix multiplications in FP32 (`torch.float32`) to prevent catastrophic cancellation or spectral drift before casting back to model dtype.
3. **KV Cache Decoupling**:
   - Linear attention mechanisms with state-space or recurrent formulation achieve $O(1)$ memory consumption per decode token, but do not maintain standard $O(N)$ key-value histories. They cannot be mixed with standard KV-cache paged allocation without using `NeuralOpsStateCache`.
4. **Parameter Presets vs. Distinct Classes**:
   - The compressor registry contains 89 keys resolving to 73 distinct classes; several keys (such as rank-specific or precision-specific presets like `int4_weight_only`, `fp8_e4m3_hybrid`) share underlying parameterized base engine classes.
