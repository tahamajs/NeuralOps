Module neuralops.tests.test_aegis_v5

Hardening test suite for aegis_v5.py (AegisAttention V5).

Covers the 9 hardening rules applied to this module: 1. config=None safety 2. Multi-arch weight copy: DistilBERT / RoBERTa nested / GPT-2 fused / Qwen GQA 3. Fail-loud on missing mandatory weights 4. Frozen base weights, trainable LoRA after copy 5. GQA kv_repeat 6. RoPE (position_embeddings tuple) 7. Causal masking (decoder) 8. output_attentions returns actual weight tensor (not None) 9. Odd-dim _rotate_half roundtrip 10. inject_aegis_v5 safe/fail paths 11. Registry registration

def test_rotate_half_roundtrip_odd()

def test_rotate_half_roundtrip_odd():
    """For odd dims, two applications should still give -x on the rotated part."""
    x = torch.randn(1, 3, 9)
    rr = _rotate_half(_rotate_half(x))
    # The rotated 8 dims satisfy rr == -x; last dim is preserved → preserved twice → rr[-1] == x[-1]
    assert torch.allclose(rr[..., :-1], -x[..., :-1], atol=1e-5)
    assert torch.allclose(rr[..., -1:], x[..., -1:], atol=1e-5)
