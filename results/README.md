# NeuralOps Experimental Results Repository

This repository stores all empirical benchmark logs, checkpoint metadata, evaluation metrics, and comparative artifacts generated by the SVD & Linear Attention Framework across multiple model architectures and GLUE tasks.

## Directory Structure

- **Top-Level Comparative Reports**:
  - `benchmark_summary_v2.csv`: Aggregate multi-run efficiency metrics across all tracks.
  - `compatibility_report_all_families.md`: Multi-architecture compatibility matrix (Qwen, T5, RoBERTa, BERT, GPT-2).
  - `compatibility_results.csv`: Tabular per-module compatibility status.
  - `master_benchmark_summary.csv` & `master_benchmark_summary.json`: Top-tier verified Pareto frontier candidates.

- **Categorized Run Archives**:
  - **`qwen_*`**: Causal decoder-only benchmark runs evaluating GQA, DeltaNet, and low-rank adaptations on Qwen2.5 / Qwen3.5.
  - **`t5_*`**: Encoder-decoder cross-attention and relative position bias validation runs on T5 (`sst2`, `cola`, `stsb`).
  - **`distilbert_*` & `generalization_bert_*`**: Bidirectional encoder generalization runs on DistilBERT and BERT.
  - **`all_modules_paper_run` & `final_paper_run`**: Canonical paper-grade validation runs with fine-tuning recovery.
