## How to Navigate

### Find a specific module's results
```bash
# 4-model unified run for module "a3"
ls results/03_unified_runs/unified_a3/

# DistilBERT SST-2 full sweep
ls results/02_glue_sweeps/distilbert/distilbert_sst2_sst2_sweep/

# Rank sweep for RoBERTa
ls results/04_rank_sweeps/roberta/deep_rank_roberta/
```

### Find all summary CSVs for a category
```bash
find results/03_unified_runs -name "summary.csv" | sort
find results/04_rank_sweeps  -name "summary.csv" | sort
```

### Quick module lookup across all suites
```bash
python3 Codes/framework/main.py list              # list all registered modules
python3 scripts/build_results_index.py            # rebuild INDEX.md
```
